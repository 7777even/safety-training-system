# 清爽现代风样式基准

## 适用范围与优先级

本文件是安全教育培训系统后续 Web 门户、管理后台、移动端及详情编辑页的唯一视觉样式基准。它以 `清爽现代风 (Clean & Modern)UI设计风格.html` 的“风格 1：现代清爽”和 `详情编辑.html` 为参考来源。

当本文件与既有设计描述存在差异时，以本文件为准；页面实现仍须遵循 `docs/api/` 中已确认的接口契约。

## 视觉语言

- **定位**：清爽、现代、专业的企业级学习管理与安全培训系统。
- **界面基底**：浅灰蓝页面背景、白色内容容器、细边框与轻阴影；不使用拟态风、玻璃拟态或大面积渐变。
- **信息层级**：蓝色仅承担品牌、选中、链接与主操作；状态色只表达状态，不用于装饰。
- **课程封面例外**：课程、培训计划等内容封面可使用低面积渐变和简洁线性图形，不能扩展到后台页面背景、导航或表单。

## Foundation Tokens

| Token                    | 值          | 用途                           |
| ------------------------ | ----------- | ------------------------------ |
| `color-bg-page`        | `#F8FAFC` | 页面背景                       |
| `color-bg-surface`     | `#FFFFFF` | 顶栏、侧栏、卡片、编辑容器     |
| `color-bg-subtle`      | `#F9FAFB` | 区块标题栏、筛选区、底部操作区 |
| `color-text-primary`   | `#0F172A` | 页面标题、关键正文             |
| `color-text-regular`   | `#374151` | 正文、表单标签                 |
| `color-text-secondary` | `#64748B` | 辅助说明、次级信息             |
| `color-border`         | `#E5E7EB` | 控件、卡片与分割线             |
| `color-primary`        | `#2563EB` | 主按钮、链接、选中导航、焦点   |
| `color-primary-hover`  | `#1D4ED8` | 主操作悬停                     |
| `color-primary-subtle` | `#EFF6FF` | 导航选中、轻提示背景           |
| `color-danger`         | `#DC2626` | 删除、错误、必填标记           |

字体使用 Inter 与系统中文字体回退（PingFang SC、Microsoft YaHei）。正文为 14px，辅助信息为 12px，区块标题为 16px/600，页面标题为 24px/700。

## 组件规则

- **圆角**：控件与导航项 6–8px；卡片、编辑容器与移动端内容卡 12px；Tag 可用全圆角。
- **阴影**：默认使用 `shadow-sm` 等级；卡片悬停仅上移 2px 并略增阴影，不使用夸张动效。
- **导航**：后台为白色左侧导航，选中项使用 `color-primary-subtle` 背景与主色文字；门户使用顶栏导航，但保持相同的状态色、间距与图标风格。
- **按钮**：一个区域只保留一个主操作。Primary 为蓝底白字；Secondary 为白底灰边；Text 为蓝色文字；Danger 为红色。保存与发布通过主次层级区分，不新增第二个品牌主色。
- **表单**：PC 字段高度 40px、移动端 44px；白底灰边、8px 圆角、蓝色焦点环。详情页采用“标签列 + 字段列”的 2/10 栅格，并以分段容器组织内容。
- **详情编辑**：页面标题可使用左侧 4px 蓝色强调线；主体为居中的白色编辑容器，区块标题栏与底部操作栏使用浅灰底。
- **列表与卡片**：筛选区、列表工具栏、数据卡片均使用白色容器和轻边框；课程卡封面与信息区分层，封面渐变仅作为内容识别。
- **门户任务卡片（学习/考试/培训）**：分类走封面**左上角**白底胶囊角标（12px 主色），状态走标题行**右侧** `ElTag size="small"`，
  元信息走 `dl` 浅底对齐行（`dt` 12px 次级色 / `dd` 13px 正文色、`grid-template-columns: 60px minmax(0,1fr)`、
  行高 20px、`background: var(--color-bg-subtle)`）；日期同年省略年份，跨年才补全年份。参照件 `frontend/pc-web/src/views/portal/exams/index.vue`。
- **图标**：使用单色、简洁线性图标，常规尺寸 16–20px；禁止娱乐化、多色或 3D 图标。

## 跨端布局

- **门户**：顶部导航 + 任务、学习进度、提醒等内容卡片。
- **后台**：顶部工具栏 + 左侧导航 + 内容工作区。
- **详情页**：居中编辑容器 + 分段表单 + 固定语义的底部操作区。
- **移动端**：沿用颜色、字体和组件状态，使用 16px 页边距、12px 卡片圆角、44px 最小触控区域与底部 Tab；不得直接压缩后台布局。

## 禁止项

- 不使用附件中的“拟态极简”备选主题。
- 不在系统级背景、导航或表单中使用课程封面渐变。
- 不同时出现多个同权重主按钮。
- 不创建脱离本基准的自定义圆角、阴影、色彩和图标语言。
- 不用彩色胶囊（`.portal-chip` 之类）承载字段元信息：多个同权重药丸并排堆叠，是任务卡片"文本突兀"的主要来源。
