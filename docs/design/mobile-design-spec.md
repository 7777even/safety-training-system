# Mobile 设计规范

## 布局基础

移动端设计基准为 375 × 812。使用安全区域、16px 页面水平间距、12px 卡片圆角和 16px 卡片内边距。重要操作按钮高度不低于 44px。底部 Tab 固定为首页、课程、考试、我的；首期制作首页、课程中心、我的页面，考试仅预留导航入口。

## 首页

顶部为问候语、头像入口、通知和搜索。页面优先展示“今日学习任务”和任务完成进度，其后依次为待办事项、培训计划、考试提醒、快捷入口。任务卡显示课程名、截止时间、进度和明确的继续学习按钮；临期任务同时使用橙色标签和文字提示。

## 课程中心

顶部为搜索和课程分类筛选。课程卡包含封面色块/课程图标、标题、课程时长、学习进度与状态，支持继续学习入口。课程详情和视频学习属于后续页面，仅在信息结构中预留入口与状态。

## 我的页面

顶部使用头像、姓名、组织和账号设置入口。学习数据以学习时长、完成课程、获得证书三项概览呈现；下方为证书、积分、学习记录、设置等列表入口。个人信息区不使用社交化运营元素。

## 交互与状态

列表支持下拉刷新和分页加载；无数据、加载中、网络异常分别使用统一空状态。移动端状态不单靠颜色传达，必须提供文字标签或图标说明。

## 列表界面样式规范

移动端列表界面以课程学习列表为基准：页面背景使用浅灰，顶部使用英文小标题、中文主标题和一句辅助说明形成层级；列表项使用白色卡片、24rpx 左右圆角、轻阴影和 30rpx 内边距。卡片内优先展示类型标签、主标题、辅助信息、圆形关键指标和底部状态/操作区。强调色使用浅蓝系，状态与行动文案必须同时可见，不能只依赖颜色。

考试、课程、任务等列表不得改成 PC 表格或深色大块面板。关键指标可使用圆环或短标签，辅助信息使用低饱和灰色；主要操作放在卡片右下或底部右侧，保持与“继续学习”同级的轻按钮样式。

## 学习任务样式规范

学习任务页应与列表界面同源：使用浅灰页面背景、白色摘要卡、白色目录卡、红色标签和浅红行动按钮。避免使用大面积深蓝、深灰或高饱和渐变作为课程头图背景。章节目录以轻边框分组，内容项使用浅底小卡片；当前可学习项、锁定项、已完成项必须通过文字状态表达。
