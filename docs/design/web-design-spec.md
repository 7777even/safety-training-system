# Web 设计规范

## 布局基础

PC 设计基准宽度为 1440px。门户使用顶部导航与居中内容容器；管理后台使用 240px 左侧导航、顶部工具栏和自适应工作区。页面背景为 `#F5F7FA`，内容模块使用白色卡片与 24px 间距。

## 登录页

Frame：1440 × 900。左侧 58% 为深海蓝品牌区，包含系统名称、安全培训价值说明与简洁的盾牌/课程线性图形；右侧为居中的 400px 登录卡片，包含企业欢迎语、账号、密码、验证码/记住登录、主按钮与帮助入口。品牌区不使用复杂渐变，以深浅蓝色块建立层次。

## 门户首页

顶部放置 Logo、主导航（首页、学习中心、考试中心、证书中心）、通知及用户菜单。主体顺序为：学习概览指标、待完成培训任务、考试任务、学习进度、证书提醒、快捷入口。普通用户仅显示与个人相关的入口；拥有管理权限时，在用户菜单或快捷入口中展示“进入管理后台”，前端只依据后端返回的权限数据决定可见性。

## 管理后台首页

左侧导航包含工作台、培训管理、考试管理、用户管理、企业管理、证书管理。主区顶部展示页面标题和组织筛选；第一行展示培训覆盖率、完成率、待处理考试、临期证书四项统计；第二行使用培训进度趋势和考试通过分布；第三行以待办列表与培训计划表格承载行动项。图表强调趋势与对比，不用装饰性图形替代数据。

## 表格与响应

表头高度 44px、正文行高 52px，默认使用 14px 正文。操作列放置文字按钮，危险操作放入二次确认。页面在 1280px 以下优先缩减栅格列数和侧边留白，不把后台表格强制转换为移动样式。
