# UI Design Principle

> 后续样式实现以 [清爽现代风样式基准](clean-modern-style-baseline.md) 为准；本文的定位与原则用于补充业务设计意图。

## 视觉定位

安全教育培训系统定位为企业级培训与安全监管平台。界面应传达可信、清晰、可执行的工作感，帮助学员快速完成学习任务，也让管理人员高效掌握培训与考试运行状态。

避免娱乐化插画、复杂渐变、夸张动效和大面积营销 Banner。视觉表达以内容、状态和操作优先。

## 参考设计分析

本次仅提供任务说明，未附可分析的参考图片，因此不对具体图片作推断。设计取向依据企业培训、数据驾驶舱和移动学习场景归纳如下：

- **Web 登录与门户**：使用清晰的品牌区与任务工作区分层；信息通过卡片、列表和状态标签组织，导航保持稳定可预期。
- **管理工作台**：以指标、趋势、待办和表格形成从概览到行动的层级，数据图表服务于培训覆盖、完成和风险识别。
- **移动学习**：以当日任务、课程进度和待办优先，底部导航保持低认知成本；个人中心聚焦学习档案与证书。
- **共同特征**：低饱和背景、白色内容容器、克制阴影、统一状态色，以及更高的信息密度（PC）和更大的触控目标（Mobile）。

## 设计原则

- **任务优先**：学习、待办、考试与证书提醒置于页面核心区域。
- **信息分层**：关键指标、任务列表、辅助说明依次呈现，避免同层级争夺注意力。
- **状态清晰**：进行中、已完成、临期、异常使用统一颜色和文字标签共同表达。
- **跨端一致**：PC 与移动端共享语义颜色、字体层级、圆角和组件规则；移动端按触控场景重新组织布局。
- **可组件化**：页面由导航、卡片、表单、标签、表格、空状态等稳定模块组合，便于 Vue3、Element Plus 与 uni-app 实现。

## 字体与数字

中文使用 PingFang SC（macOS/iOS）或 Microsoft YaHei（Windows）回退，英文和数字使用 Inter 回退。标题使用 600 字重，正文使用 400，重点数值使用 600。

## 间距与形态

采用 8px 间距体系：4、8、12、16、24、32、40、48。PC 内容区默认内边距 24px，移动端页面水平内边距 16px，卡片内边距为 16 或 24px。组件圆角为 8px，移动端大卡片可使用 12px。阴影仅用于浮层与关键卡片：`0 4px 12px rgba(16,24,40,.08)`。
