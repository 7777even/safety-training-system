# Design System

## 基础 Token

- 颜色、字体、间距遵循 [清爽现代风样式基准](clean-modern-style-baseline.md)。
- 圆角：`radius-sm=4`、`radius-md=8`、`radius-lg=12`。
- 阴影：`shadow-card=0 4px 12px rgba(16,24,40,.08)`，仅用于悬浮卡片、弹窗和下拉菜单。

## Button

| 类型 | 正常 | Hover | Disabled |
| --- | --- | --- | --- |
| Primary | `#2563EB` 蓝底白字 | `#1D4ED8` | `#BFDBFE` |
| Secondary | 白底蓝边蓝字 | 浅蓝底 | 灰边灰字 |
| Text | 透明底蓝字 | 浅蓝底 | 灰字 |
| Danger | 红底白字 | 深红底 | 浅红底 |

PC 高度为 32/40px；Mobile 主要按钮为 44px。按钮文本使用 14px、600 字重。

## Card 与 Tag

Card 使用白色背景、8–12px 圆角、`#E5E7EB` 细边框与轻阴影；默认内边距 16px，数据概览卡可使用 24px。Tag 为 12px、24px 高度，使用成功、警示、危险、信息四类浅色背景加深色文字，覆盖培训、考试、证书和任务状态。

## Form

输入框、选择框和日期选择统一 40px 高（移动端 44px）、8px 圆角。标签位于控件上方；错误信息位于控件下方，并用文字说明原因。上传组件显示文件名、格式/大小说明和上传状态。

## Table 与 Empty State

后台表格使用浅灰表头、清晰分割线、固定操作列；分页放在表格右下方。空状态包括“暂无数据”“加载中”“加载失败”，均包含简洁线性图标、说明文字和可选的重试/创建操作。
