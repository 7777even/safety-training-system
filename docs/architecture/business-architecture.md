# 业务架构

## 业务领域地图

| 业务领域      | 核心职责                                   | 主要参与角色             | 关键输出            |
|-----------|----------------------------------------|--------------------|-----------------|
| 培训标准与监管规则 | 管理培训类型（尺子）、标准（检查口径）与计划模板（可引用方案）。       | 园区监管端              | 培训类型、培训标准、计划模板。 |
| 组织与身份基础支撑 | 管理机构、账号、角色及认证能力。                       | 园区监管端、企业/培训机构端、学员端 | 组织、用户、身份与授权关系。  |
| 教学资源      | 管理课程素材、题库、试卷与仿真资源。                     | 企业/培训机构端           | 可复用教学与考试资源。     |
| 培训计划与任务   | 按尺子和口径编排本期计划，复制模板课表后可改，并调用开课/考试能力发布任务。 | 企业/培训机构端、学员端       | 培训计划、开课任务、考试任务。 |
| 课程学习与培训执行 | 支持线上学习、线下签到、学习进度和学习反馈。                 | 学员端、企业/培训机构端       | 学习记录、培训参与记录。    |
| 考试与评价     | 组织理论或仿真考试（暂定）、阅卷并形成结果。                 | 学员端、企业/培训机构端       | 答卷、成绩、评价结果。     |
| 分析与归档     | 汇总学习与考试数据，生成个人、机构和期次档案。                | 企业/培训机构端、园区监管端     | 分析指标、培训档案。      |
| 证书与监管预警   | 按既定规则生成证书，监测计划与执行数据并预警。                | 企业/培训机构端、园区监管端、学员端 | 证书、预警记录、监管数据。   |

## 领域协作关系

1. 培训类型提供学时尺子，培训标准提供检查口径，二者约束培训计划；模板只提供可复制课表。
2. 教学资源为培训计划中的课程、练习和考试提供内容输入。
3. 培训计划调用开课与考试能力发布学习与考试任务，学员端产生学习记录和答卷。
4. 考试与评价生成成绩；分析与归档汇总计划、学习和成绩数据。
5. 档案和成绩在满足规则后可触发证书；监管端基于计划、学习、成绩和档案进行监控预警。

## 边界原则

- “课程中心”“考试中心”“工作台”等是交互入口，不作为业务领域的唯一拆分依据。
- 资源管理不直接承担培训任务分配；培训计划承担资源编排与任务发布。
- 成绩分析负责解释和汇总结果，档案负责长期沉淀；二者不能互相替代。
- 证书发放条件和预警判定规则为“暂定”，后续由独立 OpenSpec 确认。
