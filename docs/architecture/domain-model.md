# 概念领域模型

## 建模范围

本文描述业务概念及其关系，用于统一需求、API Contract 和后续数据设计语言。它不是数据库表设计，也不规定字段、主键、索引或存储方式。
培训类型、标准、模板、计划的分层产物与禁止越界带入见 `docs/architecture/training-layer-responsibility.md`。

## 核心概念

| 概念      | 业务含义                       | 主要关系                                    |
|---------|----------------------------|-----------------------------------------|
| 园区      | 实施监管规则和汇总监管数据的范围。          | 包含受监管机构，维护培训标准。                         |
| 机构      | 企业或培训机构等受监管、可开展培训的组织。      | 具备组织成员，执行培训计划。                          |
| 组织单元    | 机构内部的层级化管理单元。              | 归属于机构，关联学员和培训任务。                        |
| 用户与学员   | 系统使用者；学员是参与学习、考试和档案沉淀的主体。  | 隶属组织单元，接收任务。                            |
| 培训类型    | 工种或作业类别及其初培学时、复审学时和线上占比基线。 | 被培训标准、模板和计划引用；产物是尺子，不编排课表，不表达单次计划性质。    |
| 培训性质    | 单次培训计划采用的培养阶段，当前为初培或复审。    | 决定计划使用培训类型的哪一套学时基线。                     |
| 培训标准    | 对培训类型学时与必含考核的检查口径。         | 约束计划发布与预警；可加严但不能降低类型基线；不生成可编辑课表。        |
| 培训模板    | 按类型编排的可复用阶段与内容方案。          | 发布后供计划复制为草稿；不等于一次实际培训；不配本期人员与执行参数。      |
| 培训计划    | 面向特定机构、人员和时间范围的一期培训。       | 必选类型与性质，可选标准（检查）与模板（复制课表）；发布后调用开课/考试能力。 |
| 课程与课程内容 | 可学习的教学单元及其目录内容。            | 由计划分配给学员，关联资源与知识点。                      |
| 教学资源    | 文档、音视频、图片、题目、试卷和仿真资源等内容资产。 | 被课程、考试或计划引用。                            |
| 考试与答卷   | 对学员学习结果进行测评的安排与作答记录。       | 关联计划、试卷、学员和成绩。                          |
| 成绩与分析   | 评分结果及其统计解释。                | 来源于答卷和学习记录，沉淀至档案。                       |
| 培训档案    | 对个人、机构或期次培训过程与结果的长期归集。     | 汇总计划、学习、成绩、证书等。                         |
| 证书      | 在满足既定条件后向学员发放的凭证。          | 关联学员及考试或培训计划。                           |
| 监管预警    | 对标准与实际执行数据比对后形成的监管事项。      | 关联园区、机构、计划及预警规则。                        |

## 关键关系

```text
园区 → 机构 → 组织单元 → 学员
园区 → 培训类型 / 培训标准 / 培训模板
培训类型 + 培训性质 → 计划适用最低学时
培训标准 ──检查──► 培训计划
培训模板 ──可选复制──► 培训计划课表
机构 → 培训计划 → 调用开课 / 考试 / 培训线下场次
学员 → 学习记录 / 答卷 → 成绩与分析 → 培训档案 → 证书
培训计划 / 学习记录 / 成绩 / 培训档案 → 监管预警
```

## 生命周期概览

- 培训计划：选择培训类型与初培 / 复审性质 → 可选按标准检查、按模板复制课表 → 编排并校验适用最低学时 →
  发布冻结并调用开课/考试能力 → 执行与汇总 → 归档。
- 学习任务：待接收 → 学习中 → 已完成或逾期（状态细节“暂定”）。
- 考试：安排 → 作答 → 判分或批阅 → 成绩确认。
- 证书：满足规则 → 生成 → 下发 → 学员查看或下载。
- 监管预警：规则比对发现异常 → 生成预警 → 查看与处置（处置流程“暂定”）。
