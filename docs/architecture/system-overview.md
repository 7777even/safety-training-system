# 系统总览

## 系统定位

安全教育培训系统面向园区监管、企业/培训机构培训组织和学员学习考核场景，形成从培训标准到监管预警的可追溯培训闭环。

系统不以单一页面为业务边界，而以培训标准、培训计划、学习、考试、分析、档案、证书和监管为核心业务能力。

## 系统角色

| 角色 | 主要职责 | 典型业务结果 |
| --- | --- | --- |
| 园区监管端 | 制定培训标准和类型，管理受监管机构，汇聚数据并处置预警。 | 标准、模板、监管视图、预警记录。 |
| 企业/培训机构端 | 建设资源，制定并执行计划，组织课程和考试，管理分析、档案与证书。 | 培训计划、学习任务、成绩、档案、证书。 |
| 学员端 | 接收任务，完成学习和考试，查看个人档案并获取证书。 | 学习记录、考试结果、个人档案、证书。 |

企业端与培训机构端的差异化管理规则为“暂定”。本阶段将二者视为共享培训组织能力的同一角色域。

## 业务闭环

```text
培训标准制定
  → 培训计划
  → 课程学习
  → 考试
  → 成绩分析
  → 档案
  → 证书
  → 监管预警
```

园区监管端从标准制定开始提供规则输入，并在闭环末端接收培训执行数据用于监控和预警；企业/培训机构端负责计划到证书的组织与管理；学员端负责完成被分配的学习和考试任务。

## 边界说明

- 本文档描述长期稳定的业务全景，不定义接口、页面、字段或数据库表。
- 课程直播、仿真运行、人脸识别、微信接入和 App 原生能力均为“暂定”，须在对应 OpenSpec 中确认后实施。
- 具体培训标准、学时规则、合格条件和预警阈值不在本文档中确定。
