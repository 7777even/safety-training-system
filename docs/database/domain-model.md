# 数据库概念领域模型

## 用途与边界

本文从持久化视角描述安全教育培训系统需要长期管理的概念对象及其关系，帮助后续数据建模保持一致。

本文不是 DDL，不定义表名、字段、数据类型、主外键、索引或分库策略。任何数据库实现变更必须先通过 OpenSpec design 确认，再通过
`backend/sts-service-admin/src/main/resources/db/migration/` 实施。

## 概念实体分组

| 分组   | 概念实体                           | 说明                                  |
|------|--------------------------------|-------------------------------------|
| 组织身份 | 园区、机构、组织单元、用户、学员、角色            | 表达监管范围、组织归属与系统参与者。                  |
| 规则计划 | 培训标准、培训类型、培训性质、计划模板、培训计划、培训任务  | 表达从培训类型的初培 / 复审基线、单次计划性质到实际执行任务的链路。 |
| 教学资源 | 课程、课程内容、教学资源、知识点、题库、题目、试卷、仿真资源 | 表达可复用教学和考试内容；仿真细节“暂定”。              |
| 学习考试 | 学习记录、签到记录、考试、答卷、成绩、评价          | 表达学员过程和结果。                          |
| 归档监管 | 培训档案、证书、监管预警                   | 表达长期留存、凭证和监管结果。                     |

## 概念关系

| 起点概念           | 关系      | 终点概念       | 业务含义                                    |
|----------------|---------|------------|-----------------------------------------|
| 园区             | 管辖      | 机构         | 园区监管多个受监管机构。                            |
| 机构             | 包含      | 组织单元       | 机构可按内部层级组织人员。                           |
| 组织单元           | 归属      | 学员         | 学员在培训组织范围内参与培训。                         |
| 培训标准           | 约束      | 培训计划       | 计划选择适用标准并满足其要求。                         |
| 培训类型、培训性质      | 确定      | 培训计划适用最低学时 | 初培读取初培学时，复审读取复审学时；发布后冻结，不根据来源当前值重算历史计划。 |
| 培训计划           | 编排      | 课程、考试、培训任务 | 计划组织执行内容并产生任务。                          |
| 课程             | 使用      | 教学资源       | 课程内容引用资源与知识点。                           |
| 考试             | 使用      | 试卷         | 考试以试卷或题目集作为测评内容。                        |
| 学员             | 产生      | 学习记录、答卷    | 学员执行任务产生过程数据。                           |
| 答卷             | 形成      | 成绩         | 判分或批阅后形成成绩。                             |
| 培训计划、学习记录、成绩   | 汇总为     | 培训档案       | 档案用于长期追溯。                               |
| 学员、培训计划、成绩     | 满足条件后关联 | 证书         | 证书条件及规则“暂定”。                            |
| 标准、计划、学习、成绩、档案 | 触发或支撑   | 监管预警       | 预警规则与处置流程“暂定”。                          |

## 数据演进约束

- 概念实体不等同于一张表；后续可根据生命周期、查询边界和一致性要求拆分或合并。
- 任何新增、修改或删除物理数据结构，必须同步 migration、Entity、API 文档与 OpenSpec design。
- 禁止将本概念模型直接用于生产数据库操作。
