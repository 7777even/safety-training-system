# 业务概览

安全教育培训系统服务企业/培训机构管理员、老师、学员和园区监管人员，覆盖课程、考试、培训、教学辅助、运营分析与统计归档及监管预警的培训业务闭环。

## 当前交付状态

- 已完成：登录认证、机构组织、用户账号、角色权限、数据范围、PC 门户与后台访问控制、移动端登录基础。
- 未开始正式业务实现：课程、考试、培训、证书、档案、统计与监管预警。
- 当前首个业务域：课程能力。其启动条件与拆分见 [课程能力启动清单](./course-readiness-checklist.md)。
