# 业务领域模块

## 培训标准与计划模板

面向园区监管端维护培训类型、初培 / 复审学时基线、培训标准和计划模板，为企业/培训机构制定实际培训计划提供统一依据。平台内置不少于
25 种正式
培训类型；培训标准可收紧但不得降低培训类型对应学时基线。类型是尺子、标准是检查口径、模板是可引用方案、计划是本期实例，分层职责见
`docs/architecture/training-layer-responsibility.md`。其他规则与下发机制以对应 OpenSpec 为准。

## 组织、用户与身份基础支撑

管理园区、企业/培训机构、组织单元、用户与学员等基础对象，并支撑账号、角色和认证。组织层级、角色模型、微信登录和人脸识别等具体能力须在后续 OpenSpec 中确认。

## 教学资源

管理课程素材、题库、试卷和仿真资源。题目可按题型、知识点和难度归类；资源格式、转码方式、导入导出和仿真软件运行机制均为“暂定”。

## 课程与培训计划

课程用于组织教学目标、大纲、内容和考核方式；培训计划分别选择培训类型和初培 / 复审性质，组合课程、考试或线下阶段，确定检查口径、人员范围和执行
周期，并通过调用开课能力与考试能力向学员发布任务，而不是自造另一套开课或考试。仿真能力本期延期。

## 学习与培训执行

学员按任务完成在线课程学习、仿真练习（暂定）或线下培训参与；系统沉淀学习进度、学习时长、签到和评价等过程记录。具体完成口径为“暂定”。

## 考试、练习与评价

支持理论考试、题库练习、模拟考试及仿真考试（暂定）。考试组织包括组卷、人员安排、作答、自动判分、人工批阅和成绩确认；综合素质评价、问卷和专家查课属于补充评价能力，规则为“暂定”。

## 成绩分析与培训档案

汇总课程参与、学习进度、考试成绩和线下培训记录，形成考情与培训分析。档案分为个人档案、企业/机构档案与期次档案，用于长期追溯。统计指标、归档时点和下载范围为“暂定”。

## 证书管理

依据已确认的培训或考试达标规则生成、下发和供学员查看证书。证书模板、编号规则、签发条件和撤销机制均为“暂定”。

## 监管数据与预警

园区监管端聚合企业/培训机构的计划、学习、考试、档案和证书数据。计划学时预警使用计划发布时冻结的初培 / 复审适用最低学时；其他预警规则、等级、
通知与处置机制以对应 OpenSpec 为准。
