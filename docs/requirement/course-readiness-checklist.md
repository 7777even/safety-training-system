# 课程能力启动清单

课程域覆盖 `FR-ENT-CRS-001` ～ `FR-ENT-CRS-010`，并向学员端 `FR-LRN-003` ～ `FR-LRN-007` 提供课程任务、学习与选课能力。本清单是课程 Change 的确认输入，不替代 OpenSpec design。

## 已确定的范围

| 能力      | FR              | 本期确定内容                                        |
|---------|-----------------|-----------------------------------------------|
| 课程资源    | CRS-001、002     | 上传、下载、删除、在线预览；转码状态控制；转码任务可查询                  |
| 课程制作    | CRS-003、004、005 | 维护课程信息、教学目标、大纲、考核方式；章节目录；章节挂载资源、知识点及后续考试/仿真类型 |
| 开课与机构边界 | CRS-007、008     | 课程仅供所属机构使用；配置开课时间、类型与合格方式                     |
| 学习与管理   | CRS-006、009     | 记录章节学习和答题/成绩结果；管理员查看学习详情                      |
| 直播      | CRS-010         | 配置名称、时间、老师和链接；访问资格继承课程报名，学员端从课程卡片进入           |

## 建议拆分为 5 个可确认的业务 Task

| Task        | 覆盖 FR                         | 交付边界                      | 不包含                     |
|-------------|-------------------------------|---------------------------|-------------------------|
| 课程资源与素材库    | CRS-001、002                   | 资源元数据、上传、预览入口、转码状态和操作限制   | 未确认的转码失败重试策略与供应商实现      |
| 课程创建与目录编排   | CRS-003、004、005 的资源/知识点部分     | 课程基本信息、分类、章节树、可学习材料编排     | 理论考试、测验与仿真实体的实际绑定       |
| 课程机构边界与开课   | CRS-007、008                   | 资源归属、严格机构隔离、开课有效期、可见范围    | 外部人员链接学习规则              |
| 学员课程学习与学习记录 | CRS-006、009；LRN-003～007 的课程部分 | 我的课程、选课大厅、章节学习、学习进度和管理端详情 | 未确认的有效时长、完成、退选和知识点掌握度算法 |
| 直播课程        | CRS-010                       | 直播配置、访问范围、入口和有效学习时长采集边界   | 直播平台选型、录播、互动与回放能力       |

## 实施前必须确认

| 决策                          | 原因                          | 确认责任    |
|-----------------------------|-----------------------------|---------|
| 文件格式、单文件和批量上限、存储位置与保留策略     | 对照表列出示例格式和大小，但未形成项目级技术与成本决策 | 产品 + 架构 |
| 转码服务、状态机、失败重试和通知            | 直接影响资源可用性和异步任务实现            | 架构 + 产品 |
| 课程分类是否可由业务用户临时创建            | 对照表有细化描述，主需规未定义分类治理         | 产品      |
| 章节树“无限级”的实际限制与排序并发规则        | 影响数据模型、查询和编辑冲突处理            | 产品 + 架构 |
| 学习时长、切屏、完成、合格与重学规则          | 这些规则决定学习记录和课程结果的业务有效性       | 业务负责人   |
| 公共课程、内部课程在本机构内的创建者、使用者及管理边界 | 影响既有数据范围与权限模型               | 权限负责人   |
| 课程消息、直播平台和选课退选规则            | 对照表提供候选交互，主需规仍标记为待确认        | 产品 + 架构 |

## 对照表细化内容的处理原则

对照表中的智能封面、积分、成员快照、提醒渠道、课程材料下载开关、直播切屏计时等内容均已登记为设计输入。除非在课程 Change 的 `design.md` 中被逐项确认，它们不进入本轮实现，也不作为验收条件；这样可避免将调研产品的行为误当作本系统已批准的业务规则。
