# 业务需求基线与 FR 索引

> **基线版本：** V1.2（2026-07-16）
> **来源：** 《安全教育培训需求规格说明书》与《安全教育培训 74 条 FR 新需求描述对照表》
> **用途：** 本文保留跨版本有效的业务范围、FR 索引和需求治理规则；单项业务能力的可实施规格以 `openspec/changes/` 中经确认的 Change 为准。

## 当前交付状态

已完成系统基础平台：登录认证、机构组织、用户账号、角色权限、数据范围、PC 门户与后台访问控制，以及移动端登录基础。课程、考试、培训及其他业务域尚未进入正式实现；PC 课程中心当前仅为路由入口占位，移动端课程页面目录尚未实现业务页面。

## 端到端业务顺序

```text
课程资源 → 课程制作与开课 → 学员学习与学习记录
  → 理论考试 / 仿真考试 → 培训计划与实施
  → 结果分析与档案 → 证书 → 园区监管统计与预警
```

该顺序用于控制依赖，不代表所有能力必须串行交付。每个领域均须先完成独立 OpenSpec Change、API Contract、数据模型与验收标准确认，再进入前后端实现。

## 需求治理规则

- 每个 OpenSpec Task、API Contract、测试用例和验收记录必须引用一个或多个 FR 编号。
- 对照表中的细化描述是设计输入，不自动覆盖主需求；与主需求冲突、超出主需求或缺少业务口径的内容必须写入 Change 的“需确认事项”。
- `待确认` 的规则不得由实现人员自行补全。涉及权限、数据范围、数据库结构、外部服务或跨端协议时，按 L4 在实现前取得人工确认。
- 原型基线确认后，应在对应 Change 中补充“原型页面—FR—接口—测试”映射；本文不维护页面级规格。
