# 用户角色

## 园区监管端

园区监管端负责“管标准、管机构、看数据、看预警”。

| 职责域 | 角色职责 |
| --- | --- |
| 培训标准 | 设置培训类型、培训标准和计划模板，为培训组织提供合规依据。 |
| 机构监管 | 管理受监管的企业/培训机构及其监管范围。 |
| 监管分析 | 汇聚园区范围的培训、学习、考试、档案等数据，查看统计与下钻信息。 |
| 预警处置 | 基于标准与实际计划或执行数据的比对查看预警；具体处置闭环为“暂定”。 |

## 企业/培训机构端

企业/培训机构端负责“建资源、办培训、发任务、管结果”。

| 职责域 | 角色职责 |
| --- | --- |
| 资源建设 | 管理题库、课程素材、试卷和仿真资源（暂定）。 |
| 培训组织 | 基于标准制定培训计划，配置课程、考试、人员及线下阶段。 |
| 教学与考试 | 发布课程和任务，组织考试，完成自动判分或人工批阅。 |
| 结果管理 | 分析学习与考情，沉淀档案，按规则生成并下发证书。 |
| 基础支撑 | 管理组织、账号、角色、认证与授权；具体权限模型为“暂定”。 |

## 学员端

学员端负责“接任务、学课程、参加考试、查档案证书”。

| 职责域 | 角色职责 |
| --- | --- |
| 任务接收 | 查看被分配的课程、培训和考试任务及消息提醒。 |
| 学习执行 | 进行在线学习、培训阶段学习与线下签到（暂定）。 |
| 考试练习 | 完成练习、模拟考试或正式考试，查看个人结果。 |
| 个人管理 | 完善个人资料，查看个人档案和已获得证书。 |

## 权限边界

本文只描述职责，不定义角色权限点或数据范围。业务资源严格按所属机构隔离，不提供跨机构资源授权；真实访问控制由后端承担，其他权限模型必须在后续
OpenSpec 中确认。
