## 1. 统计口径

本报告以 `docs/product/功能项.csv` 中编号 1～87 的原始功能项为主表，不使用 74 条 FR 对照表替代原始编号。

每个功能项按当前有效的原文完整语义评估：

|  完成度 | 判定口径                        |
|-----:|-----------------------------|
| 100% | 原文全部有效语义已形成真实端到端闭环，并有验收证据   |
|  75% | 主体能力基本完成，但仍缺真实联调、部分子能力或最终验收 |
|  50% | 后端和部分页面或流程已完成，但业务闭环明显不完整    |
|  25% | 仅有数据模型、后端接口、Mock 或局部实现      |
|   0% | 当前有效范围没有实现证据                |
|   不计 | 已明确延期、退役或本期不实施              |

范围调整按当前已确认规则处理：

1. 仿真软件、仿真教学、仿真练习/考试、防作弊和人脸识别本期延期。
2. 跨机构资源授权能力本期不实施并已退役。
3. 混合功能项只排除其中明确延期或退役的语义，其余非仿真、非防作弊部分继续计入当前范围。

## 2. 总体统计

原始功能项共 87 项，整项排除 9 项：

- 12：人脸识别认证。
- 23：课程资源授权，已随跨机构资源授权能力退役。
- 27～32：仿真管理、仿真考试、仿真练习及成绩。
- 75：学习水印、随机验证题及防挂机，属于延期的防作弊能力。

剩余当前有效功能项为 78 项。

|  完成度 | 数量 | 占当前范围 |
|-----:|---:|------:|
| 100% |  0 |    0% |
|  75% | 16 | 20.5% |
|  50% | 24 | 30.8% |
|  25% | 29 | 37.2% |
|   0% |  9 | 11.5% |
|   合计 | 78 |  100% |

折算完成量：

> 31.25 个完整功能项当量 / 78 个当前功能项，综合完成度约为 **40.1%**。

该结果应按以下方式理解：

- 61/78 项已经存在某种工程资产，但不代表已经可交付。
- 按原文完整语义，当前没有一项具备无缺口的 100% 证据。
- 主体基本完成、达到 75% 的有 16 项。
- 38 项处于 0%～25%，是当前主要欠账。
