# 系统背景

## 业务问题

安全教育培训涉及监管标准、培训组织、课程学习、考试评价、档案证书和监管监督等多个环节。若这些环节在不同系统或不同口径下运行，容易出现计划与标准脱节、学习与考试结果不可追溯、监管数据滞后等问题。

## 建设目标

建设统一的安全教育培训系统，使园区监管端能够设定规则和监测执行，使企业/培训机构端能够组织培训闭环，使学员端能够完成任务并查看个人结果。

## 本期知识库范围

- 明确园区监管端、企业/培训机构端、学员端的职责。
- 固化培训标准制定到监管预警的端到端闭环。
- 按业务领域归纳功能清单，为后续业务能力 OpenSpec 提供输入。
- 建立概念模型和术语，避免团队在“培训计划”“培训任务”“课程”“考试”“档案”等概念上产生歧义。

## 非范围

- 不在本阶段确定具体页面、接口、角色权限、数据表或报表指标口径。
- 不在本阶段确定培训学时、合格线、证书签发条件和预警阈值。
- 人脸识别、微信接入、直播、仿真和 App 能力的实施范围均为“暂定”。
