# 安全教育培训系统使用说明

## 1. 登录

登录需要填写企业编码、账号和密码。密码在浏览器端先计算 SHA-256 摘要后提交。企业编码、账号或密码错误时，按页面提示修正；1001、1002、1003 统一按认证失败处理。

## 2. 租户管理员

租户管理员可在“系统管理 → 机构组织”中完成租户管理、用户管理、部门管理、标签管理、岗位管理和角色管理。创建租户时需要同时填写管理员账号、管理员名称和管理员初始密码；租户可停用或重新启用。停用租户后，该租户用户不能继续登录。

角色仅维护角色级别、菜单权限、状态和版本，不再配置数据范围或自定义部门范围。用户资料直接维护成员类型、邮箱、职务、入职日期、标签、岗位和主岗位。

## 3. 普通企业用户

普通企业用户只能在当前企业租户上下文中使用被授权的门户、素材、课程、考试和培训功能。企业用户不能切换租户，也不能查看其他企业的聚合数据。

课程、考试和培训页面中尚未完成真实联调的业务仍使用现有 Mock，但请求字段必须以 `docs/api/*.openapi.json` 为准。

## 4. 监管平台

`REGULATOR` 租户且具有 `regulator:aggregate:view` 权限的用户可查看企业汇总，包括已发布课程、运行中培训计划、参训人数和完成情况。查看某企业时，前端通过 `X-Target-Tenant-Id` 设置只读租户视角；该视角只允许 GET、HEAD、OPTIONS 请求，不改变业务接口路径和参数。

监管相关错误码：4061 表示非监管租户不允许切换，4062 表示只读视角禁止写操作，4063 表示目标租户不存在或不可用，4064 表示目标租户参数非法，4065 表示监管聚合仅对监管租户开放。

## 5. 素材

素材上传保留分片、SHA-256 校验、断点续传和取消上传。旧 DOC 或包含 VML 的旧 DOCX 需要先转换为标准 DOCX 或 PDF，遇到 5006 按提示重新处理。在线预览格式为 HLS、MP3、PDF、Excel、图片和原文件；Excel 统一支持 XLS/XLSX，原文件仅提示下载或不支持在线预览。外链和富文本不请求 play-info，直接使用对应渲染分支；6011 表示素材不存在或已删除。

## 6. 已移除能力

系统已移除机构成员独立 CRUD、监管关系 CRUD、组织层级/上级机构入口和角色数据范围配置。成员信息已合并到系统用户，监管企业关系改为监管聚合与只读租户视角。
