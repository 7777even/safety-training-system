# 关于裕龙项目使用安全教育培训系统的部署方式与云资源费用说明

编制日期：2026-08-28

状态：内部决策说明，可直接呈报上级。费用为桌面推演，不是云厂商报价单。

点播与带宽口径见 [customer-environment-survey.md](./customer-environment-survey.md)。阿里云 OSS + CDN
算法见 [aliyun-oss-cdn-cost-estimate-300-users.md](./aliyun-oss-cdn-cost-estimate-300-users.md)。

---

## 1. 背景

裕龙侧希望使用本套安全教育培训系统。该系统与普通管理后台不同：学员看课会持续拉取培训视频（720p HLS
切片）和课件预览，流量随「同时看的人数、每月看了多少小时」线性增加。

因此需要提前说明两件事：

1. **系统本身可以完全内网私有化部署**，不绑定阿里云 OSS、CDN 或云转码。
2. **一旦学员要从公网（家里、4G、园外）看课**，视频出片要么走客户自己的公网出口，要么走云 OSS + CDN。后者会产生**按月、按流量计费的额外费用
   **，需要单独汇报和决策。

---

## 2. 费用从哪来（先澄清一个误解）

OSS、CDN **不是本系统的标配组件**，也不是「装系统就必须买的云产品」。

| 组件               | 作用             | 何时才会产生费用             |
|------------------|----------------|----------------------|
| 对象存储（云 OSS）      | 把视频、课件放在云上     | 课件允许出园区、并采用云存储时      |
| CDN              | 把已经转好的片子发给园外学员 | 园外看课、且不想把全部流量压在客户出口时 |
| 园区内 MinIO + 自建转码 | 内网存、内网转、内网播    | **无上述云点播费**          |

当前产品默认路径是：**园区内私有对象存储（MinIO）+ 园区内转码（FFmpeg / OnlyOffice）**。预览和播放走鉴权，不把文件做成公网直链。

云 OSS + CDN 是「课件允许出域、且园外看课量较大或出口扛不住」时的**可选方案**，不是安装必要条件。

---

## 3. 给裕龙的两条路（本次决策主线）

### 3.1 方案甲：园区内部署，必要时把系统映射到公网（推荐优先评估）

- 应用、数据库、视频文件、转码全部放在裕龙机房/内网。
- 园内学员走内网看课，**不占互联网出口**。
- 若确有园外/手机流量看课需求，可通过防火墙/反向代理把系统映射到公网 IP 或域名。
- **只要公网出口（尤其是上行）带宽够高峰同时观看，就可以不买 OSS、不买 CDN。**
- 云点播月费：**0 元**。代价是占用裕龙已有专线/出口，并需做好 HTTPS、访问控制、等保边界。

### 3.2 方案乙：课件上云，走 OSS + CDN

- 适合：课件允许出园区；大量学员在家里/4G 看课；或园区出口明显不够、又不想扩专线。
- 费用按「这个月一共看了多少小时视频」计，长期存在。
- 课件和个人信息出域须裕龙安全/等保书面同意；当前产品要接公网 CDN，还涉及签名 URL 等架构变更，不能当成开关一开就上。

**结论一句话：** 不是「用这套系统就必须付 OSS/CDN 钱」；而是「**园外看课的流量从哪出**」——出客户自己的公网出口，还是出云厂商
CDN。

## 4. 费用对比（便于汇报的量级）

点播流量只跟观看时长有关，公式：

```text
人·小时 = 人数 × 人均每月看视频小时数
下行流量 ≈ 人·小时 × 1.3 GB
```

`1.3 GB` 对应单人规划约 3 Mbps 看 1
小时，含切片开销；不是锁死码率承诺。单价与算法细节见 [aliyun-oss-cdn-cost-estimate-300-users.md](./aliyun-oss-cdn-cost-estimate-300-users.md)。

**示例：300 人、人均每月看视频 4 小时**（约 1200 人·小时，下行约 1.56 TB）

| 出片方式                 | 云点播月费量级（阿里云官网案例单价，调价以控制台为准） |
|----------------------|-----------------------------|
| 园区内部署，视频不出公网         | **0 元**                     |
| 园区内部署，映射公网，出口带宽够用    | **0 元云点播费**（走裕龙已有专线）        |
| 云 OSS + CDN（推荐的云上点播） | **约 450～550 元/月**           |
| 学员直连 OSS、不配 CDN      | **约 800 元出头/月**（不建议长期这么用）   |

换人数可按同一公式放大。例如 500 人、人均每月 4 小时：下行约 2.6 TB，CDN 方案仅流量大约七百元量级，另加存储。

说明：

- 300 人 ≠ 300 路同时在线。月费用看「看了多少小时」；卡不卡看「高峰同时看几路」。
- 100 GB 流量包远远不够（约只够 77 人·小时），不能当月套餐。
- 直播（腾讯会议等）不在本估算内。
- 以上是桌面推演，签订合同前应以云厂商实时单价和裕龙实际人数、学时重算。

## 5. 方案甲要「带宽比较高」具体指什么

内部署映射公网后，**园外每多一个人在线看课，流量都从裕龙机房的上行出去**。这和 CDN 相反：CDN 是学员就近取流，客户出口只承担少量回源。

规划假说（720p 培训课，待用真实课件实测）：

```text
峰值带宽 ≈ 同时观看人数 × 3 Mbps
```

| 园外同时看课人数 | 建议预留出口上行   | 含义                      |
|----------|------------|-------------------------|
| 50 人     | 约 150 Mbps | 普通百兆出口会卡                |
| 100 人    | 约 300 Mbps | 需至少千兆级出口余量              |
| 200 人    | 约 600 Mbps | 专线要明确「媒体保障带宽」，不宜和办公抢    |
| 500 人    | 约 1.5 Gbps | 一般应考虑 CDN 或扩容，不宜长期单机房硬扛 |

同时观看 ≠ 账号总数。分散自学可能只有日活的 5%～15%；入园培训、三级教育集中开班，可能到当班人数的 50%～80%。

**判断口径：**

1. 学员主要在厂区/办公楼内网学习 → **不必上 OSS/CDN**，也不必为点播扩公网出口。
2. 有园外看课，但高峰同时观看人数对应的上行，裕龙专线**已有余量且可做 QoS** → **内部署 + 公网映射即可，避免云费用**。
3. 园外并发高、出口不够或不允许视频出机房公网 IP → 再评估 OSS + CDN，并走安全出域审批。

带宽不够时，也不应一上来买 CDN。处理顺序建议为：

1. 错峰开课、分班、限制同时开播课数（管理手段，零成本）
2. 教室有线 + 加 AP（园内卡顿多半是无线，不是互联网出口）
3. 机房万兆到存储、播放直出对象存储（仍内网）
4. 最后才是公网 CDN（必须先过出域书面许可）

## 6. 安全与合规

- **课件能否出园区**是第一道闸：不能出域，则 OSS/CDN 直接排除，只能方案甲；园外学习需另评 VPN/零信任。
- 映射公网 ≠ 把视频桶改成公开下载。仍应保持登录鉴权、HTTPS、最小化暴露面（建议只开放网关，不直接暴露存储）。
- 成绩、证书、人员信息是否允许出域，与课件不是同一件事；即使看课走公网，业务库仍可只放内网。
- 等保、密评、数据驻留以裕龙书面口径为准，口头「应该可以上云」不能作为方案乙依据。

## 7. 建议决策与请示事项

**建议：**

1. 向裕龙按 **「默认内部署、不绑定 OSS/CDN」** 报价和方案说明，明确云点播不是系统必选成本。
2. 请裕龙信息化确认：**园区出口带宽（含上行余量）、是否允许公网映射、高峰同时看课人数、学员是否必须园外看课、课件能否出域。**
3. 若出口余量覆盖高峰并发，采用方案甲，**可避免 OSS/CDN 持续费用**。
4. 仅当「必须大量园外看课 + 出口不够 + 允许出域」同时成立时，再单列云资源预算（按人·小时测算，并预留单价波动）。

**请上级决策：**

1. 是否同意按方案甲作为裕龙项目默认部署口径对外沟通。
2. 是否授权在调研问卷回收前，暂不把 OSS/CDN 列入必选商务成本。
3. 若裕龙坚持园外看课且出口不足，是否同意启动云资源专项（需安全书面许可后再做详细报价）。

**下一步（不阻塞本次汇报）：**
向裕龙回收环境调研中的决策关键项（出域、园外看课、同时在线、出口带宽）。无这四项，不能出具最终拓扑和云费用锁定值。问卷见 [customer-environment-questionnaire.md](./customer-environment-questionnaire.md)。

## 8. 对外 / 对内口径

- **对外：** 系统支持完全内网私有化；OSS/CDN 只在园外大规模点播时才需要；内部署且公网出口够用即可避免这笔费用。
- **对内：** 不要把「约 460 元/月」说成合同价，那是 300 人 × 人均 4 小时、阿里云案例单价的推演。
- 裕龙实际人数、是否倒班集中看课、专线是百兆还是千兆，会显著改变结论；数字确认后应按第四节公式重算一版附在请示后面。
