### 数据安全与出域（安全填）

**K1** 培训视频、课件是否允许离开园区内网？（单选，须与书面策略一致）

「离开园区内网」指教学视频/PPT/PDF 会不会出现在园外的网上：存在阿里云 OSS、经公网 CDN 发给家里/4G 学员，或从园内机房把视频推到互联网。不是指
U 盘拷贝。

- **不能出域**：不能把课件放到公网对象存储或 CDN；如需园外学习，须另行评估 VPN 等合规远程接入方式。
- **能出域**：允许把课件放到国内云/CDN，园外可从公网看（能到哪家云见 K5）。

本题是判断能否使用公网对象存储或 CDN 的前提，请依据客户现行制度或书面确认填写。

- [ ] 不能出域
- [ ] 能出域
- [ ] 尚无书面结论

**K2** 学员姓名、成绩、证书扫描件是否允许离开园区内网？（单选）

和 K1 不是同一件事：K1 是课件文件；本题是**个人信息**。有的园区允许课件上
CDN，但要求成绩保存在园内。本题选“不能出域”时，应进一步确认应用、数据库、日志和备份的部署边界，不能直接采用整套公有云方案。

- [ ] 不能出域
- [ ] 能出域
- [ ] 尚无书面结论
