# 业务术语表

| 术语           | 定义                                      | 边界说明                                              |
|--------------|-----------------------------------------|---------------------------------------------------|
| 园区监管端        | 代表园区管理方开展标准制定、机构监管、数据监控和预警的系统角色。        | 不等同于企业/培训机构后台管理员。                                 |
| 企业/培训机构端     | 组织教学资源、培训计划、课程、考试、档案和证书的系统角色域。          | 企业与培训机构的差异化规则“暂定”。                                |
| 学员端          | 接收并完成学习、考试和个人资料查看任务的系统角色。               | 不等同于授课教师、阅卷人等内部岗位。                                |
| 培训标准         | 对培训类型、学时、考核等提出的监管规则描述。                  | 总学时要求可以收紧但不能降低培训类型对应的初培 / 复审基线；其他规则以 OpenSpec 为准。 |
| 培训类型         | 表达工种或作业类别、可被标准和培训计划引用的培训分类。             | 维护初培学时、复审学时和线上最高占比；不表达某一次计划是初培还是复审。               |
| 培训性质         | 一次培训计划采用的培养阶段，当前业务值为初培或复审。              | 与培训类型是两个维度；“初审”不是初培，“复训”不作为当前独立业务值。               |
| 培训计划         | 基于培训类型、培训性质和适用标准组织课程、考试、人员和周期的业务单元。     | 发布时冻结培训性质和适用最低学时；不等同于单节课程或单场考试。                   |
| 培训任务         | 由培训计划向特定学员或组织下发的可执行事项。                  | 可包含学习、考试或线下阶段，细节“暂定”。                             |
| 课程           | 组织教学目标、内容与考核方式的教学单元。                    | 不等同于课程资源文件。                                       |
| 教学资源         | 被课程、题目或考试引用的内容资产。                       | 包含文档、音视频、图片等；格式和存储“暂定”。                           |
| 题库           | 按知识点、题型、难度等维度管理的题目集合。                   | 不等同于试卷。                                           |
| 试卷           | 用于一次考试或练习的题目组合。                         | 组卷和随机规则“暂定”。                                      |
| 学习记录         | 学员完成课程或培训任务过程产生的记录。                     | 完成口径、时长口径“暂定”。                                    |
| 答卷           | 学员在考试或练习中提交的作答内容。                       | 不是最终成绩。                                           |
| 成绩           | 对答卷或评价结果进行评分后形成的结果。                     | 成绩计算和确认规则“暂定”。                                    |
| 成绩分析         | 对成绩、考情或学习数据进行统计和解释的结果。                  | 指标口径由后续 OpenSpec 确定。                              |
| 培训档案         | 对培训过程及结果进行长期归集的资料集合。                    | 可分个人、机构与期次档案。                                     |
| 证书           | 达到既定条件后向学员生成和下发的培训凭证。                   | 模板、签发、撤销规则“暂定”。                                   |
| 监管预警         | 根据监管标准与实际计划或执行数据比对产生的异常事项。              | 等级、通知和处置流程“暂定”。                                   |
| API Contract | 前后端协作的接口唯一边界，定义 URL、方法、参数、返回、错误码、权限和示例。 | 必须维护在 `docs/api/`，不由前端自行定义。                       |
