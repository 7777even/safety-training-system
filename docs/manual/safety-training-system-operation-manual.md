# 1. 系统概览

## 1.1 系统定位

本系统是一套**多租户**的安全教育培训平台，把「培训标准制定 → 培训计划 → 课程学习 → 考试 → 成绩 → 档案 → 证书 → 监管预警」串成一条完整闭环。

系统按**机构（租户）**划分数据空间，共三类机构：

| 机构类型 | 说明 | 数量约束 |
|---|---|---|
| 企业 `ENTERPRISE` | 开展本企业安全培训的主体 | 可创建多个 |
| 培训机构 `TRAINING_INSTITUTION` | 提供培训服务的主体 | 可创建多个 |
| 监管平台 `REGULATOR` | 园区/上级监管方，只读查看全部企业与培训机构数据 | **全系统唯一**，由系统初始化建立，不可在界面创建 |

> ⚠️ 企业与培训机构在系统内能力一致（都可建课程、办考试、办培训），仅类型标签与监管统计口径不同。类型可在机构管理中互转，但**不能改写为监管平台**。

## 1.2 三类使用者与职责

| 使用者 | 使用端 | 核心职责 |
|---|---|---|
| **平台运营 / 超级管理员** | PC 管理端 | 创建机构（开户）、维护全平台菜单与字典、跨机构排障 |
| **机构管理员 / 培训教师** | PC 管理端 | 建部门/角色/用户；建素材、课程、题库、试卷、考试、培训计划；发成绩、发证书、归档 |
| **监管人员** | PC 管理端（监管渠道） | 只读汇聚企业数据、查看学时预警、下钻机构计划与人员 |
| **学员** | PC 门户 + 移动端 | 接任务、学课程、考试、查看证书与档案 |

## 1.3 导航结构

登录后，左侧/顶部菜单**完全由账号权限决定**，不同角色看到的菜单不同。系统共五个菜单模块：

```
门户            →  首页 / 学习中心 / 考试中心 / 培训中心 / 教学辅助
模块首页概览     →  静态概览占位（指标卡 + 图表占位，暂未接入数据）
应用中心         →  素材库 / 课程管理 / 考试管理 / 培训管理
系统管理         →  机构组织（机构・标签・岗位・部门・用户・角色）/ 菜单管理 / 字典管理
企业工作台       →  本机构业务概览与待办
监管平台         →  监管工作台 / 数据中心 / 学时预警 / 机构管理（仅监管机构会话可见）
```

> 🔎 「教学辅助」与「模块首页概览」当前为占位页，不承载业务操作。
> ⚠️ 专属模块按**登录会话的机构类型**收敛：以企业/培训机构编码登录看不到「监管平台」；以监管平台编码登录看不到「应用中心」「企业工作台」。这与账号身份无关。

## 1.4 端与访问地址

| 端 | 用途 | 说明 |
|---|---|---|
| PC 管理端 | 机构管理、业务配置、监管 | 浏览器访问系统地址后进入登录页 |
| PC 门户 | 学员学习/考试/培训 | 与 PC 管理端同一站点，登录后按权限落点 |
| 移动端（H5） | 学员移动学习、扫码填问卷 | 由运维提供移动端地址/二维码 |

> 🔎 生产访问域名、移动端地址由运维/实施方提供。开发环境参考：PC 端 `5173`、移动端 H5 `5174`（仅供内部联调，勿用于培训演示以外场景）。

# 2. 初始账号、角色与登录

## 2.1 系统初始化后「默认有什么」

一套**全新初始化的系统**只包含以下内容（其余数据全部由运营人员在使用中创建）：

### 2.1.1 默认机构（租户）

| 企业编码 | 机构名称 | 机构类型 | 说明 |
|---|---|---|---|
| `REGULATOR` | 监管平台 | 监管平台 | 全系统唯一，只读覆盖全部企业与培训机构；**不由界面创建** |
| `DEMO` | 示例企业 | 企业 | 开发与演示用的示例企业租户 |

### 2.1.2 默认账号

| 企业编码 | 登录账号 | 初始密码 | 账号性质 | 绑定角色 |
|---|---|---|---|---|
| `DEMO` | `superAdmin` | `superAdmin123` | **平台超级管理员**（全平台唯一） | 无角色（硬编码全权限特权） |
| `DEMO` | `admin` | `admin123` | 示例企业管理员 | `admin`（管理员） |

> ⚠️ **两个账号的性质完全不同，这是操作手册最重要的一条：**
> - `superAdmin` 是全平台唯一的特权账号，拥有所有功能权限（通配符 `*`），**是唯一能在界面上"创建新机构"的账号**。它在系统用户列表中**不显示任何操作按钮**，不可被编辑、删除，也不能被普通流程重置密码。
> - `admin` 是 **DEMO 示例企业的企业管理员**，只能管理 DEMO 企业自己的数据，**看不到「机构管理」菜单**，无法创建机构。

### 2.1.3 默认角色

| 角色编码 | 角色名称 | 归属机构 | 说明 |
|---|---|---|---|
| `admin` | 管理员 | `DEMO` | 示例企业管理员角色；绑定除监管模块与机构管理外的全部可见菜单 |

> 说明：`superAdmin` **不是角色**，而是账号级特权，系统初始化时刻意不创建同名角色，也不会出现在角色列表里。

### 2.1.4 其他初始化内容

- **全量菜单树**：门户、应用中心、系统管理、企业工作台、监管平台五大模块及其所有页面与按钮权限点。
- **两个字典类型**：`sys_user_status`（用户账号状态）、`device_status`（设备运行状态）。
- **三条系统参数**：系统标题、启用的登录方式（`local` 本地账号）、密码安全策略（最短 5 位、至少 1 个数字、至少 1 个字母）。

## 2.2 登录操作

### 2.2.1 PC 端登录步骤

1. 打开系统登录页，页面有三个输入项：
   - **企业编码**：机构的登录标识（如 `DEMO`）；
   - **账号**：工号（如 `superAdmin`）；
   - **密码**：账号密码。
2. 点击「登录」。
3. 登录成功后，系统自动跳转到该账号菜单中第一个可访问的页面。

> ✅ **专属登录链接**：机构管理页可为任一机构「复制登录链接」，格式为 `系统地址/login?orgCode=机构编码`。员工用该链接打开时，企业编码自动带入并显示「当前机构」，无需手工输入，降低输错概率。
> ⚠️ 企业编码在系统中**不区分大小写**（自动转换为大写比对）。
> ⚠️ 登录失败时系统统一提示"企业编码、账号或密码错误/认证失败"，**不会区分**是哪一项错误（安全设计，防止账号枚举），运营排障时不要依赖错误文案区分原因。

### 2.2.2 会话规则（重要）

- 登录时的「企业编码」决定**本次会话的数据空间**：之后所有列表、查询、保存都只作用于该机构。
- 企业/培训机构不能切换机构，也看不到其他机构的数据。
- **superAdmin 可用任意一个「已存在且启用」的企业编码登录**，该编码决定本次会话进入哪个机构的数据空间。这是"给某个机构建账号/排障"的关键手法（详见 §4.6）。

### 2.2.3 移动端登录

移动端同样需要「企业编码 + 账号 + 密码」三项，操作与 PC 端一致；登录后进入底部五个标签页：首页、学习、考试、培训、我的。

## 2.3 首次上线必做事项（运营 Checklist）

1. **修改默认口令**：`superAdmin`、`admin` 的初始密码仅用于交付/演示，正式环境必须修改。
   - `admin` 可在「系统管理 → 机构组织 → 用户管理」中通过「重置密码」修改；
   - 🔎 `superAdmin` 在界面不显示操作按钮，其密码修改途径需与实施方确认。
2. **创建正式机构**：按 §3 创建实际使用的企业/培训机构，弃用示例租户 `DEMO`（或改造成正式的示例）。
3. **为每个正式机构建好管理员与基础组织**：按 §4 执行。
4. **删除/停用演示数据**：确认示例数据不影响正式统计后再上线。

# 3. 开园第一步：创建新机构

## 3.1 谁可以创建机构

| 账号 | 能否创建机构 | 说明 |
|---|---|---|
| `superAdmin`（超级管理员） | ✅ 可以 | 可在界面创建企业 / 培训机构 |
| 监管平台账号 | ✅ 可以 | 监管租户的管理员可创建、维护企业与培训机构 |
| 企业 / 培训机构管理员（`admin` 角色） | ❌ 不可以 | 系统**刻意不向企业管理员分发「机构管理」菜单及其按钮权限** |
| 示例租户 `DEMO` 的 `admin` | ❌ 不可以 | 同上 |

> ⚠️ 这是设计的硬边界：机构是租户主数据本身，只由平台或监管方维护。企业管理员即便手工构造请求也会被后端拒绝（`4048 仅系统管理员或监管租户可管理租户`）。

## 3.2 操作步骤（用 superAdmin 创建机构）

| 步骤 | 操作 |
|---|---|
| 1 | 登录 `superAdmin`：企业编码填 `DEMO`（或任意已存在机构编码），账号 `superAdmin`，密码 `superAdmin123` |
| 2 | 打开 **系统管理 → 机构组织 → 机构管理** |
| 3 | 点击「**新增**」 |
| 4 | 填写机构信息与初始管理员信息（见 §3.3） |
| 5 | 点击保存，提示「机构创建成功」 |
| 6 | 在列表中对该机构点击「**复制登录链接**」，发给该机构管理员 |
| 7 | 新机构管理员用该链接与初始密码登录，开始 §4 的组织初始化 |

**菜单路径**：系统管理 → 机构组织 → 机构管理
**页面地址**：`/admin/system/org/organization`

## 3.3 新增机构表单字段

| 字段 | 必填 | 说明与约束 |
|---|---|---|
| 企业编码 | **是** | 登录入口标识，2～64 位，仅字母/数字/下划线/短横线，自动转大写；**创建后不可修改** |
| 机构名称 | **是** | 不超过 100 字 |
| 机构类型 | **是** | 仅可选「企业」或「培训机构」（监管平台不可在此创建） |
| 管理员账号 | **是**（仅新增时出现） | 新机构首个管理员工号，默认 `admin` |
| 管理员名称 | **是**（仅新增时出现） | 默认「管理员」 |
| 管理员初始密码 | **是**（仅新增时出现） | 新机构首个管理员的登录密码 |
| 状态 | 否 | 默认「正常」 |
| 说明 | 否 | 不超过 500 字 |

> ⚠️ 企业编码、管理员账号不能包含不可见字符（如从 Word/网页复制带入的空格、零宽字符），否则会报"不能包含不可见字符"。
> ⚠️ 企业编码重复会报「企业编码已存在」。

## 3.4 创建机构时系统自动完成了什么

创建机构时，系统会在**新机构的数据空间内**自动完成（无需人工再做）：

1. 建立新机构（租户）主数据；
2. 创建一条内置的 **「管理员」角色**（角色编码 `admin`，角色级别「管理」）；
3. 给该角色绑定**除监管平台模块、机构管理及旧组织模块之外的全部可见菜单权限**；
4. 创建 **首个管理员账号**（即表单里填的管理员账号/名称/密码），并绑定上述「管理员」角色；
5. 写入登录凭证（内部以「企业编码:工号」唯一标识）。

**系统不会自动创建的**（需登录新机构后手工建立）：

- ❌ 部门（**没有默认部门**，这是新机构第一件必须做的事）
- ❌ 岗位、标签
- ❌ 除首个管理员外的任何账号
- ❌ 任何课程、考试、培训等业务数据

> ⚠️ **因此新机构管理员首次登录后不能直接建用户**——用户表单要求选择「所属部门」。必须先建部门，见 §4.1。

## 3.5 其他机构管理操作

| 操作 | 说明 |
|---|---|
| 查询/筛选 | 支持按关键词（企业编码或机构名称）、机构类型、状态筛选 |
| 编辑 | 可改机构名称、机构类型（企业/培训机构互转）、状态、说明；**企业编码不可改** |
| 停用 / 启用 | ⚠️ 没有独立"停用"按钮，通过「编辑」把**状态**改为「停用」实现。停用后该机构全部用户**无法登录** |
| 复制登录链接 | 生成并复制该机构的专属登录链接（监管平台不出此项） |
| 详情 | 查看企业编码、名称、专属登录链接、类型、状态、说明 |
| 删除机构 | ❌ 当前版本**不提供**机构删除功能 |

# 4. 新机构初始化：部门 / 标签 / 岗位 / 角色 / 用户

> **本章主角**：新机构的管理员（用 §3.2 拿到的登录链接 + 初始密码登录）。
> **推荐顺序**：部门 → 标签 → 岗位 → 角色 → 用户 → 复核权限。

## 4.0 新机构初始化顺序概览

```
① 建部门树  →  ② 建标签（可选）  →  ③ 建岗位（可选）
        →  ④ 建角色并勾选菜单权限  →  ⑤ 建用户并分配角色
        →  ⑥ 复核：用各角色账号试登录，确认菜单与操作范围正确
```

> ⚠️ 顺序不可颠倒：用户必须落在部门下；角色必须先存在才能分配给用户；权限变更后**访问即时生效**（菜单即时生效，权限缓存约 30 分钟内失效，如需立即生效请联系运维清缓存）。

## 4.1 建立部门树

**菜单路径**：系统管理 → 机构组织 → 部门管理
**页面地址**：`/admin/system/org/dept`

| 步骤 | 操作 |
|---|---|
| 1 | 打开「部门管理」，可见一个树形表格 |
| 2 | 点击「新增」，或对某行点击「添加子级」建下级部门 |
| 3 | 填写部门信息（下表），保存 |
| 4 | 重复建立，形成本机构完整的组织架构 |

表单字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 父级部门 | **是** | 树选择；顶级部门选虚拟根「顶级部门」 |
| 所属机构 | **是** | 企业管理员只能选本机构；平台/监管可选机构（编辑时禁用） |
| 部门名称 | **是** | |
| 部门编码 | **是** | |
| 部门类型 | 否 | 学校/学院/专业/部门/班级/其他，默认「部门」 |
| 部门描述、负责人、负责人电话 | 否 | |
| 排序 | 否 | 数字，默认 0 |
| 状态 | 否 | 默认「正常」 |

> ⚠️ 删除部门会二次确认，且**不可恢复**；已被用户引用的部门不建议删除。
> 💡 建议：新机构至少建一个「安全管理部」类部门，作为首个管理员的所属部门。

## 4.2 建立标签（可选，用于人员分类筛选）

**菜单路径**：系统管理 → 机构组织 → 标签管理
**页面地址**：`/admin/system/org/tag`
**按钮/字段**：新增标签 / 编辑 / 删除；字段为 所属机构（必填）、标签名称（必填）、描述、状态。

💡 典型标签：新员工、特种作业、重点岗位、管理人员、外包人员。

## 4.3 建立岗位（可选）

**菜单路径**：系统管理 → 机构组织 → 岗位管理
**页面地址**：`/admin/system/org/position`
**按钮/字段**：新增岗位 / 编辑 / 删除；字段为 所属机构（必填）、岗位编码（必填）、岗位名称（必填）、描述（无状态字段）。

💡 典型岗位：安全管理人员、车间负责人、设备操作员、外包作业人员、企业培训教师。
> 💡 用户可设多个岗位并指定**一个主岗位**。

## 4.4 建立角色并配置菜单权限（核心步骤）

**菜单路径**：系统管理 → 机构组织 → 角色管理
**页面地址**：`/admin/system/org/role`

| 步骤 | 操作 |
|---|---|
| 1 | 打开「角色管理」，点击「新增」 |
| 2 | 填写角色名称、角色编码、角色级别、说明、状态 |
| 3 | 在**菜单权限树**中勾选该角色允许使用的菜单与按钮 |
| 4 | 保存，提示「角色保存成功」 |

表单字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 所属租户 | **是** | 企业管理员固定为本机构 |
| 角色名称 | **是** | |
| 角色编码 | **是** | 机构内唯一 |
| 角色级别 | 否 | 管理 / 教师 / 学员，默认「管理」 |
| 角色说明、状态 | 否 | |
| 菜单权限 | — | 勾选式菜单树，**父级菜单只负责显示，实际授权以叶子（页面/按钮）为准** |

> ⚠️ 系统**已移除"数据范围"配置**：角色只表达"能操作什么功能"，可见的数据范围一律由机构隔离自动保证（只能看到本机构数据）。
> 💡 角色级别（管理/教师/学员）仅作分类标识，**不自动决定权限**，权限完全取决于勾选的菜单。

**建议的角色规划（企业/培训机构通用四角色）**：

| 角色编码 | 角色名称 | 级别 | 建议赋予的权限范围 |
|---|---|---|---|
| `TENANT_ADMIN` | 机构管理员 | 管理 | 系统管理（用户/部门/标签/岗位/角色）+ 素材库 + 全部业务管理 |
| `TRAINER` | 培训教师 | 教师 | 素材库、课程管理、开课管理、题库/试卷/考试、培训管理、教学任务 |
| `DEPT_MANAGER` | 部门负责人 | 教师 | **只给查看类**权限：课程/开课/报名/学习查看、考试与培训结果查看 |
| `LEARNER` | 学员 | 学员 | **不配后台菜单**，仅门户的学习中心/考试中心/培训中心 |

> ⚠️ **学员角色不要勾选任何后台管理菜单**；学员只用门户与移动端。
> ⚠️ **不要给企业管理员勾「机构管理」**——该菜单不会出现在企业租户的授权范围内，勾了也无法使用。

## 4.6 运营必备手法：如何给「任意机构」建账号

由于用户创建归属**当前登录会话的机构**，平台运营在跨机构排障时可用这个手法：

1. 用 **该机构的企业编码 + `superAdmin` + 超级管理员密码** 登录；
2. 此时会话数据空间即该机构，可正常新增其部门、角色、用户、标签、岗位；
3. 处理完后退出，换回自己的常用登录。

> ⚠️ 该手法同样适用于**为监管平台机构（`REGULATOR`）建立首批账号**：监管平台租户由系统初始化创建，**初始没有账号**，需由平台方按上述方式为其建立管理员与角色后，监管人员才能登录。

## 5. 企业业务全流程

> **本章主角**：机构管理员、培训教师。
> **一句话主线**：备素材 → 做课程 → 发课程 → 开课报名 → 学员学习 → 建题库/试卷/考试 → 批阅发成绩 → 组培训计划 → 线下执行 → 出综合成绩 → 发证书 → 归档 → 供监管查看。

### 5.0 全流程地图

```
【资源】 素材库 ──┐
                  ├─→【课程】课程分类→课程→章节/内容项→发布版本→开课→指派/开放报名→学习监控
【题库】题库中心 ─┤
       试卷管理 ──┘        └─→【考试】考试→人员配置→发布→学员作答→批阅→发布成绩→补考
【培训】培训类型→培训标准→培训模板→评价表单→培训计划→参训人→发布→执行→线下成绩→奖惩→综合成绩→结果
【结果】证书模板→签发规则→已签发证书 ／ 培训档案（一期/企业/个人三视角） ／ 问卷
【监管】汇聚培训/学习/成绩/档案 → 学时预警 → 只读下钻
```

> 💡 各模块相对独立又互相引用：课程内容项可引用题库练习与试卷；培训计划可引用课程、考试、题库练习与线下活动。

## 5.1 素材库（一切课程资源的基础）

**菜单路径**：应用中心 → 素材库
**页面地址**：`/admin/business-center/resource-library`

| 步骤 | 操作 |
|---|---|
| 1 | 进入素材库，可先按 素材名称/素材类型/处理状态/启停状态 筛选 |
| 2 | 点击「**新增素材**」 |
| 3 | 填写素材编码、素材名称、**素材类型**、**素材来源**（类型与来源强绑定） |
| 4 | 上传文件（支持拖拽；大文件自动分片，可暂停/继续/重试/取消） |
| 5 | 保存后等待转码；处理中状态每 3 秒自动刷新 |
| 6 | 转码成功后「预览」检查效果；失败可点「重试转码」 |

**类型与来源对应关系**（必须匹配）：

| 素材类型 | 允许来源 | 说明 |
|---|---|---|
| 文档 DOCUMENT / 图片 IMAGE / 音频 AUDIO / 视频 VIDEO | 上传 UPLOAD | 需转码 |
| 富文本 RICH_TEXT | 创建 CREATED | 在线编辑 |
| 外链 LINK / 直播 LIVE | 外部 EXTERNAL | 引用外部地址 |

**上传限制**：音视频单文件 ≤ 2GB，文档 ≤ 512MB，图片 ≤ 16MB；≥10MB 自动走分片上传（支持断点续传）。

**处理状态**：`UPLOADED 已上传 → PROCESSING 处理中 → SUCCEEDED 成功 / FAILED 失败`

> ⚠️ **只有转码成功的素材才能用于课程内容**。素材被课程/题目引用后，只能"停用"不能删除。
> ⚠️ 旧版 DOC 或含 VML 的旧 DOCX 需先转成标准 DOCX/PDF 再上传。
> ⚠️ 上传完成后**不能再更换素材类型**。

## 5.2 课程管理（分类 → 课程 → 编排 → 发布 → 开课）

### 5.2.1 课程分类

**菜单路径**：应用中心 → 课程管理 → 课程分类 ｜ **地址**：`/admin/business-center/course/classify`
操作：新增课程分类 / 新增下级 / 编辑 / 移动 / 删除。字段：上级分类（必填）、分类名称（必填）、描述、排序、状态。

### 5.2.2 课程中心与课程工作台

**菜单路径**：应用中心 → 课程管理 → 课程中心 ｜ **地址**：`/admin/business-center/course/center`

课程中心是一个**四阶段工作台**，通过行操作按钮进入对应阶段：

| 行按钮 | 阶段 | 作用 |
|---|---|---|
| 详情编辑 | 基础信息 | 课程编码/名称/封面/学分/学习规则等 |
| 内容编排 | 内容编排 | 章节与内容项 |
| 发布版本 | 发布版本 | 生成不可变版本 |
| 开课配置 | 开课配置 | 创建开课、报名、学习监控 |
| 删除 | — | 删除课程 |

**阶段一 · 基础信息**（必填：课程编码、课程名称、内容模式、学分）

其他字段：封面（JPG/PNG/WebP ≤10MB）、课程简介、教学目标、课程大纲、考核方式、积分模式/分值、可下载规则、是否允许倍速、是否开启学习防作弊、是否显示学习说明、是否加水印、启用状态、课程分类。

> ⚠️ 课程一旦创建，**课程编码与内容模式不可修改**。

**阶段二 · 内容编排**

- 章节：章节名称、排序、状态，可增删改。
- 内容项类型（**仅 4 种**）：

| 内容项类型 | 说明 | 可选资源 |
|---|---|---|
| 素材 ASSET | 学习素材 | 仅可选**转码成功**的素材；要求学习时长必须 > 0 |
| 直播 LIVE | 直播场次 | 需完整填写场次信息，指定讲师 |
| 题库练习 QUESTION_BANK | 练习 | 仅可选**已发布且启用**的题库 |
| 课程测验 QUIZ | 测验 | 仅可选**已发布**的试卷版本 |

- 「课程附件（学员可下载）」：可挂文档/图片/音视频/富文本/外链供学员下载。
- 「参与后锁定」仅对题库练习与课程测验生效。

> 💡 常见校验提示：「请输入内容标题」「请选择课程素材」「要求学习时长必须大于 0」「请选择已发布题库」「请选择已发布试卷版本」「请完整填写直播场次信息」。

**阶段三 · 发布版本**

| 步骤 | 操作 |
|---|---|
| 1 | 系统自动做发布前检查（基础信息 / 课程内容 / 课程附件） |
| 2 | 可选填版本说明 |
| 3 | 点击「**发布当前草稿**」→ 生成不可变版本快照 |
| 4 | 如需下线，点「下线课程」 |

> ⚠️ **课程没有任何章节或内容项时无法发布**（发布按钮不可用）。
> ⚠️ 发布生成的是**不可变快照**；之后修改草稿再发布会产生**新版本**，不影响已发布版本。
> 状态：`DRAFT 草稿 → PUBLISHED 已发布 → OFFLINE 已下线`

### 5.2.3 开课配置与报名

**阶段四 · 开课配置**（进入方式：课程中心 → 某课程 → 「开课配置」）

| 步骤 | 操作 |
|---|---|
| 1 | 点击「新增开课」 |
| 2 | 填写开课信息（下表） |
| 3 | 「保存草稿」→ 提示"开课草稿已保存" |
| 4 | 若含课程测验，先在「考核管理」中配置**阅卷人** |
| 5 | 点击「发布开课」→ 提示"开课已发布"；指派报名的开课会同步完成学员指派 |

新增开课字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| 开课编码 | **是** | ≤64 字符 |
| 课程 | **是** | 选择已发布版本的课程 |
| 开课名称 | **是** | ≤150 字符 |
| 开课时间 | 是 | 起止时间，结束必须晚于开始 |
| 课程类型 | **是** | 必修 / 选修 |
| 报名方式 | **是** | **指派报名**（由管理员指派）/ **开放报名**（学员自主选课） |
| 完成规则 | 否 | 完成全部必修内容（默认）/ 完成全部内容 |
| 报名资格 | 开放报名时 | 全部人员 / 指定人员 |
| 创建后指派学员 | 指派报名时 | 选择需要指派的学员 |

开课状态与操作：

| 状态 | 可执行操作 |
|---|---|
| 草稿 DRAFT | 发布开课、删除、查看 |
| 已发布 PUBLISHED | 取消、结束、报名名单、考核管理、查看 |
| 已结束 ENDED / 已取消 CANCELLED | 查看 |

> ⚠️ 含课程测验的开课，**必须先配置阅卷人才能发布**，否则提示"请先为课程测验配置阅卷人"。
> ⚠️ 课程尚未生成发布版本时不能创建开课。
> ⚠️ 所有发布/取消/结束/删除操作都会二次确认。

**报名名单**（开课 → 「报名名单」）：

- 仅「已发布 + 指派报名」的开课可「选择学员并指派」；
- 列表展示：账号、姓名、报名来源（管理员指派/自主报名/导入/培训计划）、学习状态、进度%、学习秒数；
- 可「移除」报名（⚠️ 已完成 COMPLETED 的学员不可移除）。

**学习监控**（报名名单 → 「学习详情」）：

- 学员进度环、累计学习时长、获得学分；
- **分项进度表**：各内容项状态（未开始/学习中/已完成/未通过）、学习秒数、最近位置、作答次数等；
- **最近学习会话表**：学习设备（PC/APP/H5）、有效秒数、结束原因（完成/主动退出/离开页面/超时/异常）；
- 学员对课程的**评价**（评分 + 内容）。

## 5.3 考试管理（题库 → 试卷 → 考试 → 批阅 → 成绩）

### 5.3.1 题库中心

**菜单路径**：应用中心 → 考试管理 → 题库中心 ｜ **地址**：`/admin/business-center/exams/question`

题库中心为**三层结构：知识点 / 题库 / 题目**。

| 步骤 | 操作 |
|---|---|
| 1 | 维护「知识点树」（知识点编码、名称必填） |
| 2 | 「新增题库」（题库名称必填；题库编码仅新增时填） |
| 3 | 可选「批量导入」——**上传 JSON 数组文件**导入题目 |
| 4 | 「新增题目」→ 填写所属题库、题目编码、题干、题型 |
| 5 | 题目详情页可关联题干素材（本地上传 / 从素材库选择） |
| 6 | 「保存草稿」→ 检查无误后「发布版本」 |

**题型**（5 种）：单选题、多选题、判断题、填空题、简答题。

| 题型 | 录入要点 |
|---|---|
| 单选 / 多选 / 判断 | 需完整录入选项与正确答案 |
| 填空题 | 至少一个答案（多空逐空作答） |
| 简答题 | 自动判分需关键词；人工判分需评分参考 |

> ⚠️ 题目**版本化**：发布后所有字段只读；再次修改需「创建新草稿」，编辑产生**新版本**，旧版本保留。
> 状态：`DRAFT 草稿 → PUBLISHED 已发布 → ARCHIVED 已归档`

### 5.3.2 试卷管理

**菜单路径**：应用中心 → 考试管理 → 试卷管理 ｜ **地址**：`/admin/business-center/exams/paper`

工作台三阶段：**基础信息 → 组卷配置 → 发布确认**。

| 步骤 | 操作 |
|---|---|
| 1 | 「新增试卷」，填写试卷编码、试卷名称（必填）、组卷类型、分类、启用状态 |
| 2 | 进入「组卷配置」：填考试时长、及格比例、题目顺序、多选题计分、随机种子 |
| 3 | 组卷：固定卷逐题选入并设分值/排序；随机/自定义卷配置**抽题规则**（题库、题型、难度、知识点、抽题数量、每题分值、权重） |
| 4 | 选题目弹窗支持按分类/题库/关键字筛选，「全选当前列表」「添加已选题目」 |
| 5 | 「发布确认」→ 核对题目数/总分/及格分 → 「确认发布版本」 |

**组卷方式**：固定试卷 / 随机试卷 / 自定义试卷。

> ⚠️ 已在试卷中的题目**不可重复选**。
> ⚠️ 校验提示：「请为抽题规则 N 选择题库」「请先添加试卷题目」「请先新增随机抽题规则」。
> ⚠️ 发布后固定当前题目版本，**后续对题库的修改不影响该试卷版本**；版本页只读。

### 5.3.3 考试管理

**菜单路径**：应用中心 → 考试管理 → 考试管理 ｜ **地址**：`/admin/business-center/exams/exam`

工作台四阶段：**基础信息 → 人员配置 → 发布 → 考试情况**。

| 步骤 | 操作 |
|---|---|
| 1 | 「新增考试」，填写考试编码、名称、**考试类型**、学分、启用状态 |
| 2 | 绑定**已发布试卷版本**（选择后自动带入时长、及格比例、及格分、题目顺序、多选计分） |
| 3 | 配置考试策略与防作弊 |
| 4 | 「人员配置」：选择考生范围（全部/部门/指定人员）与**批阅人** → 「保存人员配置」 |
| 5 | 「发布考试」→ 核对检查清单后确认发布（**发布后考试锁定**） |
| 6 | 学员作答后，在「考试情况」中查看/批阅/处置成绩 |

**考试类型**：线上考试 `ONLINE` / 线下考试 `OFFLINE` / 专项练习 `SPECIAL_PRACTICE` / 题库练习 `BANK_PRACTICE`。

**考试策略（要点）**：
- 端限制：是否允许 PC / APP / H5；
- 可见性：是否展示解析、是否展示成绩；
- 补考：是否允许补考、最大次数、补考范围（仅不及格 / 不及格或未参加 / 仅未参加）、补考时间窗、成绩取值（最高分 / 最近一次）；
- 答案详情可见时机：交卷后可见 / 成绩发布后可见 / 始终不可见；
- 防作弊：是否开启防作弊、是否加水印。

**人员配置与发布**：
- 考生范围：全部人员 / 按部门 / 指定人员（保存时逐人展开为考生事实）；
- 批阅人：线上考试与专项练习**必须配置批阅人**才能发布；
- 发布按钮不可用的条件：无考生 / 需批阅人但未配置 / 抽题规则缺失；
- 题库练习须配置抽题规则（至少一条，且候选题量足够、范围不重叠）。

**考试情况（考试后处理）**：

| 功能 | 说明 |
|---|---|
| 录入线下成绩 | 针对线下考试，逐人录入 0～满分成绩 |
| 批阅试卷 | 客观题自动判分；主观题人工评分（支持满分/半分/0 分快捷评分） |
| 查看与处置 | 查看作答与得分、开补考、**发布正式成绩** |

> ⚠️ **成绩发布后才更新候选人正式结果**，并触发后续（积分/证书/消息）。
> ⚠️ 正式成绩已发布后，作答**不可再批阅或改分**。
> ⚠️ 补考是**新的作答尝试**（次数递增），需满足补考资格。

**批阅 / 成绩相关状态**：

| 维度 | 取值 |
|---|---|
| 批阅状态 | 待批阅 / 待人工批阅 / 自动判分完成 / 人工批阅完成 |
| 成绩发布状态 | 未发布 / 已发布 / 已生效 |
| 考生状态 | 待考试 / 未开始 / 进行中 / 已交卷 / 待批阅 / 待发布成绩 等 |

**跨考试的批阅与成绩入口**（菜单为「成绩批阅」「成绩管理」，其入口权限由考试管理内的按钮权限控制）：

| 页面 | 地址 |
|---|---|
| 成绩批阅 | `/admin/business-center/exams/review` |
| 成绩管理 | `/admin/business-center/exams/results` |

### 5.3.4 学员作答（简述）

学员在**门户/移动端**（非管理端）完成开考、作答、交卷：先看「考试须知」，再作答（含倒计时、答题卡、暂存答案），交卷后等待批阅与成绩发布。管理端只做监控与处置。

## 5.4 培训管理（类型 → 标准 → 模板 → 评价表单 → 计划 → 执行 → 结果）

### 5.4.1 培训类型（学时"尺子"）

**菜单路径**：应用中心 → 培训管理 → 培训类型 ｜ **地址**：`/admin/business-center/training/type`

| 字段 | 说明 |
|---|---|
| 类型编码 / 类型名称 | 必填；编码编辑时不可改 |
| 适用工种 | |
| 初培最低学时 / 复审最低学时 | 必填，最小值 1 |
| 线上学时占比上限 | 填百分数（如 30 表示线上最多占 30%） |
| 类型标签 / 类型图片 / 状态 / 说明 | 图片上传需文件上传权限 |

> 💡 培训类型规定了**初培/复审的最低学时与线上占比上限**，是后续培训计划学时校验的基准。

### 5.4.2 培训标准（可加严的检查口径）

**菜单路径**：应用中心 → 培训管理 → 培训标准 ｜ **地址**：`/admin/business-center/training/standard`

工作台三步：**基础信息 → 规则编排 → 发布确认**。

- 基础信息：标准编码（新建可编辑）、标准名称、标准版本、**培训类型**、默认带入学时、有效期。
- 规则类型：总学时 / 线上学时占比 / 指定课程 / 指定考试 / 线下培训。
- 规则校验：总学时与线上占比**各只能一条**；线上占比 ≤ 100%；指定课程/考试必须选资源。

> ⚠️ 标准只能**加严**不能降低培训类型基线。
> 状态：`DRAFT → PUBLISHED → ARCHIVED`；发布后规则只读。
> 错误码提示：`8016` 重复基础规则、`8018` 线上占比超上限。

### 5.4.3 培训模板（可复用的计划方案）

**菜单路径**：应用中心 → 培训管理 → 培训模板 ｜ **地址**：`/admin/business-center/training/template`

- 左侧**模板分类**树（新增子级/编辑/删除），右侧模板列表。
- 工作台三步：**基础信息 → 阶段内容 → 发布确认**。
- 阶段类型：线上 / 线下 / 混合；内容类型：课程 / 考试 / 题库练习 / 线下活动。

> ⚠️ 模板只是创建计划的输入，引用后**复制**生成计划，不回写模板。
> 状态：`DRAFT → PUBLISHED → ARCHIVED`。

### 5.4.4 评价表单（综合成绩与专家检查的计算口径）

**菜单路径**：应用中心 → 培训管理 → 评价表单 ｜ **地址**：`/admin/business-center/training/evaluation-form`

- 表单类型：**综合评价** `COMPOSITE` / **专家检查** `EXPERT_INSPECTION`。
- 项目类型：分数项 / 文本项 / 选择项。
- 计算方式：权重折算 / 加减分调整。
- 成绩来源：课程成绩 / 考试成绩 / 线下成绩 / 奖惩记录 / 人工录入。

> ⚠️ 综合评价**只允许权重折算**，且来源限「课程 / 考试 / 线下」三类。
> ⚠️ 专家检查总分固定 100，只允许分数项与文本项，且**不参与综合成绩**（只生成现场检查记录）。
> 状态：`DRAFT → PUBLISHED → ARCHIVED`；发布后生成不可变版本，调整需**新版本**。

### 5.4.5 培训计划（业务主线核心）

**菜单路径**：应用中心 → 培训管理 → 培训计划 ｜ **地址**：`/admin/business-center/training/plan`

工作台**五步**：**基本信息 → 阶段与内容 → 评价表单 → 人员与执行 → 过程与结果**。

| 步骤 | 关键操作 |
|---|---|
| 1 基本信息 | 计划编码（创建后不可改）、计划名称、**培训类型**、**培训性质（初培/复审）**、培训标准、培训模板、计划负责人、培训时间、培训地点、说明。保存后可"下一步" |
| 2 阶段与内容 | 编排阶段（名称/类型/要求学时），向阶段添加内容（课程/考试/题库练习/线下）；为每个内容配置**执行参数** |
| 3 评价表单 | 绑定已发布的**综合评价**表单版本；可绑定**专家检查**表 |
| 4 人员与执行 | 选择参训人员 → 发布预检并发布 → 生成执行 → 开始计划 → 同步结果 → 结束 |
| 5 过程与结果 | 记录奖惩、培训资料；查看执行状态与个人分项结果 |

**内容执行参数（要点）**：

| 内容类型 | 必填配置 |
|---|---|
| 课程 COURSE | 完成规则：完成全部必修项 / 完成全部内容项 |
| 考试 EXAM | 考试模式：测验 QUIZ / 正式考试 FORMAL_EXAM |
| 题库练习 QUESTION_BANK | 练习时长（默认 30 分钟）、最大作答次数（默认 3）、抽题规则 |
| 线下 OFFLINE | 授课教师、培训地点、授课时间、及格分数（默认 60） |

**计划生命周期与操作**：

| 操作 | 前提 | 说明 |
|---|---|---|
| 发布预检并发布 | 草稿 + 已配置参训人 | 预检通过后发布；发布后**冻结培训性质与适用最低学时**，参训名单只读 |
| 生成执行 / 安排培训内容 | 已发布 | 为各内容生成执行实例（开课/考试/线下场次） |
| 开始计划 | 已发布 + 全部内容已安排 | |
| 结束培训并确认结果 | 执行中 | 有阻塞项时不可结束；结束后冻结最终结果 |
| 取消计划 | 草稿/已发布 | |

**发布预检常见拦截（错误码）**：

| 错误码 | 含义 |
|---|---|
| `8115` | 考试没有可用的冻结试卷版本 |
| `8121` | 线上内容占比超过允许上限 |
| `8156` | 缺少培训标准指定的课程/考试/线下内容 |
| `8157` | 所选模板未发布、类型不一致或不属于当前机构 |
| `8158` | 仅草稿计划可从模板覆盖复制课表 |

**参训人员**：
- 「选择参训人员范围」支持 全部人员 / 按部门 / 指定人员；
- ⚠️ **发布前必须至少配置一名具体参训人**，否则无法发布；
- 发布后参训名单只读。

**过程与结果（奖惩 / 资料）**：
- ⚠️ **仅"执行中 RUNNING"的计划可写入**奖惩与培训资料；其他状态一律只读。
- 奖惩字段：类型（奖励/处罚）、标题（必填）、说明、分数变动、发生日期、佐证文件、状态。
- 培训资料字段：资料类型（一般资料/图片/视频/评价佐证）、名称（必填）、说明、关联阶段、文件、排序、状态。

**综合成绩与结果**：

| 概念 | 说明 |
|---|---|
| 分项成绩 | 课程成绩 / 考试成绩 / 线下成绩；**只有计划中标记"计入综合成绩"的内容才纳入汇总** |
| 题库练习 | **固定不参与综合成绩**，只提供反馈 |
| 综合成绩 | 按绑定的综合评价表单规则计算，生成不可变批次；只有"已确认+正式"的批次是最终结果 |
| 培训结果 | 合格 `PASSED` / 不合格 `FAILED` / 结果待补全 `INCOMPLETE` |

> ⚠️ 明细里出现成绩 ≠ 一定纳入综合成绩；课程未完成时课程成绩保持"尚未产生"。
> 💡 培训成果页（`培训计划 → 已结束计划 → 培训成果`）展示：参训人数、通过/未通过、结果待补全、通过率、平均综合分，以及逐人分项成绩与本期奖惩。

### 5.4.6 教学任务（教师端）

| 6 | 查看统计（匿名问卷仅展示脱敏数据） |

**问卷用途**：线下培训调查 / 培训机构评价。
**结果可见**：仅管理员 / 提交后本人可见。

> ⚠️ 问卷投放后内容**冻结只读**；调整需「复制为新草稿」。
> ⚠️ 已投放的问卷不可删除。

# 6. 学员使用手册

> **主角**：被分配了课程/考试/培训任务的学员。学员**不使用管理端**，只在**门户**（PC）与**移动端**操作。

## 6.2 我的课程（学习中心）

**PC 地址**：`/portal/class` ｜ **移动端**：学习 tab

| 步骤 | 操作 |

# 8. 常见问题与注意事项

## 8.1 账号与登录

| 现象 | 原因与处理 |
|---|---|
| 登录提示"企业编码、账号或密码错误" | 系统**不区分**具体错项。依次核对：企业编码是否写对（如 `DEMO`）、工号是否正确、密码是否正确、机构是否被停用 |
| 机构用户突然都无法登录 | 检查该机构在机构管理里是否被**停用**（停用后全部用户不可登录） |
| 新建用户后登录不了 | 确认用户是否被设为"停用"；确认用**正确的企业编码**登录（不是管理端的编码） |
| 忘记密码 | 管理员在「用户管理」中「重置密码」；`superAdmin` 密码修改途径需与实施方确认 |
| 提示"账号已被禁用" | 该用户状态为停用，需编辑改为正常 |

## 8.2 权限与菜单

| 现象 | 原因与处理 |
|---|---|
| 某菜单看不到 | 角色未勾选该菜单权限；或该模块按会话机构类型被收敛（如企业会话看不到监管平台） |
| 改了角色权限不生效 | 菜单即时生效；权限缓存约 30 分钟内失效，紧急情况下请运维清理该用户权限缓存 |
| 企业管理员找不到"机构管理" | **设计如此**，企业管理员无权维护机构，只有 `superAdmin`/监管租户可维护 |
| 学员看到了后台菜单 | 学员角色被误配后台权限，请在角色管理中修正 |
| 按钮点不了/提示 403 | 前端按钮显隐由权限控制，真实鉴权在后端；确认账号是否被授予对应按钮权限 |

## 8.3 业务操作

| 现象 | 原因与处理 |
|---|---|
| 课程无法发布 | 课程没有章节或内容项 |
| 素材无法用于课程 | 素材仍在转码中或转码失败；等待成功或点「重试转码」 |
| 开课无法发布 | 含课程测验但未配置阅卷人；或课程未生成发布版本 |
| 考试无法发布 | 无考生 / 需批阅人但未配置 / 抽题规则缺失 |
| 无法录入线下成绩 | 计划不是"执行中"状态（仅 RUNNING 可写奖惩与资料）；或场次状态不允许录分 |
| 培训计划发布失败 | 按错误码处理：`8115/8121/8156/8157/8158`（见 §5.4.5） |
| 成绩看不到 | 成绩尚未发布；或该考试设置为不展示成绩；答案详情可能设置为"发布后可见" |
| 档案无法下载 | 归档事实有缺项（`missingItems` 非空），需补齐数据后再更新档案 |
| 有效期/统计对不上 | 历史计划按**发布时冻结**的口径计算，不随当前配置变化 |

## 8.4 运营注意事项（务必告知使用者）

1. **一个机构一套数据空间**：跨机构数据不可见、不可授权；平台运营跨机构操作需按 §4.6 切换登录。
2. **发布即冻结**：课程版本、试卷版本、评价表单版本、培训标准、培训计划发布后都会冻结，修改需产生新版本；这是审计与可追溯的基础设计，不要试图绕过。
3. **机构编码、工号、课程编码等"编码类"字段创建后基本不可改**，建前请核对命名。
4. **不要用 admin/superAdmin 演示账号做正式业务**。
5. **密码是单向哈希存储、物理不可读**，只能重置、不能找回。
6. **删除多为逻辑删除或受引用保护**：被引用的素材只能停用；已投放问卷不可删除；部分删除不可恢复。
7. **数据类变更不会自动刷新权限缓存**，涉及菜单/权限的调整请知会运维。
