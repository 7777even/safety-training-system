# 考试补考管理与成绩状态展示复盘

## 做得好的地方

- 全程复用现有 OpenAPI 和 API 封装，未新增接口、权限或后端字段。
- 补考操作使用稳定的幂等令牌，失败重试不会因为前端重复点击而创建多次作答。
- 将状态映射集中在考试字典中，避免成绩处置页继续直接显示英文枚举。

## 发现的问题

- 单次作答详情缺少用于前端完整预判补考资格的次数、窗口和考生状态聚合事实。
- 测试目录未配置 Node 全局变量的 ESLint 环境，不能直接对 Node 测试文件执行现有 lint 规则。

## 改进措施

- 在不扩展契约的前提下，页面只按补考开关、考生标识和权限显示入口，资格由接口最终判断并返回业务提示。
- 后续若统一治理测试 lint，应在全局 ESLint 配置中显式为 `tests/**/*.mjs` 声明 Node 环境；本次不扩大修改范围。
