# Retro：M2 前端 Task 5

- 课程考试项必须同时以 `examId` 和已发布状态约束，不能只依赖前端隐藏草稿。
- 真实联调时需验证课程考试启动后任务的 `examTaskStatus`、成绩发布与完成态刷新。

- 通用考试启动与课程考试启动应共享“返回作答快照、按快照路由”的契约断言，避免接口从 ID 升级为对象后只修复其中一个终端。
- 仅实现批阅/处置详情页不能形成角色工作流；Contract 提供列表接口后，应同时核验“任务列表→详情操作→学员结果”的可发现入口。
- 幂等令牌和动作级权限属于真实接口切换前必须静态核验的 Contract 要素，不能只比较 URL、Method 和请求体。
