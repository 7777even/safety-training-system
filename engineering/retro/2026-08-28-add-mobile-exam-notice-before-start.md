# 复盘：移动端正式考试考前须知与单向开考

日期：2026-08-28

## 做得好的地方

- 复用 PC 已稳定的详情与开考 Contract，仅在移动端增加窄屏须知布局和单向页面跳转，未扩张后端范围。
- 将开考调用从列表点击移至学员明确点击“开始答题”之后，避免仅浏览任务就创建正式作答。
- 使用 `redirectTo` 清除须知页返回栈，使正式开考后不能回到须知重复触发开考。

## 注意事项

- 考试详情的 `passRatio` 是小数比例，移动端 Mock 与总分反推必须保持 `0.6` 这类 Contract 语义。
- 复用管理详情接口前必须核验学员角色已有 `exam:exam:list` 权限；若未来调整授权，应单独提供受控的学员须知读取接口。
