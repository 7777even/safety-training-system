# M2 前端 OpenAPI 回读闭环复盘

## 有效做法

- 以公开 API 请求映射、Mock 状态回读和独立页面行为作为 TDD 边界，先观察失败再补实现。
- 对版本序号与版本主键分别建模，避免页面继续依赖偶然相同的数值。
- 对新增读取面同时补真实请求、Mock、页面和测试，保证后续只需切换 `VITE_USE_API_MOCK=false`。

## 问题与原因

- 早期 Contract 缺少版本列表、策略和批阅人读取面，前端曾记录保守降级方案；Contract 补全后旧假设未自动失效。
- `course.openapi.json` 存在错误响应悬空引用，普通 JSON 解析无法发现，必须执行 `$ref` 遍历检查。

## 后续改进

- 每次 OpenAPI 更新后执行字段、路径、示例和 `$ref` 四类检查，并复跑对应请求映射测试。
- Task 6 真实联调时重点验证候选人分页、试卷版本 ID、策略更新、批阅人回显和两类审计流水。
