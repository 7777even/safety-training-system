# M3 培训工作台 UI 统一 Retro

## 做得好

- 保持父页面持有真实 API、权限和版本状态，仅抽离步骤视觉容器，避免 UI 重整影响培训生命周期。
- 以工作台结构回归测试覆盖四个页面与私有步骤组件的统一约束，并检查父工作台不再传递步骤子模板。
- 在模板分类按钮迁移时通过测试发现权限传递遗漏，已恢复新增、编辑、删除三项独立权限控制。
- 返工后将“workspace 单一 surface、步骤组件单一 card”写入长期 UI 标准，并由结构测试锁定，避免仅有 class 名而产生嵌套工作区的视觉偏差。

## 后续改进

- 后续真实登录态环境应补充四个工作台的视觉与操作栏可见性验收。
- 组件抽离后须同时检查父页的事件、权限和表单校验责任，不能只以组件不声明 `<slot>` 作为迁移完成依据。
