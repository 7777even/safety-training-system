## 二、逐项操作与判据

### 53 学员分类与用户组（人员分类 / 特征）
1. `DEMO/admin` → 人员分类与用户组 → 新建用户组：条件里**同时**放 性别=男、某部门、某岗位、关键词、培训完成状态，点预览。
   - 判据：同一字段**多值取并集**、不同字段**取交集**；缺该属性的人**不命中**；培训完成类事实**只读**，与手工填写的说明区分。
2. 用该组把人员绑定到培训 / 考试（下发），记下名单；回组里**加/减成员**，再次预览。
   - 判据：预览人数变化，但**已绑定 / 已下发名单不自动增删**；重复绑定不产生重复记录；**空组、跨机构被拒**。
3. 用户管理 → 某用户 → 人员特征维护 → 填出生日期 / 属性并保存，回读。
   - 判据：静态特征可维护并可读回；越权 / 跨机构保存被拒。

### 71 岗位培训矩阵
1. 岗位培训矩阵页维护「岗位 → 课程 + 发布版本 + 内容 + 学时」；对**多个岗位**用**相同资源版本**保存。
   - 判据：合并同一资源时**取最大学时**；来源与课件**随课程版本冻结**（之后改课程版本不影响已建矩阵）。
2. 由矩阵**创建人工计划草稿**。
   - 判据：只生成**草稿**，**不自动发布**，需管理员后续补齐。

### 72 年度计划、审批、下发与提醒
1. 年度培训计划页：上传年度文件并**关联**到计划。用 `admin` 提交、`m4-expert-01` 审批 → 驳回 → 重提 → 批准。
   - 判据：**待审期间禁止编辑草稿 / 名单**（8331）；**批准只对当前版本生效**（8332）；修改后必须**重新审批**；**不能自己批自己**（8337）；驳回**必须填意见**（8338）。
2. 年度文件批准后受控下载、依据冻结。
   - 判据：已批准版本的年度依据不被后续编辑影响。
3. **计划变更申请**：对**无执行安排**的已发布计划发起完整变更，查看「原计划 / 原名单 + 拟修改」，再批准或驳回。
   - 判据：批准前原计划仍有效；提交即**冻结人员 / 年度依据**；批准**原子生效**；旧版本不得覆盖，失败时原计划恢复。
4. **事实保护**：对**已生成执行安排**的计划申请完整变更。
   - 判据：**8351 明确拒绝**完整变更；运行中只允许改 名称 / 负责人 / 地点 / 说明；学习 / 作答 / 成绩不变；终态拒绝。

### 73 培训任务管理
1. 下发后转为培训任务；制造一次**部分失败再重试**；等安排就绪后点**开始**。
   - 判据：复用既有安排、**不重复生成**；无安排时**禁止开始（8162）**。
2. PC 门户 / H5 从**消息**或**培训中心**打开本人任务，看进度与课程记录。
   - 判据：统计对应**真实事实**。

### 85 考试人员与通知
1. 考试管理 → 新建考试 → **人员配置**：分别用「部门 / 岗位 / 用户组 / 姓名」选考生与评卷人，保存后回读。
   - 判据：展开结果**去重**、限定**当前租户启用**人员；评卷人**必须有阅卷权限**。
2. 改动**用户组成员**后，**只改评卷人**、不动考生。
   - 判据：**不重新展开旧考生组**，已绑考生不变；筛选出 0 人**不影响**已保存的实际人数。
3. **失败名单保护**：把评卷人分别设成 `operator01`（无 `exam:review`）/ `QA85DISABLED-*`（停用）/ `M5QA_TI_20260930/admin`（外机构）。
   - 判据：**全部拒绝（7070）且旧评卷名单保留**（整份校验后才写，不部分覆盖）；空用户组在人员选择层被 **4120** 拦；空固定名单可**明确清空**；来源与人员范围显示**中文**。
4. 发布考试 → 用 `operator01` 登录 H5 看消息。
   - 判据：实际考生收到「已为你安排学习任务」；重复发布 / 绑定**不重复投递**（事件键幂等）；进入 24h 窗口给**截止提醒**、已开考给**开放提醒**、已完成 / 已截止**不再提醒**；消息引用 `examCandidateId + examId` 且**不串考试**。
