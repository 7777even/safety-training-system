# 已确认设计

## 互斥模型（74）

服务端权威的单活跃学习会话：`sts_course_study_session` 增加 `device_id`（终端标识，客户端生成并持久化）与 `last_active_at`（心跳时间）。

- 心跳即现有 30 秒上报：同一 `(course_enrollment_id, client_trace_id)` 已存在时，由「仅插入」改为 upsert，更新 `ended_time`、`valid_study_seconds`、起止位置/页码、`end_reason` 与 `last_active_at`，保留首行 ID 与幂等语义。
- 新追踪标识首次落库前做互斥校验（活跃窗口 `ACTIVE_WINDOW=90` 秒，覆盖 3 个上报周期）：
  - 同一 `user_id` 存在其他活跃会话 → `409/5095`「该账户正在其他终端或培训内容中学习，请先结束」。
  - 同一 `device_id` 存在其他 `user_id` 的活跃会话 → `409/5096`「当前终端正在学习其他账户的内容」。
- 心跳过期（超过 90 秒无上报）视为会话非活跃，不阻塞新会话；页面关闭后最多 90 秒释放，账号切换存在可接受等待，如实记录为该模型已知取舍，不新增释放接口。
- 前端消费：PC/H5 学习页收到 5095/5096 时给出明确中文提示并暂停学习计时，不静默失败；同一终端同一账户的多标签页同样按 5095 拒绝（符合「同一账户多终端」原文语义）。
- web 终端标识为尽力而为检测（清除存储或隐私模式可绕过），不宣称为安全边界；PC/H5 各自生成并持久化，仅传标识不回传其他用户信息。

## 防挂机（74）

- 随机验证题即防挂机手段（与 75 原文同源）：学习页以 60～180 秒均匀随机间隔弹出轻量验证题（整数算术，60 秒作答时限），弹窗期间暂停有效学时累计（复用页面不可见/媒体暂停同一计时门控），答对恢复并重新随机调度；超时未答以既有 `endReason=TIMEOUT` 结束当前会话、停止计时并提示挂机判定。
- 验证题纯客户端门控，服务端不生成、不判定、不留痕，不新增接口；弹窗期间不上报有效秒数，从计时上消除挂机累计。
- 已有「页面不可见、媒体暂停不计有效学时」行为不回归。

## 随机水印（75）

- 水印文字优先员工编号：`userCode`（工号）回退 `userName`，再回退「学员」；仅调整学习页取值顺序，`watermark.ts` 工具函数保持兼容。
- 不定时不定位置：`shared` 新增随机变体生成（平铺相位、旋转角、字号、行锚点随机化），PC/H5 学习页以 45～90 秒随机间隔重建；课程快照 `isWatermarkEnabled` 开关语义不变；考试与课程作答页继续使用固定平铺水印，不随本批改变。
- 原文「水印或弹幕」为选择语义，本期实现随机化水印，不新增漂浮弹幕。
