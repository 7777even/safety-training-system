# Spec Delta：考试工作台的考试情况阶段

## ADDED Requirements

### Requirement：按考试查看学员作答与成绩情况

考试工作台必须提供当前考试范围内的作答记录查看能力，并固定以当前考试 ID 查询；页面必须显示学员、作答和交卷时间、用时、批阅状态、成绩与发布状态。

#### Scenario：管理员查看某场考试的考生情况

- **WHEN** 管理员打开已创建考试的“考试情况”阶段
- **THEN** 系统以该考试 ID 查询作答记录并展示分页结果

### Requirement：复用既有批阅和成绩处置流程

页面必须将单次作答跳转至既有批阅或成绩处置页面，且入口仅在用户已有相应权限时显示。

#### Scenario：批阅教师处理待批阅作答

- **WHEN** 具有批阅权限的用户查看待批阅作答
- **THEN** 系统提供批阅入口并跳转到既有教师批阅页

#### Scenario：成绩发布人员发布成绩

- **WHEN** 具有成绩发布权限的用户打开成绩处置
- **THEN** 系统沿用既有未完成批阅不可发布的校验与单次发布流程
