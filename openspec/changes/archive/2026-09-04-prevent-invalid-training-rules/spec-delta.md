# Spec Delta

## 新增需求：规则资源必须可执行

### Requirement: 指定考试只能选择可冻结版本

培训标准、培训模板和培训计划在配置考试内容或指定考试规则时，系统 MUST 只允许选择当前机构可用且存在可冻结试卷版本的考试；已发布但没有可冻结试卷版本的考试 MUST NOT 作为可选项。

#### Scenario: 选择指定考试

- Given 当前机构存在已发布考试和未形成可冻结试卷版本的考试
- When 管理员打开培训标准的指定考试选择项
- Then 只展示具备可冻结试卷版本的考试
- And 页面说明不可选考试的原因

## 新增需求：培训模块必填字段必须可识别

### Requirement: 所有培训表单显示必填标识

培训类型、培训标准、培训模板、培训计划、阶段与内容、内容执行配置、评价绑定、参训人员和线下执行相关表单 MUST 对所有实际必填字段显示统一的必填标识；条件必填字段 MUST 在条件成立后显示标识；标识与保存校验 MUST 使用同一字段规则。

#### Scenario: 用户填写培训表单

- Given 用户打开培训模块任一可编辑表单
- When 表单展示字段或用户切换规则类型、内容类型、培训性质
- Then 当前必填字段显示统一必填标识
- And 条件必填字段同步显示中文说明和中文校验提示
- And 系统自动生成字段、只读字段和结果字段不显示为用户必填输入项

#### Scenario: 用户保存不完整表单

- Given 用户未填写一个或多个必填字段
- When 用户点击保存、下一步或发布
- Then 系统阻止提交
- And 页面定位或明确指出缺失字段及填写方式

## 新增需求：阶段内容保存必须通过合规检查

### Requirement: 模板和计划保存前校验编排规则

培训模板或培训计划保存阶段内容时，系统 MUST 校验线上占比、有效总学时、标准指定资源覆盖和内容执行配置；校验不通过 MUST 阻止保存并给出可操作的中文提示。

#### Scenario: 线上占比超限

- Given 当前模板或计划的线上内容占比高于培训类型或标准允许的上限
- When 管理员保存阶段内容
- Then 阶段内容不得提交
- And 页面显示当前占比、允许上限以及降低线上占比的建议

#### Scenario: 缺少必需资源或执行配置

- Given 标准要求指定课程、考试或线下内容，或内容执行配置不完整
- When 管理员保存阶段内容
- Then 阶段内容不得提交
- And 页面指出缺少的规则或具体内容项

## 新增需求：发布预检问题可追溯

### Requirement: 预检问题回到可修复的编排位置

当发布预检仍返回问题时，系统 MUST 将问题转换为用户可理解的中文说明；存在 `planContentId` 时 MUST 显示对应内容名称并提供返回阶段内容的入口；不存在内容 ID 时 MUST 指出应检查的计划规则摘要。

#### Scenario: 发布预检返回 8115 或 8121

- Given 计划发布预检返回考试版本不可冻结或线上占比超限
- When 页面展示预检结果
- Then 页面显示对应内容/规则、当前值和调整建议
- And 管理员可以返回阶段内容修复后再次保存和预检
