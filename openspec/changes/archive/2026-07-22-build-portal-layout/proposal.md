# Proposal：搭建前台门户统一布局

## 背景

当前 `views/portal/index.vue` 同时承担门户顶层框架和首页内容。菜单现已补充“首页、课程中心、考试中心、培训中心、教学辅助”五个前台一级入口，若继续由同一页面承载固定首页内容，切换菜单后无法显示对应页面。

## 目标

- 将 `views/portal/index.vue` 调整为前台门户统一布局。
- 在门户内容区域通过嵌套 `RouterView` 承载已授权的前台菜单页面。
- 为菜单配置中的五个前台入口建立可解析、可访问的占位页面。

## 用户价值

学员可在统一的门户导航中切换五个前台入口；后续各业务能力可在独立页面中渐进实现，而不需要再次调整门户框架。

## 功能范围

- 保留现有品牌区、动态菜单导航、用户菜单、管理后台入口和退出登录行为。
- 将原门户首页展示内容迁移至 `portal/home/index.vue`。
- 新增课程中心、考试中心、培训中心、教学辅助四个最小占位页面。
- 门户布局的 `.portal-content` 使用 `RouterView` 渲染子页面。

## 非目标范围

- 不实现课程、考试、培训或教学辅助的业务功能。
- 不新增或修改 API、菜单接口、权限模型、数据库或后端初始化数据。
- 不修改菜单配置文本中已定义的路径、组件字段和排序。
