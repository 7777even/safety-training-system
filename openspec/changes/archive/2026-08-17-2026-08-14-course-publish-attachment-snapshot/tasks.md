# Tasks：课程发布检查与附件快照增强

## Task 1：保存课程附件名称到版本快照

- 状态：已完成
- Owner：fxw11
- 输入：课程附件关联、当前机构素材
- 输出：包含 `assetName` 的 `DownloadAssetSnapshot`
- 前后端影响：仅后端快照结构；前端读取历史快照展示
- API 依赖：现有课程发布和版本详情接口
- 数据影响：无数据库结构变化；新快照 JSON 增加字段
- 验收标准：发布生成的快照附件包含素材名称；旧快照无名称时仍可解析
- 测试方式：后端零 DB 单元测试

## Task 2：发布前检查展示课程附件

- 状态：已完成
- Owner：fxw11
- 输入：课程附件列表和素材详情
- 输出：发布前检查中的附件数量、名称、素材 ID、排序和状态
- 前后端影响：仅 PC 管理端
- API 依赖：现有课程附件查询、素材详情查询接口
- 数据影响：无
- 验收标准：有附件时展示明细；无附件时展示提示且不改变现有发布按钮规则
- 测试方式：前端定向测试、PC typecheck
