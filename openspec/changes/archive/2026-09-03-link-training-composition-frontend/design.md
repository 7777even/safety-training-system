# Design：串联培训编排前端工作台

## 1. 关联链

```text
培训类型（初培/复审学时、线上上限）
  └─ 培训标准（同一类型；总学时、线上比例、指定资源规则）
       └─ 培训模板（同一类型，且标准一致；阶段/内容编排）
            └─ 培训计划（选择来源后复制阶段，草稿内独立调整）
                 └─ 评价表单版本（已发布、用途匹配、来源可用提示）
```

类型是最低约束；标准只能增加约束；模板是可复用编排起点；计划是最终可发布的独立草稿。计划始终可不选标准或模板而手工编排。

## 2. 前端行为

1. 标准工作台根据所选类型展示初培、复审及线上上限；规则页汇总启用总学时、线上比例和指定资源。
2. 模板工作台仅加载当前类型下已发布标准；展示类型/标准摘要，按阶段和内容计算同一摘要和差异。
3. 计划类型变更时，若已有阶段，确认后清空标准、模板和阶段；标准变更时确认清空阶段；模板变更时确认读取模板详情并覆盖阶段。复制保留内容属性，阶段写入 `sourceTemplateStageId`，不保留模板阶段主键作为计划主键。
4. 计划页面仅显示当前类型标准；有标准时仅显示同类型且 `trainingStandardId` 一致的模板。阶段页展示来源、类型/标准约束、当前总学时、线上比例与指定资源命中情况。
5. 评价表单仍为通用资产。计划仅列出已发布版本；COMPOSITE 绑定可选择，EXPERT_INSPECTION 仅用于专家检查。读取版本详情后，将 COURSE、EXAM、OFFLINE、REWARD_PENALTY、MANUAL 来源与计划内容作提示，不伪造计算结论。
6. 计划内容行提供“执行配置”弹窗：课程维护完成规则，考试维护考试模式，题库练习维护时长、及格线、次数和抽题规则，线下培训维护教师、地点、授课时间、签到窗口、签退要求和及格线。弹窗确认后写回计划内容草稿，由既有阶段整体替换接口保存。

## 3. 契约边界与已知缺口

只调用既有详情、分页、阶段整体替换、预检和表单版本详情接口。前端无法保证：后端跨类型/标准/模板一致性、模板到计划的原子复制、标准指定资源的强制发布校验，以及表单规则来源的强制校验；这些事项不在本 Change 修改，保留为后端 L4 Change 候选。

## 4. 测试设计

测试 seam 为 PC 工作台的用户可见模板与已声明的 API 调用：

- 计划来源变化的确认、清空和模板复制；
- 类型/标准/模板筛选与摘要传递；
- 标准/模板/计划的合规摘要；
- 评价版本用途筛选和来源提示；
- 四类计划内容执行配置的必填提示、取消回滚和契约字段保存；
- 定向源码行为测试、typecheck、lint、build 和真实接口联调。
