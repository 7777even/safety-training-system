# 统一 PC Web 界面布局与列表风格

## 背景

当前门户、后台工作台和不同业务列表页存在布局、字体、间距、分页、表格高度及操作按钮风格差异。后台页面还保留独立的 page-header，缺少完整面包屑和可关闭的多页签，影响连续操作体验。

## 目标

- 以后台工作台为基准，统一 PC Web 门户和后台的基础视觉 token、间距、字体和内容区布局。
- 为后台提供可折叠侧栏、完整面包屑和 tabs-card 多页签导航。
- 为列表页提供可复用的双 Card 结构、固定表格滚动高度、统一分页器和操作栏样式。

## 用户价值

管理员在不同模块之间切换时可以保持一致的认知和操作习惯，长列表不会推动右侧主体页面产生长滚动条，常用页面可以通过多页签快速切换。

## 功能范围

- 后台布局：移除 `page-header`，增加面包屑、可折叠侧栏、tabs-card，并统一工作区高度和间距。
- 列表布局：筛选表单独立为第一个 `ElCard`；列表说明及新增、导入、导出按钮放在第二个 `ElCard` 的 `card-header`；表格在内容区内滚动；分页器统一使用 `total, sizes, prev, pager, next`。
- 列表高度：分页列表使用统一的可视高度 token；无分页树表使用更高的统一 token；两类高度写入全局常量并由列表页复用。
- 操作栏：除删除按钮使用 `danger` 外，其余操作按钮统一使用 `primary`，保持 link 形式。
- 门户与后台：统一背景、字体、控件尺寸、卡片边框和间距 token，不改变门户业务导航和页面内容。

## 非目标

- 不新增或修改后端 API、权限语义、数据库结构和业务规则。
- 不改动移动端页面。
- 不重写各业务页面的数据请求、表单校验或业务交互；只调整其通用布局接入和样式。

## 成功标准

- 后台任一已授权页面均不再渲染旧 `page-header`，且显示完整的菜单层级面包屑。
- 侧栏可在展开/折叠状态间切换，折叠后内容区自动扩展，刷新后状态保持。
- 已纳入本次整改的列表页符合双 Card、固定表格滚动区和统一分页器结构。
- 多页签能记录打开页面、激活当前页面、关闭当前页/其他页/全部页，并能点击切换。
- PC Web lint、typecheck、build 通过，差异不触及接口和权限代码。
