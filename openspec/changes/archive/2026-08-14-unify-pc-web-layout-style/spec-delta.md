# Spec Delta

## 新增：统一 PC Web 工作台壳层

- 后台页面必须显示由授权菜单生成的完整面包屑。
- 后台侧栏必须支持展开和折叠，折叠状态必须持久化于浏览器会话。
- 后台必须提供 tabs-card，记录用户在当前会话打开的页面并支持关闭与切换。
- 后台不得渲染旧的 `admin-page-header`。

## 新增：统一列表页结构

- 列表筛选表单必须独立位于第一个 `ElCard`。
- 列表标题和新增、导入、导出等操作必须位于第二个 `ElCard` 的 `card-header`。
- 分页列表必须使用固定表格高度，并在表格区域内滚动。
- 分页器必须使用 `total, sizes, prev, pager, next` layout，并提供统一页大小选项。
- 无分页树表必须使用独立的更高表格高度常量。
- 操作栏除删除外的按钮使用 `primary`，删除使用 `danger`。

## 约束：接口与权限不变

- 本 Change 不新增、删除或修改 API、权限标识、数据字段和数据库结构。

## 长期标准

- `docs/design/pc-web-ui-standard.md` 作为后续 PC Web 门户、后台页面和组件开发的 UI 标准来源。
