# Spec Delta：M2 读取面补齐与可重现事实

## ADDED Requirements

### Requirement: 随机试卷抽题结果可重现

系统 MUST 在生成随机试卷版本时持久化本次抽题使用的随机种子，并 MUST 在版本详情中返回该种子。
使用相同种子与相同抽题规则重新抽题 MUST 得到相同的题目集合。

#### Scenario: 随机卷组卷记录种子

- **GIVEN** 一份 `paperType=RANDOM` 的试卷
- **WHEN** 调用组卷接口并提供 `randomSeed`
- **THEN** 系统将该种子写入试卷版本
- **AND** 版本详情接口返回该 `randomSeed`

#### Scenario: 未提供种子时自行生成并记录

- **GIVEN** 一份 `paperType=RANDOM` 的试卷
- **WHEN** 调用组卷接口且未提供 `randomSeed`
- **THEN** 系统生成种子用于抽题
- **AND** 将实际使用的种子写入试卷版本，使结果仍可重现

#### Scenario: 历史版本无种子

- **GIVEN** 本能力上线前已生成的试卷版本
- **WHEN** 查询该版本详情
- **THEN** `randomSeed` 返回 `null`
- **AND** 系统不得为历史版本编造种子

### Requirement: 考试人员档案快照真实冻结

系统 MUST 在建立考试人员时冻结该人员的账号、姓名、机构、部门路径、工号和职务快照。
读取考试记录时 MUST 优先使用快照，快照缺失时才回退到当前用户数据。

#### Scenario: 建立考生时冻结档案

- **GIVEN** 一名机构成员被纳入考试人员
- **WHEN** 系统建立考试人员记录
- **THEN** 档案快照包含账号、姓名、机构、机构名称、部门路径、工号和职务
- **AND** 取不到的字段写入 `null` 而非省略该键

#### Scenario: 用户改名后历史记录不变

- **GIVEN** 某考生已完成考试且档案已冻结
- **WHEN** 该用户随后修改姓名
- **AND** 查询该场考试的作答记录或批阅任务
- **THEN** 返回的仍是考试当时冻结的姓名

### Requirement: 考试策略可回显

系统 MUST 在考试详情中返回该考试的防作弊、补考与成绩可见性策略。

#### Scenario: 详情返回策略

- **GIVEN** 一场已配置策略的考试
- **WHEN** 查询考试详情
- **THEN** 返回完整策略对象
- **AND** 字段与创建、更新时接受的策略字段一一对应

#### Scenario: 列表不返回策略

- **WHEN** 分页查询考试列表
- **THEN** 列表项不包含策略对象

### Requirement: 考试批阅人可读取

系统 MUST 提供按考试读取当前批阅人的接口，并返回可供展示的人员信息。

#### Scenario: 读取批阅人

- **GIVEN** 某考试已指派批阅人
- **WHEN** 具有考试查看权限的用户读取该考试批阅人
- **THEN** 返回批阅人用户 ID、姓名、账号、所属机构及分配来源

### Requirement: 试卷版本可枚举与完整回读

系统 MUST 提供按试卷枚举其版本的接口，并 MUST 在版本详情中返回抽题规则。

#### Scenario: 枚举试卷版本

- **WHEN** 按试卷查询版本列表
- **THEN** 返回各版本的 `paperVersionId`、`versionNo` 与发布状态
- **AND** 调用方可据此获取草稿版本的 `paperVersionId`

#### Scenario: 版本详情返回抽题规则

- **GIVEN** 一份随机试卷版本存在抽题规则
- **WHEN** 查询该版本详情
- **THEN** 返回题目列表、抽题规则、随机种子、抽题设置模式、计分与及格规则

### Requirement: 题目素材可回显

系统 MUST 在题目版本详情中返回该版本关联的素材。

#### Scenario: 详情返回素材

- **GIVEN** 某题目版本已关联素材
- **WHEN** 查询题目详情
- **THEN** 当前版本包含素材列表及其用途和排序

### Requirement: 题库与试卷支持服务端筛选

系统 MUST 支持按题目发布状态筛选题目分页，MUST 支持按「是否存在可用发布版本」筛选试卷分页。
筛选 MUST 在服务端完成，分页总数 MUST 与筛选条件一致。

#### Scenario: 按发布状态筛选题目

- **WHEN** 按 `publishedStatus=PUBLISHED` 查询题目分页
- **THEN** 只返回存在已发布版本的题目
- **AND** 分页总数只统计符合条件的题目

#### Scenario: 筛选有可用发布版本的试卷

- **WHEN** 按 `hasPublishedVersion=true` 查询试卷分页
- **THEN** 只返回存在已发布版本的试卷
- **AND** 分页总数只统计符合条件的试卷

### Requirement: 防作弊事件与成绩发布流水可读取

系统 MUST 提供按作答读取防作弊事件与成绩发布流水的接口。

#### Scenario: 读取防作弊事件

- **GIVEN** 某次作答已记录防作弊事件
- **WHEN** 具有作答查看权限的用户读取该作答的事件
- **THEN** 按时间返回事件列表

#### Scenario: 读取成绩发布流水

- **GIVEN** 某次作答已发布成绩
- **WHEN** 具有成绩发布权限的用户读取该作答的发布流水
- **THEN** 返回各次发布的操作人、时间与结果

## MODIFIED Requirements

### Requirement: 考试人员列表分页

考试人员列表 MUST 使用统一分页结构，并 MUST 返回可供展示的人员信息，不得只返回用户 ID。

#### Scenario: 分页查询考试人员

- **WHEN** 按考试查询人员
- **THEN** 使用 `pageNum` / `pageSize` 分页返回
- **AND** 支持按学员关键字、人员状态和机构筛选
- **AND** 每条记录包含姓名、账号、机构与部门信息

#### Scenario: 大规模考试不一次返回全部人员

- **GIVEN** 某考试人员数量超过单页容量
- **WHEN** 查询该考试人员
- **THEN** 系统按分页返回，不一次性返回全部记录
