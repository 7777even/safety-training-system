# Spec Delta：来源事实写入时自动刷新培训内容结果投影

完整场景见 `specs/training-execution-loop/spec.md`。

## ADDED Requirements

1. 培训绑定的课程学习状态变化、考试/题库开考交卷或成绩发布、线下签到确认与成绩保存，必须在同一事务按参训人+内容项刷新投影。
2. 不得要求先调用计划级结果同步才能看见内容项状态。
3. 独立开课/独立考试不刷新培训投影；已冻结参训人不可覆盖。
4. 查询接口只读投影；单条内容完成不写入参训人最终 PASSED/FAILED。

## MODIFIED Requirements

- 培训结果投影仍由正式来源幂等更新；刷新时机从「仅管理员同步或结束」改为「来源事实写入时自动刷新，计划级同步改为全量补账」。

## REMOVED Requirements

无。

## 延期

学时口径（考试/题库是否计入）、首次作答护栏、缺勤计学时、应到名单、场次状态机、多成绩项判定、监管个人下钻、读路径懒同步、前端页面。
