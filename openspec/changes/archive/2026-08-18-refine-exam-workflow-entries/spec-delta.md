# Spec Delta：考试流程入口与批阅人回显

## MODIFIED Requirements

### Requirement：考试情况入口

仅已发布考试可显示和进入考试情况；列表也仅为已发布行提供入口。

### Requirement：批阅人信息回显

人员配置仅展示批阅人读取 Contract 已提供的账号、姓名、所属机构和配置来源；不得展示部门、职务等无数据来源字段。

### Requirement：枚举中文化

界面不得直接展示考试 Contract 枚举值；`PENDING_REVIEW` 显示“待批阅”。

### Requirement：批阅与成绩处置内部路由

批阅和成绩处置必须可由已配置的考试管理菜单注册为隐藏内部页，不依赖“考试批阅”或“成绩管理”待办菜单是否存在；仍按各自既有按钮权限注册。

### Requirement：批阅可查看性与用户文案

反作弊事件较多时，教师仍能在同一页面滚动查看并完成后续评分。面向用户的考试、试卷和人员选择提示必须使用业务语言，不暴露实现术语。
