# Proposal：优化考试流程入口、批阅人回显与契约覆盖

## 目标

- 仅为已发布考试显示“考试情况”步骤，并在考试列表提供入口。
- 批阅人仅展示当前读取 Contract 已返回的字段。
- 将考试状态值统一翻译为中文，并完成考试 OpenAPI 调用覆盖审计。
- 让批阅与成绩处置内部页依附考试管理菜单注册，避免依赖未配置的跨考试待办菜单。
- 优化教师批阅长事件列表的可查看性，并将用户可见的技术术语改为业务语言。

## 范围

- PC Web 的考试工作台、考试列表和人员配置展示调整。
- 不修改后端、数据库、OpenAPI、Mock、API 类型、权限或路由契约。
- 保留批阅和成绩处置内部详情路由，以及现有“考试批阅”“成绩管理”菜单型待办入口；内部页注册锚点统一为考试管理菜单。
