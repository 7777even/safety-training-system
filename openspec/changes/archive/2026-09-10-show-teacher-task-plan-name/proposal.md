# Proposal：教师任务列表显示所属培训

## 背景

教师任务列表当前只显示线下场次名称、地点和时间。当不同培训计划下存在同名场次时，教师无法区分任务归属。列表接口仅返回 `trainingPlanId`，页面没有可直接展示的培训名称。

## 目标

1. 教师任务摘要返回所属培训名称。
2. 教师任务列表新增“所属培训”列，帮助教师区分同名场次。

## 范围

- 为 `GET /api/training/teacher-tasks` 的 `TrainingTeacherTaskVO` 增加可空 `trainingPlanName`，同步后端 VO、查询实现、OpenAPI 示例和定向测试。
- PC Web 教师任务列表显示所属培训名称；计划历史缺失时清楚降级显示。

## 非目标

- 不修改教师任务详情、场次状态、评分规则、权限模型或数据库结构。
- 不增加列表筛选、排序、分页语义或额外前端查询。
