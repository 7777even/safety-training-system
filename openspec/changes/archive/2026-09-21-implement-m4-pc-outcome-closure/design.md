# Design：M4 PC 培训成果闭环

## 业务流

```text
M3 正式课程/考试/线下成绩、奖惩
  → 自动综合分 → 培训 ENDED → 正式结果 / 一期一档 / 自动证书

问卷草稿 → 题目 → 投放冻结快照和二维码 → 用户一次填写 → 权限化统计
```

- 综合分只读参训人当前 `compositeScore`；空值即“结果待补全”，不补 0，不显示计算批次。
- 档案只读 `ArchiveViewVO`/`ArchivePersonVO`；`missingItems` 非空或无 `fileInfoId` 时禁用下载。
- 证书管理员与本人下载使用不同端点；本人身份只能由登录态派生。
- 问卷填写固定为 `/survey/fill/:surveyInstanceId`，题目来自投放快照；统计可见性由后端决定。

## 路由

旧 `/result` 菜单归一化为 `/admin/result`，已删除“综合计算”菜单不注册。管理员页面使用后台壳层；问卷填写为受登录保护的独立页；我的证书是门户页。

## 契约缺口

不实现模板/规则详情、更新、删除；不实现全量一期档案分页或个人自助档案，直到后端补齐相应 OpenAPI。
