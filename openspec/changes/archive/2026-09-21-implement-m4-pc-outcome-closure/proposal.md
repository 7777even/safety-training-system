# Proposal：M4 PC 培训成果闭环

## 状态与范围

- 状态：已确认实施；仅修改 `frontend/pc-web` 和本 Change，不修改后端、数据库、OpenAPI 或菜单种子。
- 覆盖功能项：19/50 证书、35/42 问卷、39/40 综合成果、43 专家查课、44 三级档案。
- 契约唯一来源：`survey`、`evaluation-result`、`training`、`archive`、`certificate` OpenAPI。

## 目标

将 M3 已产生的课程、考试、线下、奖惩等事实，在 M4 转化为可操作的问卷、结果、专家查课、档案与证书 PC 流程。已有页面或 API 不构成闭环；每条流程必须具备真实入口、真实契约读取和验收证据。

## 非目标

- 不恢复已删除的计算批次、人工确认、撤销/重发、版本历史和导出任务中心。
- 不伪造 `ATTENDANCE`、档案文件或证书模板编辑能力。
- 未定义的模板/规则详情、更新、删除接口不由前端自行补造。
