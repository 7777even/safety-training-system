# Tasks：优化考试批阅与培训工作台操作界面

> 状态：代码实现与自动化验证已完成，待真实环境验收。Owner：fxw11。确认日期：2026-09-15。

## Task 1：教师批阅全量校验与前端顺序保存

- 输入：作答详情、现有单题批阅接口。
- 输出：全量评分校验、右上角统一保存入口、部分失败反馈和刷新。
- 前后端影响：仅 PC。
- API 依赖：`GET /api/exam/attempts/{id}`、`POST /api/exam/answers/{id}/review`。
- 数据影响：无；多个既有单题写入可能部分成功。
- 验收标准：
  - [X] 未评分或非法分数时不发出写请求；真实 0 分允许保存。
  - [X] 所有题目有效时按顺序调用既有接口；中途失败不误报成功并刷新事实。
  - [X] 正式成绩发布后仍不可改分。
- 测试方式：先补充失败的 Node 页面/API 定向测试，再实现并验证。

- 前后端影响：仅 PC。
- API 依赖：既有读取、发布、补考、场次流转和录分接口。
- 数据影响：无。
- 验收标准：

- 测试方式：受影响页面定向测试、typecheck、目标 ESLint。
