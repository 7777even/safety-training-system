# Proposal：统一题库练习与线下考试的人员及评分流程

## 已确认决策

独立考试工作台的 `BANK_PRACTICE` 与培训题库练习使用同一语义：简答题仅保留作答记录，不评分、不进入待批阅；其他题型自动判定并形成可核对得分，不设置及格结论。线下考试没有线上答卷与批阅环节。

## 范围

1. 独立题库练习冻结题目、交卷和结果状态与培训题库练习一致。
2. 批阅人仅在确会产生人工批阅的线上/专项考试中显示并作为发布前置；题库练习、线下考试只要求已绑定考生。
3. 线下录分继续由 `exam:score:publish` 权限控制；该权限不是批阅人配置。
4. 同步 OpenAPI、PC 工作台说明和定向回归。

## 非目标

- 不变更普通线上考试、专项练习的主观题批阅及成绩发布语义。
- 不新增权限、表结构或接口。
