# Spec Delta：隔离浏览器标签页登录会话

## 新增行为

### 场景：不同标签页保持不同账户

- 假设系统地址相同，浏览器打开两个独立标签页 A、B
- 当 A 登录账户 A，B 登录账户 B
- 那么 A 的受保护请求使用账户 A 的令牌，B 的受保护请求使用账户 B 的令牌
- 并且 A、B 的用户资料、菜单权限和路由状态互不覆盖

### 场景：单标签页刷新恢复

- 假设标签页 A 已登录账户 A
- 当刷新标签页 A
- 那么标签页 A 恢复账户 A 的会话

### 场景：单标签页退出不影响其他标签页

- 假设标签页 A 登录账户 A，标签页 B 登录账户 B
- 当 A 退出登录
- 那么 A 回到未登录状态，B 仍保持账户 B 的登录状态

## 不变行为

- 登录、退出登录和获取当前用户的 HTTP API Contract 不变。
- 服务端权限校验仍以请求携带的 Bearer Token 为准。
