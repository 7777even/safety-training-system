# 提案：隔离浏览器标签页登录会话

## 背景

PC Web 当前将登录令牌写入同一来源下的 `localStorage`。同一浏览器打开多个系统标签页时，后登录的账户会覆盖前一个标签页的令牌；刷新或发起请求时，多个标签页因此表现为同一个账户。

## 目标

让同一浏览器、同一系统地址下的不同标签页或窗口可以同时登录不同账户，且各自的请求、路由守卫、用户资料和登出行为互不影响。

## 用户价值

管理员可以在同一浏览器中并行核对不同账户的权限或业务视角，不需要使用不同浏览器或手动反复登录。

## 功能范围

- PC Web 登录令牌按浏览器标签页/窗口隔离保存。
- 同一标签页刷新后继续恢复本标签页的登录会话。
- 一个标签页登录、切换账户或退出登录时，不修改其他标签页的登录会话。
- 保持现有登录 API、Bearer Token 请求方式、路由和后端会话语义不变。
- 增加覆盖上述隔离行为的前端自动化测试。

## 非目标范围

- 不改变后端登录接口、Token 生成、服务端并发登录策略或权限模型。
- 不实现标签页之间的账户同步、强制下线或统一退出。
- 不新增“记住我”、多账户切换器或新的浏览器存储依赖。
