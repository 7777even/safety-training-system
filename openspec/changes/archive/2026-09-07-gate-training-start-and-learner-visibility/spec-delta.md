# Spec Delta：培训计划准备完成门禁与学员可见性

## 变更类型

- 修改既有能力：`training-execution-loop`。
- 修改既有能力：`learner-training-task-visibility`。

## 需求增量

1. 系统 MUST 在培训计划所有内容均已生成对应实际执行安排后，才允许计划从 `PUBLISHED` 进入 `RUNNING`。
2. 系统 MUST 允许管理员在 `PUBLISHED` 阶段重试失败内容安排，且不得重复创建已经成功的安排。
3. 学员培训任务列表与详情 MUST 仅向本人开放 `RUNNING` 和 `ENDED` 计划。
4. 学员 MUST 仅在 `RUNNING` 阶段进入培训内容；`ENDED` 仅可查看结果。
5. 管理端 MUST 以真实内容安排进度展示下一步操作，部分安排不得显示为可开始。

## 场景

### 部分安排成功

- **GIVEN** 已发布计划有 5 项培训内容，其中 4 项已安排、1 项失败
- **WHEN** 管理员查看发布与执行
- **THEN** 系统显示 4/5、失败处理和继续安排入口，开始计划不可用
- **AND** 学员任务列表不返回该计划

### 全部安排成功后开始

- **GIVEN** 已发布计划所有培训内容均已安排
- **WHEN** 管理员开始计划
- **THEN** 计划进入 `RUNNING`
- **AND** 本人参训学员可看到并执行该培训任务

### 已结束仅查看结果

- **GIVEN** 计划处于 `ENDED`
- **WHEN** 学员查看我的培训
- **THEN** 学员可查看结果
- **AND** 系统不提供进入课程、考试、题库练习或线下内容的入口
