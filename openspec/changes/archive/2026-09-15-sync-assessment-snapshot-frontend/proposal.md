# Proposal：同步考核执行快照异常的学员端反馈

> 状态：已确认。Owner：fxw11。确认日期：2026-09-15。

## 背景

后端提交 `fdcfdf08` 统一考核执行冻结快照，并将业务码 `7063` 调整为考核执行快照或冻结资源不可执行。课程与培训学员入口不新增请求、成功响应、路由、权限或成绩规则，但现有页面会直接展示内部错误文案，部分 PC 课程开考异常未捕获。

## 目标

- PC Web 与移动端在课程测验、课程题库练习、培训理论考试和培训题库练习入口识别 `7063`。
- 对该错误统一显示“考核配置异常，请联系管理员重新生成。”，不向学员暴露快照、摘要或投影等实现细节。
- 保留其他错误码（包括 `8167`）的服务端中文提示和既有成功跳转行为。

## 非目标

- 不修改管理端、作答页、题库规则、成绩、权限、路由、请求或成功响应字段。
- 不在前端重试、修复或重新生成后端考核执行快照。
- 不伪造培训 Mock；仅在既有课程 Mock 提供可触发的 `7063` 场景。
