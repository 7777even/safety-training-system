# Design：以业务码映射冻结快照异常

## 契约依赖

本 Change 依赖后端 `fdcfdf08`：`course.openapi.json`、`exam.openapi.json` 与 `training.openapi.json` 均将 `7063` 定义为执行快照或冻结资源不可执行。前端不添加字段，只读取既有 Result 的 `code`。

## 错误流

1. 两端课程 API 和移动端培训 API 将非零 Result 转换为携带 `code` 的 Error；PC 培训 API 和 PC 请求拦截器已保留该字段。
2. 共享纯工具只识别 `code === 7063`，并返回统一学员文案；其他 Error 保留原始 `message`，未知异常使用入口既有兜底文案。
3. 课程与培训入口在跳转前捕获异常；命中 `7063` 时不跳转，加载状态在既有 finally 中结束或保持可再次点击。

## 兼容与发布

- `8167` 仍表示培训题库冻结题池异常，前端不改写其消息。
- 后端 migration 要求执行数据为空；该前提与部署版本核对属于发布验收，前端不操作数据库。
- 真实验证必须使用部署了 `fdcfdf08` 的非生产环境；静态和自动化测试不替代真实登录态验收。
