# Spec Delta：course-assessment-source-separation

## MODIFIED Requirements

### Requirement: 课程测验必须显式配置主观题阅卷人并自动生效成绩

纯客观题课程测验 MUST NOT 要求配置阅卷人，交卷并完成自动判分后成绩 MUST 自动生效。包含主观题时，系统 MUST
要求在开课对应考核执行中显式配置至少一名阅卷人，并在全部主观题批阅完成后自动生效成绩。课程测验 MUST NOT 进入独立考试人工成绩发布流程。
开课发布（无论调用来自管理端还是培训生成）MUST 使用同一套阅卷人校验：配置发生在开课草稿上，缺阅卷人时发布失败且开课保持草稿。

#### Scenario: 纯客观题课程测验交卷

- **GIVEN** 课程测验只包含客观题
- **WHEN** 学员交卷且系统完成自动判分
- **THEN** 最终成绩立即在该课程执行中生效
- **AND** 不生成独立考试人工发布任务

#### Scenario: 含主观题但没有阅卷人

- **GIVEN** 课程测验包含至少一道主观题
- **AND** 开课对应考核执行未配置阅卷人
- **WHEN** 该开课被发布
- **THEN** 系统拒绝发布并提示必须配置课程测验阅卷人
- **AND** 开课保持草稿

#### Scenario: 主观题全部批阅完成

- **GIVEN** 课程测验已显式配置阅卷人且存在待批阅主观题
- **WHEN** 最后一项主观题完成有效批阅
- **THEN** 系统重新计算并自动生效最终成绩
- **AND** 只更新该课程执行对应的结果和进度

## ADDED Requirements

### Requirement: 课程内考核与计划级考核必须分层

系统 MUST 将课程章节测验和课程题库练习视为开课能力内部的课程考核，随 COURSE 开课执行并自动生效成绩。系统 MUST 将培训计划内容
EXAM 和 QUESTION_BANK 视为考试能力对象，使用计划专属 Exam。两层 MUST NOT 合并为同一业务对象。

#### Scenario: 培训课程中的章节测验

- **GIVEN** 培训 COURSE 冻结版本包含章节测验
- **WHEN** 学员从培训进入该课程并完成测验
- **THEN** 成绩按课程考核自动生效
- **AND** 不进入考试人工发布流程

#### Scenario: 培训计划内容考试

- **GIVEN** 培训计划包含 EXAM 内容
- **WHEN** 学员从培训进入该内容并完成作答
- **THEN** 系统使用计划专属 Exam 的考试成绩规则
- **AND** 该任务出现在考试管理中，不出现在「我的考试」学员入口
