# Proposal：统一计划、课程和考试的时间范围录入

> 状态：已完成（2026-09-15）。

## 背景

PC 管理端在培训计划、课程开班、课程直播内容和考试开放时间中，均以两个独立控件录入同一业务时间段。用户需要逐一选择开始和结束时间，交互不一致。培训计划工作台的“培训性质”还因局部 `disabled` 属性覆盖表单只读状态，在已发布或执行中计划上仍能操作。

## 目标

- 将上述时间段录入统一为 Element Plus `datetimerange`，仍向既有 API 提交 `startTime`、`endTime` 两个 ISO `date-time` 标量字段。
- 仅允许草稿计划修改培训性质；已发布、执行中、结束、取消或归档计划保持只读。

## 范围

- 培训计划基础信息：计划开始/结束时间、培训性质只读状态。
- 课程开班：开班开始/结束时间。
- 课程内容检查器：两处直播开始/结束时间。
- 考试定义：考试开放、补考开始/结束时间。

## 非目标

- 不修改 API Contract、后端、数据库、权限、状态机或时间先后业务规则。
- 不改变展示型列表/详情的开始、结束时间列。
- 不改变已使用时间范围控件的线下授课执行配置。

## 前后端影响

仅 PC Web 前端；复用 OpenAPI 既有 `date-time` 字段和保存路径。
