# Spec Delta：PC 管理端时间范围录入

## Modified Requirement：统一时间段录入

PC 管理端中配置一个业务开始/结束时间段的计划、课程开班、课程直播内容和考试定义页面 MUST 使用单一日期时间范围控件。控件选择结果 MUST 映射为既有请求模型中的两个 `date-time` 字段，且不得新增或遗漏 API 字段。

### Scenario：保存时间范围

- **WHEN** 管理员选择完整时间范围并保存
- **THEN** 请求继续携带原字段名的开始和结束 ISO 日期时间

### Scenario：清空时间范围

- **WHEN** 管理员清空已选择时间范围
- **THEN** 表单中的开始和结束字段同步清空，并继续按原有必填规则校验

## Modified Requirement：计划培训性质冻结态

培训计划的培训性质 MUST 仅在草稿可编辑。历史未标明和所有非草稿计划 MUST 以只读状态显示该字段。

### Scenario：执行中计划

- **WHEN** 管理员打开执行中计划的基础信息
- **THEN** 培训性质选择器不可操作
