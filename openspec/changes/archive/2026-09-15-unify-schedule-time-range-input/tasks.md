## Task 1：统一 PC 时间段录入并修复计划冻结态

- 输入：既有 OpenAPI `date-time` 字段、培训计划状态、四类 PC 表单。
- 输出：统一时间范围控件和正确的培训性质只读状态。
- 前后端影响：仅 PC 前端。
- API 依赖：既有计划、课程、课程内容和考试保存接口；不变更契约。
- 数据影响：无。
- 验收标准：
  - [x] 计划、课程开班、课程直播、考试开放和补考编辑均使用单一 `datetimerange`，提交仍为原有两个 ISO 时间字段。
  - [x] 计划草稿可修改培训性质；非草稿和历史未标明计划不可修改。
  - [x] 时间范围清空、编辑回显和保存不产生遗漏字段或新的字段。
  - [x] 定向测试、PC typecheck、受影响 ESLint、`git diff --check` 通过；聚合既有回归中的 14 项无关失败已记录于 QA。
- 测试方式：先补目标静态回归断言，再做最小实现；非生产环境人工核对四类表单提交请求和计划状态禁用行为。
