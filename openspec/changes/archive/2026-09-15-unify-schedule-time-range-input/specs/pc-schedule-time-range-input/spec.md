# PC 时间范围录入 Specification

## Purpose

统一 PC 管理端配置时间段的录入体验，并确保范围控件继续使用既有开始、结束时间 API 字段。

## ADDED Requirements

### Requirement: PC 时间段使用范围控件录入

培训计划、课程开班、课程直播、考试开放和补考的开始、结束时间 MUST 由一个日期时间范围控件录入。控件值 MUST 映射回既有请求模型的两个 ISO `date-time` 字段，且不得新增或遗漏 API 字段。

#### Scenario: 保存完整时间范围

- **WHEN** 管理员在任一受影响表单选择完整时间范围并保存
- **THEN** 请求继续携带原字段名的开始和结束日期时间

#### Scenario: 清空时间范围

- **WHEN** 管理员清空已选择时间范围
- **THEN** 开始和结束字段同步清空
- **AND** 原有必填和时间先后校验继续生效

### Requirement: 非草稿计划的培训性质只读

培训计划的培训性质 MUST 仅在草稿计划中可编辑。历史未标明计划和所有非草稿计划 MUST 将该字段显示为不可操作。

#### Scenario: 打开执行中计划

- **WHEN** 管理员打开执行中计划的基础信息
- **THEN** 培训性质选择器不可操作

#### Scenario: 编辑草稿计划

- **WHEN** 管理员打开非历史未标明的草稿计划
- **THEN** 可以选择初培或复审
