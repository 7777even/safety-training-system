## ADDED Requirements

### Requirement: 执行中培训计划必须形成奖惩录入与结果回读闭环

系统 MUST 允许有权限的管理员仅在 RUNNING 培训计划内，对该计划参训人录入、编辑和删除奖惩。系统 MUST 在服务端拒绝跨计划、跨机构、非执行中及结束冻结后的写入，并保持失败时综合结果不变。界面 MUST 从本计划参训名单选择人员，不得要求管理员手输关联主键。

#### Scenario: 录入奖惩并回读正式结果

- **GIVEN** 一个执行中计划和本计划参训人
- **WHEN** 管理员录入启用的奖励或处罚，或编辑、删除已有记录
- **THEN** 计划奖惩列表与参训人综合结果从服务端重新读取
- **AND** 培训结束后成果与档案仅展示服务端冻结的正式事实

#### Scenario: 拒绝冻结后或归属错误的写入

- **GIVEN** 计划已结束，或奖惩请求关联其他计划、机构的参训人或佐证
- **WHEN** 管理员或客户端调用新增、编辑、删除奖惩接口
- **THEN** 服务端拒绝且不改写奖惩、综合分或最终结果
- **AND** 界面保留输入并展示业务错误消息
