# Proposal：补齐证书模板设计与签发规则管理闭环

> 状态：待人工确认。确认前不得修改生产代码、API、权限或数据库资产。

## 1. 背景

M4 已交付证书模板基础 CRUD、直接发布版本、签发规则创建/删除、自动签发、预览和本人证书查询；2026-09-21 又完成了既有
Controller 与 OpenAPI 的同步。但当前后端仍不能支撑真实管理端闭环：

- 模板详情只返回模板基础字段，不返回底图、版本和元素；
- 模板更新只修改名称、状态和描述，不能保存设计草稿；
- 模板删除不检查签发规则引用；
- 签发规则没有详情和更新接口，创建时也不校验模板及来源是否可绑定；
- 课程、理论考试和培训计划缺少统一、租户隔离的规则来源候选查询；
- 当前 PNG 渲染器未读取模板底图，也未应用已保存的字体样式，不能证明生成结果与模板设计一致。

本 Change 在不恢复撤销、重发、任意手工签发等已删除能力的前提下，补齐证书设计和签发配置的后端闭环。

## 2. 功能项追溯

### 功能项 19：证书管理

原文语义：证书管理能够实现证书设计与管理；设计时可使用任意图片作为模板底图，并在模板上添加证书编号、学员姓名等内容；编辑后的模板生成对应样式证书并可在线查看或下载；证书可配置于理论考试、课程和培训，达到合格标准后自动下发。

本 Change 覆盖其中：

1. 模板底图、文字、变量、坐标和字体样式的草稿保存、详情回显与发布；
2. 模板被签发规则引用时的安全删除；
3. 课程、理论考试和培训签发规则的详情、更新及可绑定来源选择；
4. 使用已发布模板底图与元素生成真实 PNG。

自动幂等签发、管理员/本人查看下载沿用既有实现，不新增手工签发、撤销或重发入口。

## 3. 目标

1. 管理员可以读取模板的当前已发布版本和未发布草稿，保存草稿后可靠回显。
2. 发布操作将当前草稿固化为不可变版本；新一轮编辑不覆盖已被证书引用的历史版本。
3. 生成和预览的 PNG 使用真实底图，并按模板元素的坐标、字体、字号和颜色绘制文字/变量。
4. 被有效签发规则引用的模板不能删除。
5. 管理员可以读取、修改和删除签发规则；创建和更新都验证模板与来源。
6. 单一候选接口按来源类型分页返回当前租户中可绑定的已发布课程、理论考试或培训计划。
7. OpenAPI、权限种子、增量 migration、测试、QA、Retro 和进度记录同步完成。

## 4. 非目标

- 不修改任何 `frontend/` 文件；前端以 OpenAPI 为准另开。
- 不实现档案分页、`/archive/persons/me`、签到事实或正式档案下载；这些另开 Change。
- 不恢复证书撤销、人工重发、到期管理或客户端任意手工签发。
- 不实现电子签章、防伪、复杂编号规则、PDF 排版或任意图片元素叠加。
- 不新增证书模板版本历史管理页面/API；历史版本只作为签发快照内部保留。
- 不修改证书业务表结构，不迁移或重写历史模板、规则与证书数据。

## 5. 影响范围

- 后端：`com.sts.certificate`，以及只读引用课程、考试、培训来源的 Mapper/Entity。
- API：`docs/api/certificate.openapi.json`。
- 权限：新增 `certificate:rule:edit`，同步 Admin-init 菜单种子和 Admin 增量 migration。
- 数据：不改证书表结构；只增加可授权的规则编辑权限种子。
- 工程记录：本 Change、进度表、QA、Retro。

## 6. 风险与控制

- **历史版本被覆盖**：PUT 只覆盖唯一草稿；PUBLISHED/ARCHIVED 版本及其元素不修改。
- **跨租户引用**：所有模板、规则和来源查询继续由租户拦截器约束；服务层对关联对象再次校验存在性与状态。
- **错误来源配置**：创建和更新规则只接受契约列出的来源类型，并验证来源处于可绑定状态。
- **并发覆盖**：模板与规则更新携带乐观锁 `version`；更新 0 行返回 409。
- **删除破坏配置**：有效规则引用模板时返回 409，不执行删除。
- **渲染不一致**：背景文件必须可读取为图片；公开元素只支持当前能稳定渲染的 TEXT/VARIABLE，历史 IMAGE 数据保留但不再允许通过公开请求新建。

## 7. 人工确认关卡

本 Change 属于 L4。确认 Proposal、Design、Tasks 和 Spec Delta 后才允许实施。确认同时表示接受：

1. 每个模板最多保留一个可覆盖的 DRAFT；发布后版本不可变，下一次编辑使用新版本号草稿。
2. `GET` 同时返回当前已发布版本和草稿；`PUT` 保存草稿；既有发布接口用请求内容更新/创建草稿后原子发布，以兼容当前调用方式。
3. 公开元素类型收口为 TEXT/VARIABLE；背景图片通过 `backgroundFileId` 表达，历史 IMAGE 元素不删除。
4. 可绑定来源定义为：已发布课程、已发布且未结束的理论考试、已发布或进行中的培训计划；草稿、取消、归档、结束来源不进入新增候选。
5. 新增独立权限 `certificate:rule:edit`，并通过 init 种子与 migration 使其可授权。
6. 本次只实施证书闭环；档案查询增强和签到事实分别另开 Change。
