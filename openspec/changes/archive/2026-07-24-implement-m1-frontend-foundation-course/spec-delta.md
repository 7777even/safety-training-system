# Spec Delta：M1 前端基础与课程真实闭环

## 新增交付要求

- 系统必须提供机构成员、标签、岗位、参与范围、监管关系和资源授权的 PC 管理入口，并完整呈现 BASE-02～04 Contract 字段。
- 系统必须在 PC 管理端以真实接口完成素材、课程、开课、报名和管理员学习详情；已实现接口不得长期保留业务 Mock。
- 系统必须为学员提供 PC 与移动端的本人课程、学习详情、学习会话、退选和评价能力。
- 前端只根据权限数据控制入口；不得硬编码业务身份或替代后端数据范围控制。

## 保持不变

- 不新增或修改 API Contract、业务规则、权限模型、数据库结构与后端实现。
- 不实施媒体播放、在线预览、真实转码、题库考试、培训计划、证书、运营或监管业务。
- M2～M5 前端能力在本 Change 完成 M1 真实端到端验收后再分别创建 Change。
