# Proposal：前端同步封面受控访问契约

## 背景

后端 Change `unify-cover-access-protocol` 已将培训类型写入字段统一为 `coverFileId`，并将学员课程、考试和培训任务的封面输出统一为受控相对路径 `coverUrl`。PC Web 和 shared 类型仍保留部分旧字段，移动端会随 shared 类型变更产生编译连带影响。

## 目标

1. 让 PC Web、shared 类型与当前 `docs/api/*.openapi.json` 一致。
2. 所有学员封面只通过后端给出的受控 `coverUrl` 读取，不暴露或推导文件主键。
3. 仅做移动端最小兼容，保持既有页面布局和课程、考试操作流程。

## 范围

- PC 培训类型管理及课程、考试、培训门户封面。
- shared 学员课程、考试类型；移动端 Mock 与封面读取兼容。
- 定向契约回归、类型检查和构建验证。

## 非目标

- 不修改后端、OpenAPI、数据库、权限、对象存储或路由。
- 不改变独立课程/考试与培训内容的进入边界。
- 不重做移动端页面视觉或交互。
