# Tasks：移动端正式考试考前须知与单向开考

> 状态：已完成。

## Task 1：提供移动端正式考试考前须知和单向开考

- 状态：已完成。
- Owner：Codex
- 输入：PC 端 `notice.vue`、既有考试详情、开考与作答接口。
- 输出：未开始正式考试先进入移动端须知页；点击开始答题才创建作答并单向进入答题页。
- 前后端影响：仅移动端与 Mock；后端、OpenAPI、shared 不变。
- API 依赖：既有考试详情、本人考试任务、开考和作答详情接口。
- 数据影响：无。
- 验收标准：须知内容和概要与 PC 使用同一考试详情事实；打开须知或返回列表不创建 Attempt；开始答题后只进入答题页；继续、结果、等待成绩不经过须知；答题页无返回须知入口。已确认学员角色具有既有 `exam:exam:list` 权限。
- 测试方式：先更新移动端页面/Mock 闭环测试为失败，再实现并运行定向测试、typecheck、受影响 lint 与 H5 build。

## Task 2：验证正式考试开考闭环

- 状态：已完成。
- Owner：Codex
- 输入：Task 1 的实现和既有 API Contract。
- 输出：覆盖未开始、开考、继续作答、等待成绩和查看结果分流的验证记录。
- 前后端影响：移动端测试、QA/Retro 和进度表。
- API 依赖：既有本人考试任务与开考接口。
- 数据影响：无。
- 验收标准：双轴 Review 通过；不影响课程考核开考流程。
- 测试方式：运行移动端定向测试、受影响 workspace 验证与 API Contract 路径检查。
