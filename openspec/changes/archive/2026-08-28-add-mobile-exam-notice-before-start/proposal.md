# Proposal：移动端正式考试考前须知与单向开考

## 背景

移动端“我的考试”当前点击“开始考试”即创建作答并进入答题页，缺少 PC 端 `notice.vue` 已提供的考前阅览环节。学员无法在正式开考前读取考试时长、开放时间、及格要求和考试须知。

## 目标与用户价值

- 学员在移动端正式开考前可阅读与 PC 一致的考试须知和考试概要。
- 仅在学员点击“开始答题”后创建作答，避免仅浏览任务即占用正式考试次数。
- 作答创建成功后以单向跳转进入答题页，答题页不能返回须知页重新开考。

## 覆盖的功能项

- 功能项 85：考试安排支持考前开启提醒须知，PC 与移动端支持考试流程。
- 功能项 86：考生可在移动端参与在线考试。

## 范围

- 在移动端新增正式独立考试须知页；未开始任务的入口先到须知页，继续作答、查看结果和等待成绩维持现有分流。
- 使用既有 `POST /api/exam/attempts/start` 在须知页“开始答题”时创建作答。
- 复用 PC 端既有的 `GET /api/exam/exams/{examId}` 考试详情读取考试总分、及格分和须知内容。
- 须知页以 `redirectTo` 进入答题页；答题页在正式开考后不提供返回须知的路径。

## 非目标

- 不修改课程题库练习或课程测验流程。
- 不改变考试次数、作答冻结、交卷、倒计时或防作弊规则。
- 不新增考试须知确认记录、数据库字段、权限、API 端点或 Contract 字段。
