# Spec Delta：移动端正式考试考前须知与单向开考

## ADDED Requirements

### Requirement：移动端正式考试必须经考前须知明确开考

移动端学员对 `availableAction=START` 的独立正式考试 MUST 先进入考前须知页。须知页 MUST 展示考试概要、启用的自定义须知或通用规则；仅在学员点击“开始答题”后调用既有开考接口创建作答。

#### Scenario：阅览须知不创建作答

- **GIVEN** 学员有一项 `START` 的独立正式考试任务
- **WHEN** 学员从考试列表进入须知页或从须知页返回考试列表
- **THEN** 不调用开考接口
- **AND** 不创建作答、不占用考试次数

#### Scenario：开始答题后单向进入作答

- **GIVEN** 学员正在移动端正式考试须知页
- **WHEN** 学员点击“开始答题”且服务端成功创建作答
- **THEN** 页面以替换式导航进入对应答题页
- **AND** 答题页不得提供返回须知并重新开考的入口

### Requirement：移动端考前须知复用既有考试详情

移动端考前须知 MUST 使用与 PC 须知页相同的既有考试详情事实；不新增或修改后端接口、数据库、权限或 API Contract。

#### Scenario：未启用自定义须知

- **GIVEN** 正式考试未启用自定义须知或须知内容为空
- **WHEN** 学员进入移动端考前须知页
- **THEN** 页面展示通用考试规则
- **AND** 仍可在点击“开始答题”后正常开考
