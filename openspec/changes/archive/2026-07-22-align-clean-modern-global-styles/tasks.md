# Tasks：统一清爽现代风全局样式

## Task 1：建立跨端清爽现代视觉 Token

- **Owner**: AI
- **输入**: `docs/design/clean-modern-style-baseline.md`、PC 与移动端现有 styles 入口
- **输出**: PC Web、移动端均可消费的颜色、字体、圆角、阴影、间距语义 Token；PC Web 的 Element Plus 主题变量覆盖
- **前后端影响**: 前端全局视觉统一；后端无影响
- **API 依赖**: 无
- **数据影响**: 无
- **验收标准**:
  - 两端页面背景、主/次文字、边框、主色、圆角和阴影均来自语义 Token
  - Element Plus 的主操作、输入、菜单和表格呈现清爽现代基准
  - 不新增依赖、不修改业务接口或数据
- **测试方式**: PC Web 与移动端 lint、typecheck、build；检查编译后的 CSS Token 引用
- **状态**: 已完成

## Task 2：统一 PC Web 门户与后台工作区视觉

- **Owner**: AI
- **输入**: Task 1 Token、`AdminLayout`、门户、登录页和当前后台页面
- **输出**: 顶栏、侧栏、页面标题、筛选区、卡片、按钮、表单、表格与详情编辑容器的统一视觉
- **前后端影响**: PC Web 门户和后台外观调整；后端无影响
- **API 依赖**: 无
- **数据影响**: 无
- **验收标准**:
  - 后台选中导航、页面容器和操作区符合清爽现代基准
  - 门户与后台共享颜色、文字、卡片、阴影与控件状态，不强制采用相同布局
  - 课程封面渐变只存在于内容封面，不进入系统级容器
- **测试方式**: PC Web build/typecheck；浏览器检查门户、后台壳层、列表页和详情编辑页
- **状态**: 验证中（待完成浏览器视觉检查）

## Task 3：统一移动端基础视觉与触控样式

- **Owner**: AI
- **输入**: Task 1 Token、移动端基础布局、登录页与首页
- **输出**: 适配移动端的页面背景、卡片、文字层级、按钮与表单视觉
- **前后端影响**: 移动端外观调整；后端无影响
- **API 依赖**: 无
- **数据影响**: 无
- **验收标准**:
  - 移动端继承同一视觉 Token，不复制 PC 的后台布局
  - 页面留白为 16px、内容卡片圆角为 12px、主要触控控件高度不低于 44px
  - 登录页和首页未发生信息架构或业务交互变化
- **测试方式**: 移动端 build/typecheck；H5 断点检查登录页和首页
- **状态**: 验证中（待完成 H5 断点视觉检查）

## Task 4：完成视觉回归与交付记录

- **Owner**: AI
- **输入**: Task 1–3 的样式变更
- **输出**: 验证结果、未覆盖风险与更新后的 Task 状态
- **前后端影响**: 无运行时能力变化
- **API 依赖**: 无
- **数据影响**: 无
- **验收标准**:
  - PC Web 与移动端相关构建、lint、typecheck 通过
  - 关键页面在桌面和移动断点下无明显溢出、文字不可读或卡片层级错误
  - 实现与 `docs/design/clean-modern-style-baseline.md` 一致
- **测试方式**: 自动化命令与浏览器视觉回归检查
- **状态**: 待确认
