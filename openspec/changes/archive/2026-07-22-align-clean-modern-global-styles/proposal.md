# Proposal：统一清爽现代风全局样式

## 背景

当前 PC Web 与移动端已有基础样式入口，但设计 Token、Element Plus 默认视觉、布局壳层与页面局部样式尚未统一收敛。已确认的
`docs/design/clean-modern-style-baseline.md` 要求门户、后台、详情页和移动端采用同一套清爽现代风视觉语言。

## 目标

- 将清爽现代风基础 Token 落地到 PC Web 与移动端的全局样式入口。
- 统一字体、页面背景、文字层级、卡片、边框、圆角、阴影、按钮、表单与导航选中态。
- 对齐当前门户、后台壳层、已实现的后台页面与移动端首页的基础视觉，不改变功能、路由、接口、权限或业务交互。

## 用户价值

用户在门户、后台、详情页和移动端切换时获得一致、清晰、专业的学习管理体验；后续页面可直接复用稳定 Token 和组件覆盖规则，减少每页重复定义样式。

## 功能范围

- PC Web 与移动端的全局颜色、字体、圆角、阴影、间距 Token。
- Element Plus 的主题变量与常见组件视觉覆盖。
- PC 后台壳层、门户和当前后台页面的卡片、表单、按钮、表格与标题样式对齐。
- 移动端基础布局、页面背景、卡片与触控控件样式对齐。
- 对已覆盖页面进行构建、类型检查与视觉回归验证。

## 非目标范围

- 不修改任何业务流程、接口契约、权限模型、数据库或 Mock 数据。
- 不新增页面、路由、业务组件或第三方依赖。
- 不把课程封面渐变扩展为系统级背景、导航或表单风格。
- 不实现附件原型中未落地的交互功能。
