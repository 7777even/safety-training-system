# Spec Delta：清爽现代风全局样式

## ADDED

### 清爽现代风视觉一致性

系统的 PC Web 门户、管理后台、详情编辑页和移动端必须采用 `docs/design/clean-modern-style-baseline.md`
定义的清爽现代风视觉语言。页面背景、容器、文字、边框、圆角、阴影、按钮、表单、导航选中态和状态表达必须复用统一语义 Token。

后台与门户可以使用不同的信息架构，但必须共享颜色、文字层级、卡片、阴影、图标和控件状态规则。移动端必须共享语义 Token，但不得复制
PC 后台侧栏或密集表格布局。

### 全局样式 Token

PC Web 与移动端必须分别提供等价的语义 Token，至少覆盖页面背景、容器背景、主/常规/辅助文字、边框、主色、主色悬停、选中态、危险色、圆角、阴影和间距。

PC Web 必须通过全局主题变量使 Element Plus 的常用按钮、输入框、菜单和表格符合该 Token 体系；不得改变其组件 API 或引入新的
UI 依赖。

### 克制的内容装饰

课程与培训内容封面可以使用低面积渐变和简洁线性图形作为内容识别。系统级背景、导航、表单、列表和详情编辑容器不得使用课程封面渐变、拟态极简主题或与本基准不一致的图标语言。

### 视觉质量验证

样式变更必须通过 PC Web 与移动端相关 lint、typecheck 和 build。验证至少覆盖 PC
门户、后台壳层、一个列表页、一个详情编辑页，以及移动端登录页和首页，并确认主要断点下的文字、卡片、表单、导航和操作区无明显视觉回归。
