## ADDED Requirements

### Requirement: M4 必须只暴露中山 50 功能项要求的产品能力

系统 MUST 只保留可追溯到功能项 19、35、39、40、42、43、44、50 且构成最小闭环所必需的对外能力。无功能项依据、且不是必要内部机制的既有能力
MUST 删除业务代码、API、菜单、权限和 OpenAPI；既有数据库结构与历史数据 MUST 保留并明确标注隐藏状态。

#### Scenario: 收口无功能项依据的既有能力

- **GIVEN** 既有代码提供人工计算批次、档案版本历史、证书撤销或重发等能力
- **WHEN** 本 Change 实施
- **THEN** 系统删除对应公开代码、API、菜单、权限和 OpenAPI
- **AND** 保留既有数据库结构和历史数据
- **AND** 使用标准 COMMENT 标注原用途、隐藏状态和重新启用条件

### Requirement: 问卷必须形成设计到扫码统计的最小闭环

系统 MUST 支持问卷创建、查看、编辑、复制、删除、电脑/手机预览、投放、二维码、本人填写、结果可见性和基础统计。系统 MUST
阻止同一用户对同一投放重复提交。

#### Scenario: 问卷投放与填写

- **GIVEN** 管理员已完成题目和答案设计并通过电脑和手机预览
- **WHEN** 管理员发起投放并由用户扫码提交
- **THEN** 系统保存一份有效答卷并阻止同一用户重复提交
- **AND** 管理员能够查看基础结果统计
- **AND** 填写人结果可见性服从管理员设置

### Requirement: 综合分必须根据考试与奖惩自动计算

系统 MUST 根据培训绑定的综合评分表、考试正式成绩和奖惩记录自动刷新参训人当前综合分。系统 MUST NOT 要求管理员创建、确认或替代计算批次。

#### Scenario: 来源事实变化

- **GIVEN** 培训已绑定启用的综合评分表
- **WHEN** 参训人的考试正式成绩或奖惩记录变化
- **THEN** 系统自动刷新当前综合分
- **AND** 不要求管理员执行计算批次操作

#### Scenario: 查看已结束培训结果

- **GIVEN** 培训已经结束
- **WHEN** 管理员查看培训结果
- **THEN** 系统展示计划整体信息、学员成绩与详情、奖惩和基础统计

### Requirement: 专家查课必须形成表单引用与意见记录闭环

系统 MUST 支持专家查课表的新建、管理、培训引用、专家意见提交和培训内查看，不扩展评分排名、整改审批或多轮复查。

#### Scenario: 专家提交查课意见

- **GIVEN** 培训已引用一个专家查课表
- **WHEN** 专家提交查课意见
- **THEN** 系统保存提交人、提交时间和完整意见
- **AND** 管理员能够在对应培训中查看

### Requirement: 档案必须提供个人、企业和一期三个视角

系统 MUST 只从已结束培训形成正式档案，并在个人、企业和一期三个视角展示一致的计划、人员、签到、成绩、评价、奖惩、影像、附件和统计事实。系统
MUST 生成真实可下载档案文件。

#### Scenario: 结束培训归档

- **GIVEN** 培训状态为 `ENDED` 且所需事实完整
- **WHEN** 管理员更新档案
- **THEN** 系统在个人、企业和一期三个视角展示一致事实
- **AND** 生成真实可下载档案文件

#### Scenario: 未结束培训归档

- **GIVEN** 培训状态不是 `ENDED`
- **WHEN** 请求形成或更新正式档案
- **THEN** 系统拒绝请求

### Requirement: 证书必须按来源合格结果自动生成真实文件

系统 MUST 支持图片底图、证书编号、学员姓名等元素的模板设计与预览，MUST
支持将模板配置到课程、理论考试和培训，并在学员达到既有合格标准时自动、幂等签发真实证书文件。管理员可查询、预览和下载证书；学员只能查看和下载本人证书。

#### Scenario: 学员首次达标

- **GIVEN** 课程、理论考试或培训已配置启用的证书模板
- **WHEN** 学员第一次达到来源对象的合格标准
- **THEN** 系统自动且幂等地签发证书
- **AND** 生成可预览、可下载的真实图片或 PDF 文件

#### Scenario: 学员查看证书

- **GIVEN** 学员已获得证书
- **WHEN** 学员进入个人中心“我的证书”
- **THEN** 系统只返回该登录学员本人的证书
- **AND** 支持在线查看和下载

### Requirement: M4 完成状态必须以真实纵向闭环为准

M4 MUST NOT 按“纯后端完成、前端另开”关闭。问卷、综合结果、专家查课、三级档案和证书五条链路全部完成真实页面、真实
API、真实数据、权限与端到端验收后，M4 才可标记为已完成。

#### Scenario: 仅后端实现完成

- **GIVEN** 某条 M4 链路只有后端接口或仍使用 Mock、空快照、占位文件
- **WHEN** 评审 M4 里程碑状态
- **THEN** M4 不得标记为已完成
