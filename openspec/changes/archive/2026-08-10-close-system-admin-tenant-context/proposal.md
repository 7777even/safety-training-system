# 收口系统管理与租户上下文

## 背景

前端多租户契约同步后，系统管理仍有用户扩展字段未形成可操作表单、普通租户仍可看到跨租户筛选、监管页面缺少运行时租户类型校验，以及初始化菜单和
Mock 中存在已删除能力残留。

## 目标

- 使系统管理页面可以录入并提交后端用户扩展字段。
- 使标签、岗位、部门、角色遵循当前租户上下文。
- 使监管聚合入口同时受 `orgType` 和权限控制，并清理只读视角状态。
- 删除已移除机构成员和监管关系能力的菜单、Mock 残留。
- 提供可重复的 superAdmin 验收数据，不直接写入数据库。

## 非目标

- 不修改后端业务规则、数据库结构或权限模型。
- 不提前关闭课程、考试、培训等仍处于产品范围的 Mock 能力。
- 不实施真实素材转码和媒体增强。
