- 输入：计划阶段、执行链接、线下场次、参训人结果及综合评价绑定。
- 输出：PC 工作台的已知阻塞项和刷新动作。
- 前后端影响：仅 PC。
- API 依赖：既有培训计划、线下场次和参训结果读取接口。
- 数据影响：无。
- 验收标准：
  - [X] 进行中线下场次、未安排内容、未终态必修内容及缺少正式综合成绩均有中文说明。
  - [X] 真实 0 分不被当作缺分。
