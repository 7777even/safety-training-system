# Proposal：实施课程模块 PC 管理端前端

## 背景

课程素材、课程草稿编排、发布版本、开课报名与学习事实的后端能力和 OpenAPI Contract 已完成，
但 PC 管理端的素材库、课程中心等菜单目前仍复用课程分类占位页面，无法形成课程管理工作流。

本 Change 承接已归档的课程业务规格，只实现当前 Contract 可以支撑的 PC 管理端能力，不创建新的业务规则。

## 目标

- 交付素材库管理页面，覆盖素材查询、创建、编辑、删除保护、转码状态和任务查看。
- 交付课程分类、机构课程设置、课程列表和课程草稿编排页面。
- 交付课程发布版本、开课、报名名单和管理员学习详情页面。
- 建立页面、FR、API Contract 和前端测试之间的可追踪关系。

## 用户价值

企业或培训机构的课程管理员可以在 PC 管理端完成素材准备、课程制作、版本发布、开课和学习情况查看，
不再依赖接口工具操作后端课程能力。

## 功能范围

- PC 管理端素材库。
- PC 管理端课程分类和机构课程设置。
- PC 管理端课程中心、课程编辑器和课程版本页。
- PC 管理端开课管理、报名名单和管理员学习详情。
- 依据 profile 菜单权限控制页面和操作入口展示。

## 非目标范围

- 学员 PC 端和移动端课程页面；其发现课程、我的课程和课程内容读取 Contract 尚未补齐。
- 文件服务未提供的在线预览、播放地址和下载地址能力。
- 课程授权管理；当前 Contract 尚未定义公共/内部课程及跨机构授权接口。
- `KNOWLEDGE_POINT`、`QUESTION_BANK`、`EXAM`、`PRACTICE` 内容项。
- 真实转码供应商、直播平台集成或新的学习完成规则。
- 后端、数据库和现有 API Contract 变更。

## 人工确认关卡

- 已确认：本轮沿用现有 PC 管理端 Design System 和业务中心布局完成素材库、课程中心、课程编辑器、课程版本和开课管理页面。
- 已确认：TDD 公开测试缝采用 API 请求封装与管理端页面用户行为；菜单组件路径由管理员在菜单配置中维护。
- 已确认：分阶段交付；契约缺口先补契约；未确认业务规则作为阻塞项。
