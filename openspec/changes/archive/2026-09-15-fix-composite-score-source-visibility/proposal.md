# Proposal：修复培训综合成绩来源与结果抽屉可理解性

> 状态：已完成（2026-09-15）。Owner：fxw11。

## 背景

培训结果抽屉可以看到线下和考试的逐内容正式分数，但综合成绩计算批次连续为 0。现有计算只读取参训人聚合分，计划内容的 `isScored` 默认值为 0，而 PC 阶段编排未展示该配置；同时计算页面没有说明每个批次实际读取的来源分数，管理员容易把“尚未产生”误解为真实 0 分。

## 目标

让课程、考试、线下培训的计分资格在草稿编排阶段可见、可配置；题库练习固定不参与综合成绩。计算前刷新当前参训人的结果聚合，并拒绝在没有任何有效成绩来源时创建待确认的全 0 批次。结果抽屉清楚展示本次计算实际采用的来源和未纳入原因。

## 范围

- 草稿计划的阶段内容为课程、考试、线下培训提供“计入综合成绩”开关，新增上述三类内容时默认计入；题库练习固定为不计入且不可修改。
- 计算综合成绩时刷新当前参训人的逐内容投影与聚合；课程尚未出分不得抹去已计入的考试、线下汇总分。
- 所有计分来源均为空时，计算接口返回明确失败，不创建计算批次。
- 结果抽屉展示每项是否纳入、原因，以及计算批次实际使用的课程、考试、线下成绩；对无有效来源的状态不提供误导性的确认操作。
- 为上述错误语义补充 OpenAPI 错误码和前后端定向回归。

## 非目标

- 不修改已发布/执行中计划冻结的计分配置，不直接修复真实环境已有计划数据。
- 不删除历史计算批次，不批量计算或自动确认。
- 不改变综合评价表单中的权重或加减分规则。

## 前后端影响

后端：结果同步服务增加当前参训人同步入口；综合成绩计算增加来源空值保护；OpenAPI 新增错误码。

前端：阶段编排配置、培训结果抽屉和定向测试调整；不新增路由或手工 ID 输入。
