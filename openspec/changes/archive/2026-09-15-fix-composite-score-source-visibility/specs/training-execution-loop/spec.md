## MODIFIED Requirements

### Requirement: 培训结果由正式来源同步到逐内容投影

系统 MUST 按 `trainingParticipantId + planContentId` 读取课程、考试和线下正式事实，并幂等更新唯一的逐内容结果投影。课程、考试和线下内容只有 `isScored=1` 时才计入对应聚合成绩；`QUESTION_BANK` MUST 固定不参与课程、考试、线下和综合成绩聚合。培训结果视图 MUST 区分“内容已有正式分数”与“该内容计入综合成绩”。

#### Scenario: 同步正式结果

- **GIVEN** 课程完成、考试成绩发布或线下成绩保存
- **WHEN** 系统同步培训结果
- **THEN** 系统更新唯一逐内容投影及参训人聚合字段，并保留可追溯的正式来源

#### Scenario: 考试成绩未发布

- **GIVEN** Candidate 已交卷但成绩未发布
- **WHEN** 同步或查询培训结果
- **THEN** 系统显示待发布且不计入 examScore

#### Scenario: 投影区分来源状态与培训结论

- **GIVEN** 来源考试 Candidate 状态与培训统一结论使用不同枚举
- **WHEN** 系统同步逐内容投影或冻结最终快照
- **THEN** `sourceStatus` 保存来源记录的原始状态
- **AND** `resultStatus` 保存培训统一结论
- **AND** schemaVersion=3 的最终快照同时保留这两个字段

#### Scenario: 计划级同步仍可全量补账

- **GIVEN** 历史投影落后于来源事实
- **WHEN** 管理员调用计划级结果同步
- **THEN** 系统按每名未冻结参训人、每个内容项刷新投影并重建聚合
- **AND** 已冻结参训人不得覆盖

#### Scenario: 课程未出分不抹去其他已计分来源

- **GIVEN** 课程尚未产生正式成绩，考试 98 和线下 90 已产生正式成绩且对应内容 `isScored=1`
- **WHEN** 同步并计算该参训人的综合成绩
- **THEN** 课程聚合为空，考试和线下聚合分别为 98、90
- **AND** 计算使用考试和线下来源，不得将三类来源都写为 0

#### Scenario: 题库练习不参与成绩

- **GIVEN** 计划包含题库练习并已有练习反馈
- **WHEN** 同步参训人结果或计算综合成绩
- **THEN** 题库练习不进入任何成绩聚合
- **AND** 结果界面说明其不参与综合成绩

### Requirement: 综合成绩计算必须有可追溯的有效来源

系统 MUST 在计算前刷新当前参训人的未冻结培训结果聚合。课程、考试、线下三类聚合均为空时，系统 MUST 返回 409 / `8805`，且 MUST NOT 新增计算批次。来源为真实 0 分不等同于空来源，仍可按已绑定综合评价规则计算。计算记录与结果界面 MUST 展示该批实际采用的三类来源分数。

#### Scenario: 无可计入来源时拒绝计算

- **GIVEN** 课程、考试、线下均未产生可计入的正式成绩
- **WHEN** 管理员计算综合成绩
- **THEN** 系统返回 409 / `8805`
- **AND** 不创建 `CALCULATED` 记录，也不允许确认
