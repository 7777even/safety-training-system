# Tasks：综合成绩来源可见与空来源保护

> 状态：已完成。Owner：fxw11。

## Task 1：避免空来源生成误导性综合成绩

- 输入：培训逐内容投影、参训人聚合、综合评价规则。
- 输出：当前参训人同步入口、空来源计算保护及 OpenAPI 错误码。
- 前后端影响：后端与 PC 错误展示。
- API 依赖：既有计算接口，新增 8805 错误语义。
- 数据影响：无结构变化；不改历史批次。
- 验收标准：
  - [x] 考试、线下已计分而课程未出分时，计算使用已有来源。
  - [x] 三类来源全空时不插入批次；真实 0 分来源仍可计算。
  - [x] 定向单元测试和 OpenAPI 校验通过。

## Task 2：让计分资格和计算来源可理解

- 输入：草稿阶段内容、结果明细、计算批次来源快照。
- 输出：草稿计分配置、冻结态只读说明及优化后的结果抽屉。
- 前后端影响：PC 前端。
- API 依赖：既有计划详情、培训结果和计算批次接口。
- 数据影响：后续新草稿的请求写入已有 `isScored` 字段。
- 验收标准：
  - [x] 课程/考试/线下可配置且新建默认计分；题库练习固定不计分。
  - [x] 抽屉明确展示每项纳入资格和每批来源分数。
  - [x] 定向 Node 测试、PC typecheck、目标 ESLint 和差异检查通过。
