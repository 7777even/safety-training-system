# Spec Delta：保护独立考试未暂存答案

## ADDED Requirements

### Requirement：独立考试关键操作前保护未暂存答案

系统 MUST 以最近一次成功暂存的全量答案为基线。学员在独立考试作答页编辑答案后，如答案尚未成功暂存，系统 MUST 在手动提交试卷或返回前提示学员先暂存；取消提示或暂存失败时，系统 MUST 不继续提交或返回。

#### Scenario：学员编辑答案后手动交卷

- **GIVEN** 当前独立考试 Attempt 可编辑，且学员对任一答案的本地修改尚未成功暂存
- **WHEN** 学员点击“提交试卷”并确认交卷
- **THEN** 系统提示“暂存并继续”或“留在当前页”
- **AND** 学员确认暂存且暂存成功后，系统才提交试卷

#### Scenario：学员编辑答案后返回

- **GIVEN** 当前独立考试 Attempt 可编辑，且学员对任一答案的本地修改尚未成功暂存
- **WHEN** 学员点击“返回”
- **THEN** 系统提示“暂存并继续”或“留在当前页”
- **AND** 只有暂存成功后系统才返回

#### Scenario：不存在未暂存答案

- **GIVEN** 当前答案与最近一次成功暂存的答案一致
- **WHEN** 学员手动提交试卷或返回
- **THEN** 系统直接继续当前操作，不显示额外暂存确认
