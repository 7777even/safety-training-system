# Tasks：保护独立考试未暂存答案

> 状态：已完成（2026-08-27）。

## Task 1：在独立考试提交与返回前保护未暂存答案

- 状态：已完成（2026-08-27）
- Owner：前端
- 输入：既有独立考试作答页、`saveExamAnswers`、手动交卷/返回逻辑，以及本 Change。
- 输出：独立考试页在手动提交和返回前识别并保护未暂存答案。
- 前后端影响：仅 PC Web；不修改 OpenAPI、后端、数据库或权限。
- API 依赖：既有 `GET /api/exam/learner/attempts/{examAttemptId}`、`PUT /api/exam/learner/attempts/{examAttemptId}/answers`、手动交卷接口。
- 数据影响：仅通过既有暂存接口写入学员答案事实。
- 验收标准：
  1. 加载完成和每次暂存成功后，页面以当前全量答案作为已保存基线。
  2. 学员编辑任一题后，手动提交或返回时先出现“暂存并继续/留在当前页”确认。
  3. 选择“暂存并继续”且暂存成功后，提交或返回继续执行；取消或暂存失败时保持在作答页且不交卷。
  4. 无未暂存答案时不出现额外确认；超时交卷行为不变。
- 测试方式：先在 PC Web 定向测试中写出失败用例，再实施最小代码；运行该定向测试、PC Web typecheck、轻量自审和 `git diff --check`。

完成记录：先新增独立考试未暂存答案保护用例并确认失败；随后以课程考核页同一规则实现答案快照、提交前保护和返回前保护。暂存请求在发送前固定 payload 与快照，避免请求进行时的后续编辑被误标为已暂存。定向测试、PC Web typecheck 通过；规格符合性 Review 与代码质量 Review 均通过。
