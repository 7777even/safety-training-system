# M3 当前机构可引用资源

## ADDED Requirements

### Requirement: 培训资源必须按机构严格隔离

系统 MUST 仅允许培训模板和培训计划引用与自身 `organization_id` 相同的课程、考试和题库资源。父子机构、监管关系、共享或资源授权
MUST NOT 扩大可引用范围。

#### Scenario：查询当前机构资源

- **WHEN** 当前机构查询可引用资源
- **THEN** 系统仅返回归属于当前机构的资源
- **AND** 其他机构资源不出现在结果或分页总数中

#### Scenario：拒绝跨机构资源写入

- **WHEN** 模板或计划内容提交其他机构的资源 ID
- **THEN** 系统拒绝写入
- **AND** 响应不得泄露该资源的名称、所属机构或其他业务信息

### Requirement: 可引用资源必须统一查询

系统 MUST 提供当前登录机构的 `COURSE`、`EXAM`、`QUESTION_BANK` 统一分页查询。当前机构 MUST 由服务端可信身份派生，接口 MUST
NOT 接受可切换机构边界的参数。

#### Scenario：按资源类型分页查询

- **WHEN** 调用者按合法资源类型和关键字查询
- **THEN** 系统按稳定排序返回统一分页结果
- **AND** 每项结果包含资源标识、名称、所属机构、状态和既有引用标识

#### Scenario：调用者没有有效主机构

- **WHEN** 登录用户没有可解析的有效主机构
- **THEN** 系统拒绝查询
- **AND** 不允许通过请求参数指定替代机构

### Requirement: 候选资源必须已发布、启用且可执行

系统 MUST 按课程、考试和题库各自的既有领域状态，只返回已发布、启用且可执行的资源。

#### Scenario：过滤不可用资源

- **WHEN** 当前机构资源处于草稿、停用或不可执行状态
- **THEN** 该资源不出现在候选结果中
- **AND** 该资源不计入分页总数

### Requirement: 计划发布必须复核并冻结资源版本

培训计划发布 MUST 在事务内重新校验资源状态和机构归属。课程和考试 MUST 使用既有版本标识；题库练习 MUST
在开考时由既有考试链冻结题目快照。候选查询 MUST NOT 替代发布校验。

#### Scenario：资源在发布前失效

- **WHEN** 草稿计划引用的资源在计划发布前被停用或变为不可执行
- **THEN** 计划发布被拒绝
- **AND** 不生成不完整的执行关联

#### Scenario：已发布计划保持历史稳定

- **WHEN** 计划发布后源资源发生修改或停用
- **THEN** 已发布计划保留发布时冻结的资源版本事实
- **AND** 历史执行和审计信息不被改写
