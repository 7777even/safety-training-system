# 学员课程学习界面最小实现

## 背景

学员端已经具备课程报名、课程任务读取和学习会话上报接口，但 PC 端仍以任务抽屉展示，无法直接完成素材学习。

## 目标

基于当前已确认的课程、素材和学习会话契约，实现 PC 学员课程学习页面：左侧学习素材，右侧章节目录，并保存学习进度。

## 范围

- PC 学员课程学习页面。
- 章节目录与内容项切换。
- 素材播放/预览入口。
- 学习断点展示与学习会话上报。
- 课程考试入口和直播入口的最小展示。

## 非目标

本 Change 不新增后端接口、数据库结构、评论、笔记、公开统计、移动端同步或高级播放器能力。

后续优化记号见 `tasks.md` 的“后续优化”部分。
