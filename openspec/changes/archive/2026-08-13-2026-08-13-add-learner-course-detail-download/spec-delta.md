# Spec Delta：学员课程简介与受控附件下载

## 新增

### Requirement：本人学习详情聚合冻结课程简介

系统必须在本人报名学习详情中返回开课冻结版本的课程简介，不得回退读取可变课程草稿。

#### Scenario：本人查看课程简介

- **GIVEN** 当前用户拥有报名且开课绑定有效课程版本快照
- **WHEN** 用户查询该报名学习详情
- **THEN** 系统返回冻结的课程编码、名称、简介、教学目标、大纲、考核方式、学分、积分、内容模式、下载模式和封面字段
- **AND** 后续课程草稿修改不改变该开课返回的课程简介

#### Scenario：拒绝他人报名详情

- **GIVEN** 报名属于当前机构的其他用户
- **WHEN** 当前用户查询该报名学习详情
- **THEN** 系统返回 HTTP 403 和既有本人访问错误码
- **AND** 不返回课程、附件、进度或评价信息

### Requirement：本人学习详情聚合冻结课程附件

系统必须按开课冻结版本中的附件引用和顺序返回附件元数据，并根据当前素材与源文件事实表达是否可下载。

#### Scenario：返回可下载附件

- **GIVEN** 冻结课程允许源文件下载且附件启用
- **AND** 当前机构内素材启用、处理成功、具有有效 UPLOAD 源文件记录
- **WHEN** 报名本人查询学习详情
- **THEN** 附件返回 `downloadable=true` 和课程学习域受控 `downloadUrl`
- **AND** 不返回对象存储地址

#### Scenario：解释不可下载附件

- **GIVEN** 课程禁止下载，或冻结附件/当前素材失效，或素材仍在处理，或不存在受支持源文件，或私有存储下载能力未启用
- **WHEN** 报名本人查询学习详情
- **THEN** 系统仍按冻结顺序返回该附件
- **AND** 返回 `downloadable=false`、`downloadUrl=null` 和稳定的 `unavailableReason`

### Requirement：学员附件下载执行课程学习域授权

系统必须通过报名与冻结课程附件关系授权文件下载，不得要求或授予学员后台课程/素材管理权限。

#### Scenario：本人下载冻结课程附件

- **GIVEN** 当前用户是报名本人且报名/开课状态允许下载
- **AND** 冻结课程允许下载，路径素材是启用的冻结附件，当前素材和源文件有效
- **WHEN** 用户调用课程学习域附件下载接口
- **THEN** 系统返回源文件流、安全文件名和内容类型
- **AND** 完整请求、合法单 Range 和非法 Range 分别使用 200、206 和 416

#### Scenario：拒绝越权或非课程附件下载

- **GIVEN** 报名不属于当前用户，或路径素材不在该开课冻结附件中
- **WHEN** 用户请求下载
- **THEN** 系统拒绝请求
- **AND** 不读取或泄漏存储对象及其他素材信息

#### Scenario：下载时文件已失效

- **GIVEN** 详情生成后素材、文件记录或实际存储对象失效
- **WHEN** 用户请求下载
- **THEN** 系统重新执行完整授权与有效性校验并返回 404 或附件不可下载业务错误
- **AND** 不返回过期对象地址

## 修改

- `GET /api/course/learning/enrollments/{enrollmentId}` 在既有报名、进度、评价和会话字段之外增加 `course` 与
  `downloadAssets`。
- 学员本人详情权限保持 `authenticated + 报名本人校验`；管理端 `course:learning:view` 权限不授予学员。

## 不变

- `GET /api/course/learning/enrollments/{enrollmentId}/tasks` 继续提供冻结学习任务，不承担课程简介或文件下载。
- 既有报名、开课、学习进度、完成判定、评价和素材处理规则保持不变。
- 通用 `/api/asset/files/{assetId}/{fileInfoId}` 继续要求后台素材权限，不作为学员下载入口。
- 不修改数据库结构和课程版本快照 schema。
