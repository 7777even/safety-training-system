# Proposal：完成移动端课程考核闭环

> 状态：已于 2026-08-28 获得人工确认，按 `tasks.md` 实施。

## 背景

移动端课程学习页能够识别题库练习和课程测验，但仍将其跳转到独立考试作答页，缺少课程域答案暂存、交卷和结果页，无法依据课程考核结果同步课程内容项状态。

## 目标

1. 学员可在移动端开始、继续和回看课程题库练习及课程测验。
2. 课程作答和结果使用独立移动页面，并与独立考试页面保持统一的移动交互与视觉层级。
3. 课程考核只调用课程域 Contract；同步课程任务状态枚举与实际后端/PC 状态，结果按自动生效事实展示并同步课程内容项完成状态。

## 非目标

- 不修改后端、数据库或权限模型；仅更新 `course.openapi.json` 中课程任务快照的既有状态枚举，使其与已实现的后端/PC 行为一致。
- 不复用或改变独立考试作答、人工发布、防作弊和超时交卷流程。
- 不实现仿真、防作弊或人脸识别能力。
