# Spec Delta：专家查课表

## ADDED Requirements

### Requirement：专家检查版本项目约束

系统 SHALL 仅允许专家检查版本包含分数项和文本意见项，分数项满分合计为 100，且不得配置自动评分规则。

### Requirement：专家查课记录原子提交

系统 SHALL 仅允许拥有评价记录新增和提交权限的登录用户，在运行中计划内对已绑定专家检查版本的一门课程提交一次完整记录；记录提交后不可编辑。

### Requirement：计划内专家查课只读状态

系统 SHALL 返回计划内全部课程的专家查课提交状态和已提交摘要，不将专家检查记录用于综合成绩计算。
