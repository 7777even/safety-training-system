# 修复考试发布后批阅锁定与工作台页签

## 背景

当前已发布正式成绩的作答仍可能进入教师批阅并提交改分，正式成绩缺少不可变的服务端保障。考试和课程工作台以阶段查询参数切换页面，后台
tabs-card 将每个阶段当作独立地址记录，导致同一资源重复出现多个同名页签。考试工作台的基础信息采用高密度表格及长文本滚动区域，与后台详情页的清爽现代风基准不协调。

## 目标

1. 已发布正式成绩的作答不可再批阅或改分，并在教师批阅界面明确呈现只读状态。
2. 同一考试或课程工作台无论切换哪个阶段，后台 tabs-card 仅保留一个资源页签。
3. 调整考试工作台基础信息的展示层级与布局，使其符合后台详情、编辑与工作台页规范。

## 用户价值

正式成绩一经发布即保持可信；管理员在同一工作台内切换阶段不会产生重复页签；考试配置与查看信息更易阅读。

## 范围

- 后端在既有人工批阅写入路径上拦截已发布正式成绩的作答。
- PC Web 批阅页依据作答成绩发布状态只读展示，并与服务端失败结果保持一致。
- PC Web 后台 tabs-card 对考试、课程工作台的阶段查询参数实施资源级去重。
- PC Web 考试工作台基础信息展示样式优化。

## 非目标范围

- 不新增或修改 API Contract、权限模型、数据库结构或迁移。
- 不提供“撤回成绩后再改分”的能力。
- 不改变试卷工作台已存在的单页签行为。
- 不重构与考试、课程工作台无关的 tabs-card 路由。
