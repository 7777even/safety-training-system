# Spec Delta：考试发布后批阅锁定与工作台页签

## ADDED Requirements

### Requirement：正式成绩发布后锁定人工批阅

系统必须将已发布正式成绩的作答视为不可修改的评分事实。任何人工批阅或改分请求均不得更新其答案评分、总分、及格结果或作答状态。

#### Scenario：教师尝试批阅已发布作答

- **GIVEN** 某次作答已发布正式成绩
- **WHEN** 教师通过既有人工批阅入口提交评分
- **THEN** 系统拒绝该请求并保持评分数据不变

#### Scenario：教师打开已发布作答的批阅页面

- **GIVEN** 某次作答已发布正式成绩
- **WHEN** 教师进入该作答的批阅页面
- **THEN** 页面显示不可批阅提示，评分输入与提交操作不可用

### Requirement：工作台阶段切换不重复创建页签

后台必须按工作台资源而非阶段查询参数记录考试和课程工作台页签。

#### Scenario：切换同一考试工作台阶段

- **GIVEN** 管理员已打开一个考试工作台
- **WHEN** 依次切换考试信息、人员配置、发布考试和考试情况阶段
- **THEN** tabs-card 仅保留该考试的一个工作台页签

#### Scenario：切换同一课程工作台阶段

- **GIVEN** 管理员已打开一个课程工作台
- **WHEN** 切换该课程的工作台阶段
- **THEN** tabs-card 仅保留该课程的一个工作台页签

### Requirement：考试基础信息遵循后台详情页视觉层级

考试工作台必须以后台详情页的内容卡和信息分组展示基础信息。

#### Scenario：查看含长文本的考试基础信息

- **GIVEN** 考试包含注意事项或说明等长文本
- **WHEN** 管理员查看考试工作台基础信息
- **THEN** 常规字段与长文本分层展示，长文本自然换行且不出现嵌套表格滚动
