# Proposal：PC 培训执行闭环契约同步

## 背景

培训执行后端已收口课程、考试、题库和线下成绩的结果投影：学员提交事实后自动刷新内容项结果；线下培训改为教师对本场参训人一人一条成绩。PC Web 仍调用已删除的签到接口，且未读取学员专属线下场次详情，导致前后端流程不一致。

## 目标

1. PC 学员培训页严格按最新培训 OpenAPI 进入、查看和刷新结果。
2. PC 教师任务页改为基于参训名单逐人录入线下成绩，并按后端授权动作推进场次状态。
3. 明确展示安排学时与获得学时，避免前端混用两种口径。

## 范围

- PC Web 学员培训 API、培训详情、线下场次详情。
- PC Web 教师任务 API、场次状态操作与线下成绩录入页面。
- 现有培训计划执行结果的学时展示语义及定向回归测试。

## 非目标

- 不修改后端、OpenAPI、数据库、权限或移动端。
- 不恢复签到、签到确认、多成绩项或人工结果同步。
- 不新增监管个人培训记录下钻。
