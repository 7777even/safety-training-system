## Task 3：完成交卷后答题回看

- 状态：已完成
- Owner：AI
- 输入：`GET /api/exam/learner/attempts/{examAttemptId}` 返回的题目快照和已暂存答案
- 输出：交卷后可从考试中心任务卡进入结果页，安全回看本人答题内容；未发布成绩时不泄露正确性、标准答案、得分或解析
- 前后端影响：仅 PC Web；不修改 OpenAPI、后端或数据库
- API 依赖：`GET /api/exam/learner/attempts/{examAttemptId}`
- 数据影响：无
- 验收标准：手动或超时交卷均进入可回看本人答案的结果页；考试中心的 `WAIT_REVIEW` 独立任务可直接进入同一回看页；未发布成绩只显示“我的答案”与等待状态；已发布时仍按服务端字段裁剪显示结果
- 测试方式：Red→Green 结果页定向测试、PC Web typecheck 与受影响 lint

完成记录：先增加“未发布成绩时仅回看本人答案、不得显示评分或解析”的定向用例并观察失败；随后在结果页复用作答快照和已暂存答案，选择题映射为选项键及选项文本，文本题显示提交文本，未答题显示“未作答”。用户澄清入口位置后，补充 `WAIT_REVIEW` 独立任务的“查看答题情况”卡片入口，使用任务的 `currentAttemptId` 打开同一结果页。已发布分支仍只显示服务端实际返回的评分、正确性、标准答案和解析。定向测试 11/11、typecheck、受影响 lint、build 与 `git diff --check` 通过；规格符合性与代码质量自审通过。
