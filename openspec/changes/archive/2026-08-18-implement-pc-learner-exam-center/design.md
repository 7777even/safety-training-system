# Design：PC 学员考试中心

## 边界与入口

- 接口唯一来源为 `docs/api/exam.openapi.json`，所有请求使用既有 `learner-exam.ts` 封装。
- 独立考试按 `availableAction` 驱动开始、续答、等待和结果入口；页面只改善体验，服务端仍是权限与状态真相源。
- `contextType=COURSE` 的任务不调用 `POST /api/exam/attempts/start`，点击后仅导航至 `/portal/class`，由课程任务页使用其已有专用开考流程。

## 任务中心

任务中心以 `/portal/class` 为唯一视觉基准，复用其蓝色学习横幅、状态标签、网格任务卡和分页体验；不使用后台管理的 `admin-*` 容器、筛选表单、表格工作区、面包屑或 tabs-card。请求层保留 `pageNum`、`pageSize`、`query.taskStatus`、`query.examName`、`query.contextType` 的完整契约映射，门户默认页不为未确认的学员检索场景显示后台式筛选区。每张卡片展示契约返回的考试、来源、开放窗口、时长、作答次数、当前尝试、成绩发布与可见成绩字段；系统内部 ID 不直接展示。

## 作答与结果

作答页保留当前题目类型、答题卡、暂存、手动/超时交卷及最小反作弊上报。开始独立考试时提交当前登录用户 ID、稳定幂等令牌、`FIRST`、`PC` 和可由浏览器获得的环境信息；课程内部字段及 `clientIp` 不提交。

交卷后统一进入结果页。结果页始终可读取并回看本人已提交的题干、选项和答案；以 `scoreVisible && scorePublishStatus === 'PUBLISHED'` 作为成绩概览门槛。题目级标准答案、正确性、得分和解析只在对应字段实际返回时渲染，不能以固定文案泄露或猜测策略。

## 风险与验证

- 真实非生产环境未提供前，不将 Mock 结果视为端到端验收；联调阻塞应如实记录。
- 7001、7020、7021、7042 和 HTTP 401/403/404 使用统一中文错误反馈与安全返回路径，不在客户端规避错误状态。
