# 建立项目知识库基础资产

## 背景

安全教育培训系统已完成 Monorepo 与工程规范初始化，但缺少能够长期复用的业务知识基线。现有泳道图明确了园区监管端、企业/培训机构端与学员端的协作链路；功能清单提供了资源、培训、考试、档案、证书与监管等能力输入。

## 目标

在 `docs/` 建立统一的系统、业务、需求、概念数据和术语文档，为后续按业务能力创建 OpenSpec change、设计 API Contract
和实施代码提供可追溯输入。

## 用户价值

- 园区监管方、企业/培训机构和学员相关需求有统一角色边界。
- 团队可按“培训标准制定 → 培训计划 → 课程学习 → 考试 → 成绩分析 → 档案 → 证书 → 监管预警”理解完整业务闭环。
- 前后端在开发前可引用一致的领域语言和模块边界，降低按页面拆分需求的风险。

## 功能范围

- 创建系统总览、业务架构、概念领域模型与技术架构文档。
- 创建系统背景、用户角色、业务领域模块与业务流程文档。
- 创建数据库概念领域模型与业务术语表。
- 将未确认的实现、规则和数据细节明确标注为“暂定”。

## 非目标范围

- 不开发业务代码、页面、接口或 Mock。
- 不定义 API Contract、权限矩阵、数据库表、字段、DDL 或 migration。
- 不确认人脸识别、直播、仿真运行、微信接入和 App 原生能力的实现方案。
