# learner-course-reading Specification Delta

## ADDED Requirements

### Requirement: 学员可分页查看同次开课的评价

系统 MUST 允许有效报名学员分页查看该报名所属开课的全部正常评价，并 MUST 从当前登录人的报名确定开课范围。PC 与移动端 MUST 提供同次开课评价入口。

#### Scenario: 查看同次开课评价

- **GIVEN** 当前登录学员有有效报名，所在开课有多条评价
- **WHEN** 学员从课程详情分页查看评价
- **THEN** 系统按提交时间和评价 ID 稳定排序返回该开课全部正常且未删除的评价
- **AND** 学员未完成学习也可以只读查看
- **AND** 页面可以逐页访问全部评价

#### Scenario: 拒绝越权与退选访问

- **GIVEN** 报名属于其他学员、其他机构或已退选
- **WHEN** 当前用户以该报名 ID 查看评价
- **THEN** 系统拒绝访问，且不返回评价内容

#### Scenario: 匿名评价不泄漏身份

- **GIVEN** 同次开课存在匿名和实名评价
- **WHEN** 其他学员查看评价列表
- **THEN** 匿名项只显示「匿名学员」，不返回真实姓名、用户 ID 或报名 ID
- **AND** 匿名项的提交时间仅显示日期
- **AND** 实名项可显示服务端确认的展示姓名

#### Scenario: 无评价和提交后刷新

- **GIVEN** 学员在 PC 或移动端打开课程详情
- **WHEN** 开课无评价，或本人提交评价成功
- **THEN** 无评价时显示空态；提交后刷新本人评价和同课评价列表
