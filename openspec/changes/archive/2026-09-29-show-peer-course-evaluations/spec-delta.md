# Spec Delta：课程评价同课可见

正式 delta：`specs/learner-course-reading/spec.md`。

## 新增

- 有效报名学员可查看本次开课全部正常、未删除的学员评价；未完成学习不影响只读查看，退选报名不可查看。
- 同课范围由服务端根据本人的报名确定，严禁客户端自行指定他人的报名或开课来扩大可见范围。
- 列表稳定分页；匿名评价在其他学员视角不暴露真实姓名、用户 ID、报名 ID。
- PC 和移动端均提供同课评价入口、分页及空态；本人评价继续通过既有本人详情回看。

## 保持

- 评价提交仍要求课程已完成，且每报名只可提交一次。
- 课程测验/考核结果与课程评价继续分域。
