# 移动端学习任务与素材学习界面调整

## 背景

移动端当前将课程目录和“正在学习”素材预览放在同一个课程详情页中，课程目录浏览与素材学习职责混杂，用户在窄屏设备上难以持续浏览目录并明确当前学习位置。

## 目标

将素材学习迁移到独立的学习界面，并让课程目录成为进入具体素材和切换学习内容的主要入口。

## 用户价值

学员可以从课程目录快速进入具体素材，在同一学习界面查看当前素材、切换课程目录，并通过高亮状态确认当前学习位置。

## 功能范围

- 移动端课程详情/学习任务页移除“正在学习”素材预览区。
- 增加独立的移动端素材学习页。
- 从可学习的课程目录项进入素材学习页。
- 素材学习页上方显示当前素材预览，下方显示按章节组织的课程目录。
- 高亮当前学习目录项，支持在目录中切换素材。
- 复用现有素材预览、学习断点和学习会话上报能力。

## 非目标范围

- 不修改后端 API、数据库结构、权限模型或学习判定规则。
- 不提前接入题库、练习或考试内容项。
- 不实现离线学习、播放器重构或新的素材格式。
