# 设计：移动端学习任务与素材学习界面调整

## 页面结构

### 课程详情/学习任务页

- 保留课程标题、课程进度、课程目录及课程简介/附件区域。
- 移除当前页面中的“正在学习”标题、素材预览区及其相关状态展示。
- 可学习的目录项点击后进入独立素材学习页，并传递 `enrollmentId` 与 `courseItemId`。
- 不可学习项和延期的考试类内容项继续沿用当前禁用行为。

### 素材学习页

- 页面主体只保留两个区域：顶部素材预览/播放区，底部课程目录区。
- 不显示课程大标题、课程进度、课程简介或课程附件等非学习内容。
- 页面顶部显示返回入口、当前素材标题和素材类型。
- 顶部主体区域复用现有 `AssetPreview`，支持当前已实现的预览、受控打开/下载降级及媒体事件。
- 下方显示课程章节和目录项。
- 当前 `courseItemId` 对应的目录项使用明显的选中/高亮样式，并展示学习状态。
- 课程目录默认展开，并提供折叠/展开操作，折叠后保留目录标题和当前课程进度。
- 点击其他可学习目录项时，先提交当前学习会话，再切换素材并刷新高亮状态。
- 初次进入时优先使用 URL 中的 `courseItemId`；参数缺失时回退到第一个可学习的非考试项。

## 路由

在 `pages.json` 增加：

- `pages/course/learning`

页面参数：

- `enrollmentId`：课程报名 ID，必填。
- `courseItemId`：初始素材课程项 ID，可选。

## 数据与 API

复用已确认的 API：

- `GET /api/course/learning/enrollments/{enrollmentId}`
- `GET /api/course/learning/enrollments/{enrollmentId}/tasks`
- `GET /api/asset/assets/{assetId}`
- `GET /api/asset/assets/{assetId}/play-info`
- `GET /api/asset/files/{assetId}/{fileInfoId}`
- `POST /api/course/learning/sessions`

不新增字段，不修改现有 Contract。

## 学习会话

- 复用现有学习会话启动、定时上报、媒体播放计时、断点恢复、切换提交和页面离开提交逻辑。
- 目录切换时先提交当前素材的 `USER_EXIT` 会话，再建立新素材会话。
- 上报失败不阻断素材切换，但保留当前页面可继续学习的行为。

## 视觉与交互

- 参考附件的“上方素材、下方目录”纵向布局。
- 素材预览区优先保证视频、音频播放区域和 PDF 查看/受控打开入口的可用空间。
- 目录项使用卡片式触控区域，保证窄屏下可点击高度。
- 当前项使用主题色边框/背景和“学习中”状态文案高亮。
- 不复刻附件中的设备状态栏、浏览器工具栏或第三方播放器外壳。

## 风险与取舍

- 为避免重复维护学习会话逻辑，学习详情页迁移为独立页面并复用现有实现；课程详情页只保留目录入口。
- 页面切换后仍需通过现有任务接口刷新进度，确保返回课程详情页时看到最新状态。
