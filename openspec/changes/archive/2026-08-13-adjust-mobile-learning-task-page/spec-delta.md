# Spec Delta：移动端学习任务与素材学习界面调整

## ADDED

### Requirement: 独立素材学习界面

移动端 MUST 提供独立素材学习页面，页面上方展示当前素材预览，下方展示课程章节目录，并高亮当前素材对应的目录项。

#### Scenario: 从课程目录进入素材学习

- GIVEN 学员打开课程详情页且存在可学习的课程目录项
- WHEN 学员点击某个可学习目录项
- THEN 系统打开独立素材学习页，并展示该目录项对应的素材

#### Scenario: 切换当前学习目录

- GIVEN 学员位于独立素材学习页且当前课程包含多个可学习目录项
- WHEN 学员点击另一个可学习目录项
- THEN 系统切换素材预览、更新当前目录高亮，并按现有规则提交前一个素材的学习会话

## MODIFIED

### Requirement: 课程详情页职责

移动端课程详情/学习任务页 MUST 移除“正在学习”素材预览区，仅保留课程信息、课程目录和已有课程简介/附件内容；课程目录项作为进入独立素材学习页的入口。
