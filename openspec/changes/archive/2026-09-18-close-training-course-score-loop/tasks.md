# Tasks：补齐培训课程正式成绩闭环

> 状态：已实施，MySQL IT 与真实验收待环境。Owner：fxw11。

## Task 1：培训课程产生正式成绩

- **输入**：本 Change 的 design；课程测验生效事实、课程冻结快照、课程报名。
- **输出**：仅培训绑定课程在完成后写入课程正式成绩。
- **前后端影响**：仅后端。
- **API 依赖**：无新增契约。
- **数据影响**：更新已有课程报名 `finalScore`，不改表结构。
- **验收标准**：单测验 85 分写入 85；两个纳入测验 80/90 写入 85；0 分参与；题库练习不参与；独立课程不写入。
- **测试方式**：`CourseLearningServiceImplTest` Red → Green。
- **完成记录**：课程测验生效与历史补账均复用同一计算器；覆盖多测验平均、0 分、题库练习排除及独立课程隔离。

## Task 2：历史培训结果补账

- **输入**：既有培训结果同步入口、未冻结参训人、Task 1 成绩规则。
- **输出**：同步前补齐历史课程空分并重建培训投影。
- **前后端影响**：仅后端。
- **API 依赖**：复用既有补账接口和权限。
- **数据影响**：仅填充空课程成绩与未冻结投影；不修改冻结结果。
- **验收标准**：历史培训课程空分补齐并投影；已有非空分、冻结结果和独立课程保持不变。
- **测试方式**：`TrainingWorkflowServiceImplTest` 与 `TrainingResultSyncServiceImplTest` 定向测试。
- **完成记录**：既有同步入口仅枚举未冻结参训人，在同步投影前补齐空课程成绩。
