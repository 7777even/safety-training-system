# Design：补齐培训课程正式成绩闭环

## 规则

课程成绩仅在以下条件同时成立时产生：开课有 `planContentId`、报名有 `trainingParticipantId`、课程学习状态为 `COMPLETED`。

候选测验由课程冻结快照按开课完成规则选择：`ALL_REQUIRED_ITEMS` 仅必修内容项，`ALL_ITEMS` 为全部内容项；再筛选内容类型 `QUIZ`。每个候选测验读取其当前课程考生正式分，全部存在才按算术平均得到课程报名 `finalScore`，以 `HALF_UP` 保留两位。题库练习与未纳入的选修测验不参与。

独立开课或独立报名直接跳过该计算，不写 `finalScore`。

## 数据流

```
课程测验结果生效
  → 课程进度与报名状态重算
  → 培训绑定且课程完成时重算课程正式成绩
  → 课程完成事实事件
  → 培训逐内容投影读取课程正式成绩
```

对已完成历史数据，既有“同步培训计划正式来源分项结果”入口先逐个处理未冻结参训人的课程报名缺失分，再按既有逻辑重建投影。该入口不处理冻结参训人，且不触达独立课程。

## 边界

- 0 分必须参与平均，不得按空值处理。
- 课程没有候选测验或候选测验仍待生效时，保持空值；培训内容若配置计分，既有综合成绩缺分门禁继续生效。
- 历史修复只填空值，不覆盖已有课程正式成绩。
