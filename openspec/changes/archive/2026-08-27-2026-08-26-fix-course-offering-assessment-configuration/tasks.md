## Task 8：修正课程考核暂存、终态与结果回看闭环

- 状态：已完成（2026-08-27；规格符合性 Review：通过；代码质量 Review：通过）
- Owner：Codex
- 输入：课程测验重复待批阅、提交后仍显示继续作答、已生效结果回看无答案的线上复现。
- 输出：课程任务对学员仅暴露 `NOT_STARTED`、`IN_PROGRESS`、`WAITING_RESULT`、`RESULT_EFFECTIVE` 状态；课程测验终态不再创建第二份作答；课程有效结果返回本人答案、标准答案与解析；作答页在提交或返回前自动暂存未保存答案，并显示内容项名称。
- 前后端影响：PC Web 与后端 Admin。
- API 依赖：既有课程作答启动、详情、暂存与交卷接口。
- 数据影响：无结构变更；不删除既有历史重复作答记录。
- 验收标准：已提交待批阅的课程测验只能查看已交卷状态，不能再次创建作答；有效结果回看与提交的答案一致；学员修改答案后点击提交或返回均先完成暂存；题库练习与课程测验均显示当前课程内容项名称。
- 测试方式：后端课程任务状态、课程结果读取、课程测验幂等启动的定向测试；PC 页面交互读取测试、typecheck。
