# Proposal：补齐培训计划综合成绩计算与确认 PC 闭环

> 状态：已完成（2026-09-15）。

## 背景

计划可以绑定综合评价表单，后端也已有计算、确认和批次查询接口，但 PC 计划工作台没有操作入口，导致绑定综合评价后无法在正常业务界面完成计划结束前的正式综合成绩确认。

## 目标

在培训计划工作台的参训人结果抽屉中，按当前计划和当前参训人计算、确认并查看综合成绩批次。前端不新增路由、菜单、接口字段或手工 ID 输入。

## 范围

- 新增 PC 评价结果 API 调用与类型，严格映射既有 `evaluation-result.openapi.json`。
- 在计划为 `RUNNING`、存在启用的 `COMPOSITE` 绑定时，允许具备权限的用户逐人计算和确认。
- 展示当前学员的计算批次历史及正式综合成绩。

## 非目标

- 不修改后端、OpenAPI、权限模型、数据库或评价计算规则。
- 不提供批量计算、自动确认、跨计划成绩中心或手工同步培训结果。

## 前后端影响

仅 PC 前端；后端以现有 OpenAPI 为准。
