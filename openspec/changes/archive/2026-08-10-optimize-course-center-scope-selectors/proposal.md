# Proposal：优化课程中心素材与组织范围选择

## 背景

课程中心的素材选择弹窗会对当前分页的每一条素材调用详情接口；人员选择和开课参与范围弹窗对普通管理员仍展示并查询机构列表；参与范围规则的枚举直接显示
Contract 值。这些行为增加了无必要请求，并与当前“普通管理员仅操作本人机构、superAdmin 才可跨机构”的使用边界不一致。

## 目标

1. 素材选择列表仅使用分页接口返回的字段，只有已选素材回显或用户主动预览时才请求详情。
2. 普通管理员在人员选择和开课参与范围中固定使用登录会话的机构，不展示、不请求机构列表；拥有既有 `system:tenant:list`
   租户管理权限的 superAdmin 保留跨机构选择。
3. 讲师选择基于当前机构的人员分页接口，而不是常规机构列表。
4. 参与范围的规则对象和解析模式全部使用中文 `{ label, value }` 映射。

## 非目标

- 不新增或修改后端 API、权限点、数据结构和跨机构授权语义。
- 不实现素材转码、播放或预览能力扩展。
- 不修改学员端页面、课程业务状态流转或动态菜单路由。
