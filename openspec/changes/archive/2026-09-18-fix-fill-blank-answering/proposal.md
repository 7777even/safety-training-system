# Proposal：填空题按空位作答

## 已确认决策

填空题不再使用一个文本框和约定分隔符。系统按题目冻结时已配置的空位，为学员展示对应数量的输入框，并按空位序号保存答案项。

## 范围

1. 作答快照新增不含正确答案的 `blankCount`，供 PC Web 和移动端渲染空位。
2. 两端填空题使用一个空位一个输入框，暂存为 `BLANK` 答案项，空位键为从 `1` 开始的序号。
3. 恢复答题、答题卡已答状态和自动判分均以全部空位已填写为准。

## 非目标

- 不改变题目编辑时的标准答案配置、填空答案归一化或评分方式。
- 不向未提交作答下发正确答案、可选答案或答案文本。
