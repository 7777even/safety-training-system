# Proposal：PC Web 培训接口分层适配

## 背景

后端已完成 `align-training-layer-apis` 与 `unify-training-course-exam-capability`：模板复制、标准检查、计划执行和课程/考试来源边界均已由 OpenAPI 定义。PC Web 仍保留手工复制模板、模板强制本期执行配置、标准规则自动带入课表等旧调用方式。

## 目标

1. 按 `docs/api/training.openapi.json` 适配培训标准、模板、计划和学员培训详情。
2. 让模板复制与课程/考试来源判断完全使用后端职责和返回字段。
3. 保留当前门户课程列表与培训详情的已修改视觉体验。

## 范围

- PC Web 培训 API 类型、计划/模板工作台、学员培训详情和定向回归测试。
- 管理端计划发布预检的 8156、模板复制的 8157/8158 中文提示。

## 非目标

- 不修改后端、OpenAPI、数据库、权限或移动端。
- 不改变课程、考试、题库、线下内容的业务生命周期。
- 不把培训来源对象从独立课程/考试管理列表中隐藏。
