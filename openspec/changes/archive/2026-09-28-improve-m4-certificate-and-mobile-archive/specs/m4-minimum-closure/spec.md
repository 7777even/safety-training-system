## ADDED Requirements

### Requirement: 双端学员证书列表必须能识别对应业务

系统 MUST 在证书列表返回可空的来源名称，PC 与移动端 MUST 使用本人受控证书文件展示图片、优先展示来源名称并保留来源类型及证书编号。来源名称缺失时 MUST 用类型和来源 ID 作为可追溯兜底。

#### Scenario: 学员查看三类证书

- **GIVEN** 学员持有课程、考试或培训计划签发的证书
- **WHEN** 进入 PC 或移动端「我的证书」
- **THEN** 可直接识别证书图片、来源名称和来源类型
- **AND** 可继续在线查看和下载本人证书

### Requirement: 移动档案必须区分培训进行状态与正式结果

系统 MUST 在培训类型名称缺失时提示名称待补全；未结束培训 MUST 展示进行状态而不展示尚未结算的结果缺失；培训结束后 MUST 展示正式结果。

#### Scenario: 培训进行中且结果尚未完整

- **GIVEN** 学员有进行中、结果投影尚未完整的培训
- **WHEN** 查看「我的培训档案」
- **THEN** 页面显示进行中
- **AND** 不显示结果待补全
