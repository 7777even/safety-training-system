# M4 证书和移动档案展示增量规格

## 证书

- 证书列表 MUST 提供可空 `sourceName`，双端 MUST 优先展示来源业务名称，并标明课程、考试或培训类型。
- 双端证书列表 MUST 使用本人受控文件端点展示证书图片，加载失败 MUST 有可读占位；查看和下载 MUST 继续校验本人身份。

### Scenario：学员识别证书对应业务

- **GIVEN** 学员持有课程、考试或培训证书
- **WHEN** 进入双端「我的证书」
- **THEN** 可直接看到证书图片、来源名称、来源类型和证书编号

## 移动培训档案

- 培训类型名称缺失时 MUST 显示「类型名称待补全」，MUST NOT 暗示计划未选择类型。
- 未结束培训 MUST 展示进行状态，MUST NOT 将尚未结算的 `INCOMPLETE` 作为缺陷提示；结束后 MUST 展示正式结果。

### Scenario：进行中的培训

- **GIVEN** 学员有进行中且结果尚未完整的培训
- **WHEN** 查看「我的培训档案」
- **THEN** 看到「进行中」且不看到「结果待补全」
