# Proposal：M4 双端证书展示与移动档案文案优化

## 状态

- 已人工确认（2026-09-28）：用户确认双端证书图片、来源名称、移动端证书 UI 与培训档案文案优化。
- 本 Change 覆盖旧移动端 Change 的「不改 PC 证书页」「缺名称显示未分类」「进行中显示结果待补全」展示约束；其本人权限与不导出档案 PDF 的边界继续适用。

## 功能项与目标

- 功能项 50「个人中心：支持个人信息完善、查看证书、绑定微信、修改密码等操作」：双端证书卡直接展示受控证书图片与对应课程、考试、培训名称。
- 功能项 57「我的培训档案：展示学员的培训任务统计，统计不同培训类型下培训任务的数量，查看培训结果，支持查看每个培训下的课程考试记录」：缺类型名称给准确提示；未结束培训不把未结算结果显示为缺陷。

## 范围

- 复用本人证书文件端点与现有三类来源主数据；证书列表新增来源名称字段，无新端点、权限、依赖或数据库变更。
- PC 门户证书卡、移动端证书卡和移动端档案列表定向调整。
- 真实登录态验证须和静态、自动化验证分别记录。
