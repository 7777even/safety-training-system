# M4 证书签发来源隔离增量规格

本 Change 不新增超出 `openspec/specs/m4-minimum-closure/spec.md` 的产品能力，只把功能项 19
「证书可配置于理论考试、课程和培训」的**来源语义**落实为可触发、可配置、可区分的事实。

## 来源语义

- 证书达标来源 MUST 是三类彼此独立的来源：**独立课程、独立理论考试、培训结果**；判据是来源对象
  MUST NOT 属于任何培训计划。
- 三类来源 MUST 各以自身主数据标识触发规则：课程 `course_id`、理论考试 `exam_id`、培训 `training_plan_id`。
- 系统 MUST NOT 以开课实例（`course_offering_id`）、考核执行实例（`assessment_execution_id`）等
  运行期标识充当规则来源标识。

## 触发口径

- 独立课程：学员该课程学习状态首次达到 `COMPLETED` 即为达标，不设及格线。
- 独立理论考试：独立指派考生的正式结论达到 `PASSED` 即为达标；成绩经人工发布或自动生效 MUST 都能触发。
- 培训结果：培训整体结果达到 `PASSED` 即为达标。
- 培训计划内引用的课程与考试 MUST 只参与该培训的结果判定，MUST NOT 单独触发课程或理论考试证书。
- 课程内考核 MUST 归属课程，MUST NOT 触发理论考试证书。
- 同一学员、同一来源对象、同一模板 MUST 幂等，重复判定 MUST NOT 产生第二张证书。

## 来源候选

- `COURSE` 候选 MUST 只包含已发布的独立课程主数据。
- `EXAM` 候选 MUST 只包含已发布的线上理论考试主数据，并 MUST 排除培训计划运行期派生的考试。
- `TRAINING` 候选 MUST 只包含已发布或进行中的培训计划。
- 既有已绑定来源在后续不可绑定时，规则详情 MUST 仍按原 ID 返回并尽力解析名称。

## 来源唯一性

- 同一来源对象（`source_type` + `source_id`）MUST 在启用态下至多存在一条签发规则。
- 新建规则或把既有规则更新为启用态时，若该来源已存在其他启用规则，系统 MUST 拒绝该操作并给出明确错误，
  MUST NOT 落库。
- 禁用态规则 MUST NOT 参与该约束；同一来源 MAY 保留多条禁用规则作为历史。

## 来源展示

- 签发规则的来源类型与来源对象 MUST 在界面上自解释，使用「独立课程 / 独立理论考试 / 培训计划」口径，
  使管理员能区分培训内引用对象与独立对象。
- 候选与列表回显 MUST 展示来源编码与名称；来源无法解析时 MUST 保留编号兜底，MUST NOT 显示空白。

## 数据清理

- 由来源标识错配产生的历史证书 MUST 定向逻辑删除，MUST NOT 物理删除，MUST NOT 改写其余历史证书。
- 清理 MUST NOT 变更表结构、索引、权限或正式初始化数据。
