# Proposal：对齐学员端线下场次状态

## 背景

教师开始线下场次后，场次实体已变为“进行中”，但学员培训详情中的线下内容卡仍显示“待开始”。当前页面将学员个人完成结果作为场次状态展示；在线下成绩尚未录入时，个人完成结果按业务规则保持“待开始”，因而与实际场次状态混淆。

## 目标

1. 学员培训详情的线下内容卡显示教师实际推进的场次状态。
2. 个人完成状态继续反映成绩和完成结果，不因场次开始而被错误标记完成。
3. 学员线下场次详情同时清晰展示“场次状态”和“完成状态”。

## 范围

- 为学员培训结果项中 `OFFLINE` 内容补充可空 `sessionStatus`，从当前线下场次读取。
- PC Web 学员培训详情的线下卡优先显示 `sessionStatus`；课程、考试和题库仍显示既有个人结果状态。
- PC Web 学员线下场次详情单独展示场次状态和完成状态。
- 同步 OpenAPI、后端测试和 PC Web 定向回归测试。

## 非目标

- 不改变线下成绩是个人完成依据的规则。
- 不改变场次状态机、教师权限、评分接口、学时计算或数据库结构。
- 不修改移动端；移动端适配另开。
