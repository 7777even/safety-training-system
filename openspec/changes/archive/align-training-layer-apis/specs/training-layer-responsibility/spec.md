# Spec Delta：training-layer-responsibility

## ADDED Requirements

### Requirement: 培训各层只产出本层对象

系统 MUST 将培训类型仅作为学时与工种尺子保存；将培训标准规则仅作为检查口径保存；将培训模板阶段仅作为可引用课表保存；将培训计划作为本期实例保存。系统
MUST NOT 提供把类型学时展开为标准规则、或把标准规则展开为模板/计划阶段的接口。

#### Scenario：保存标准指定课程规则

- **WHEN** 管理员在草稿标准中保存一条 `COURSE` 规则并指定已发布课程
- **THEN** 系统只写入标准规则行
- **AND** 不得创建或修改任何模板阶段、计划阶段

#### Scenario：不存在标准带入模板接口

- **WHEN** 调用方请求将标准规则转换为模板阶段
- **THEN** 系统不提供此类操作
- **AND** 模板阶段只能通过模板阶段替换接口写入

### Requirement: 模板到计划是唯一合法课表复制

系统 MUST 仅在创建计划携带合格 `sourceTemplateId`、或草稿计划调用 apply-template 时，将已发布同类型模板的阶段与内容复制到计划。复制后计划
MUST 允许继续修改课表，且 MUST NOT 回写模板。

#### Scenario：创建计划并复制模板

- **GIVEN** 已发布模板与计划选择同一培训类型
- **WHEN** 调用方创建计划并传入该模板 ID
- **THEN** 系统创建草稿计划并复制模板阶段与内容引用
- **AND** 模板上若有执行配置则作为计划内容默认值，没有则计划侧为空

#### Scenario：草稿覆盖复制须显式确认

- **GIVEN** 草稿计划已有阶段
- **WHEN** 调用方对同一计划调用 apply-template
- **THEN** 系统按新模板覆盖计划阶段与内容
- **AND** 仅更新基本信息中的来源模板 ID 不得复制或覆盖课表
