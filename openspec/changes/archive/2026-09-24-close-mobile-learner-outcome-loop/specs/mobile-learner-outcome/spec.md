## ADDED Requirements

### Requirement: 个人中心提供学员成果入口

移动端个人中心 MUST 在既有「我的课程 / 我的考试 / 我的培训」之外提供「我的证书」与「我的培训档案」两个入口。
入口 MUST 使用既有 tabBar 或页面栈机制，MUST NOT 引入 PC 的导航层级或密集表格结构。

#### Scenario: 学员从个人中心进入成果页

- **GIVEN** 已登录的学员
- **WHEN** 打开个人中心
- **THEN** 可见「我的证书」与「我的培训档案」入口
- **AND** 点击后进入对应页面而不是停留在个人中心

### Requirement: 学员查看与下载本人证书

系统 MUST 只返回当前登录学员本人的证书；证书列表 MUST 展示证书名称/编号、来源类型与签发时间。
学员 MUST 能在线查看证书原件并下载；证书文件 MUST 经既有受控端点按证书 ID 读取，
MUST NOT 暴露可直接访问的文件地址。

#### Scenario: 查看并下载本人证书

- **GIVEN** 已登录且持有已签发证书的学员
- **WHEN** 进入「我的证书」并选择一张证书
- **THEN** 页面展示该证书的编号、来源类型与签发时间
- **AND** 可在线查看并下载原件

#### Scenario: 无证书时的空态

- **GIVEN** 已登录但暂无已签发证书的学员
- **WHEN** 进入「我的证书」
- **THEN** 页面展示空态说明而不是报错或空白页

### Requirement: 我的培训档案按培训类型汇总

系统 MUST 基于学员本人的培训任务提供档案视图，MUST 按培训类型汇总并展示该类型下的培训任务数量。
任务项 MUST 至少展示计划名称、培训类型、培训期间、进行状态与培训结果。

#### Scenario: 按培训类型统计任务数量

- **GIVEN** 学员参加了多个培训类型的培训任务
- **WHEN** 进入「我的培训档案」
- **THEN** 页面按培训类型分组展示各类型的任务数量
- **AND** 每个任务展示其状态与培训结果

### Requirement: 培训类型必须以中文名称展示

学员侧培训任务 MUST 返回培训类型名称（`trainingTypeName`）；前端 MUST NOT 直接展示培训类型主键或英文枚举码。
类型名称缺失时 MUST 给出可读兜底，MUST NOT 渲染空白。

#### Scenario: 展示培训类型名称

- **GIVEN** 学员的一条培训任务所属培训类型存在
- **WHEN** 查询该学员的培训任务
- **THEN** 返回结果包含该类型的名称
- **AND** 移动端按名称展示而不是数字 ID

### Requirement: 进入期次查看课程考试记录

「我的培训档案」的任务项 MUST 能进入该期培训的既有详情页，用于查看课程、理论考试、题库练习与线下场次的记录。
系统 MUST 复用既有学员培训详情能力，MUST NOT 在档案页重复实现内容明细。

#### Scenario: 查看某期培训的课程考试记录

- **GIVEN** 学员在「我的培训档案」中看到某一期培训
- **WHEN** 点击进入该期
- **THEN** 打开该期培训详情并展示其内容项与结果入口
- **AND** 已结束的培训只允许查看结果，不允许重新进入作答

### Requirement: 移动端不承担管理端档案能力

移动端 MUST NOT 提供档案维护、归档、企业档案或跨人员查询能力；这些能力 MUST 保持仅 PC 管理端可用。
学员 MUST NOT 通过移动端读取他人证书或他人培训档案。

#### Scenario: 学员无法读取他人数据

- **GIVEN** 已登录的学员
- **WHEN** 请求证书或培训任务
- **THEN** 结果只包含本人数据
- **AND** 移动端不提供按人员主键查询他人档案的入口
