# 移动端学员成果增量规格

## 入口

- 个人中心 MUST 在既有三个入口之外提供「我的证书」与「我的培训档案」。
- 入口 MUST 走既有 tabBar / 页面栈机制，MUST NOT 复制 PC 的导航层级。

## 我的证书

- 系统 MUST 只返回当前登录学员本人的证书，MUST 支持在线查看与下载。
- 证书文件 MUST 按证书 ID 经既有受控端点读取，MUST NOT 暴露可直接访问的文件地址。
- 证书列表 MUST 展示编号、来源类型与签发时间；无证书时 MUST 给空态而不是报错或空白页。

### Scenario：查看并下载本人证书

- **GIVEN** 已登录且持有已签发证书的学员
- **WHEN** 进入「我的证书」并选择一张证书
- **THEN** 展示编号、来源类型与签发时间
- **AND** 可在线查看并下载原件

## 我的培训档案

- 系统 MUST 基于学员本人培训任务提供档案视图，MUST 按培训类型汇总并展示各类型的任务数量。
- 任务项 MUST 展示计划名称、培训类型、培训期间、进行状态与培训结果。
- 任务项 MUST 能进入该期既有培训详情查看课程考试记录；系统 MUST NOT 在档案页重复实现内容明细。

### Scenario：按培训类型统计任务数量

- **GIVEN** 学员参加了多个培训类型的培训任务
- **WHEN** 进入「我的培训档案」
- **THEN** 按培训类型分组展示各类型任务数量
- **AND** 每个任务展示状态与培训结果

## 培训类型名称

- 学员侧培训任务 MUST 返回 `trainingTypeName`；前端 MUST NOT 直接展示类型主键或英文枚举码。
- 名称缺失时 MUST 给出可读兜底，MUST NOT 渲染空白。

## 边界

- 移动端 MUST NOT 提供档案维护、归档、企业档案或跨人员查询；这些能力保持仅 PC 管理端可用。
- 学员 MUST NOT 通过移动端读取他人证书或他人培训档案。
- 本 Change MUST NOT 改动 PC 端已交付的档案与证书页面，MUST NOT 给学员开放 `archive:*` 管理端权限。
