# 任务

## T1 独立考试防作弊策略闭环（实现完成，待真实验收）

- **Owner**：前后端
- **输入**：管理员保存的 `isAnticheatEnabled`、`isWatermarkEnabled`。
- **输出**：冻结执行快照、学员作答详情与 PC/移动端按开关执行的切离、复制/剪贴板与右键事件审计和水印。
- **前后端影响**：考试策略契约、数据库快照、PC Web、移动端。
- **数据影响**：新增默认关闭列及迁移。
- **验收**：关闭时不记录切离、复制/剪贴板或右键事件且无水印；开启后两端记录切离，PC 与移动 H5 阻止并记录复制、剪切、粘贴与右键，且渲染水印；不产生强制交卷。
- **测试**：后端快照/作答详情测试；PC、移动定向测试与类型检查。

## T2 学员端考试策略显示闭环（已完成）

- **Owner**：前后端
- **输入**：冻结的答案详情、解析与成绩展示策略。
- **输出**：服务端正确裁剪，PC/移动仅展示允许的成绩、答案和解析。
- **前后端影响**：学员作答详情服务与两端结果页。
- **数据影响**：无新增业务数据。
- **验收**：`SUBMITTED` 不依赖成绩发布；`PUBLISHED` 仅成绩发布后可见；关闭解析或成绩时对应内容不返回、不显示。
- **测试**：服务层策略组合测试及两端定向回归。

## T3 延期考试策略列标注（已完成）

- **Owner**：后端。
- **输入**：已从考试编辑与详情摘要隐藏的 11 个延期策略字段、统一“暂时隐藏”注释格式。
- **输出**：最新 init SQL 与增量 migration 中的列注释一致，schema version 递增。
- **前后端影响**：仅后端数据库资产；不修改前端，不改变 OpenAPI 字段。
- **API 依赖**：无契约变化，既有兼容字段保留。
- **数据影响**：只修改列 COMMENT，不删除列、不改类型、不改历史值。
- **验收**：11 列仍存在，COMMENT 均以“【暂时隐藏】”开头并包含原用途及重新启用约束；水印、防作弊总开关、端侧、补考和结果可见性列不受影响。
- **测试**：先补迁移集成断言使其失败，再新增 migration 和 init SQL 修改并定向运行 `FlywayMigrationIT`；执行
  `git diff --check`。

## T3 管理端反作弊行为证据展示（实现完成，待真实验收）

- **Owner**：前端
- **输入**：反作弊事件返回的 `eventType`、`clientPayloadJson` 与可选 `evidenceFileId`。
- **输出**：可读的行为证据摘要及详情入口，真实附件仅作关联标识。
- **前后端影响**：PC Web 批阅页；复用既有接口，不改后端或契约。
- **数据影响**：无。
- **验收**：无附件事件不再出现空白证据列；可识别客户端来源并查看详情；有附件时明确标识 ID。
- **测试**：PC 批阅页定向静态测试与类型检查。
