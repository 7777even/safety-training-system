# Tasks：完善考试工作台步骤控制与试卷默认配置

> 状态：Task 1～2 已完成

## Task 1：限制新建考试的工作台步骤访问

- 状态：已完成
- Owner：Codex
- 输入：考试工作台当前步骤状态、创建态考试 ID 与既有步骤导航样式。
- 输出：新建态后续步骤按钮禁用；无效查询参数回落至考试信息步骤；已发布考试情况展示规则不变。
- 前后端影响：仅 PC Web；前端以 OpenAPI 为准，不修改后端、接口、权限或数据结构。
- API 依赖：无新增调用。
- 数据影响：无。
- 验收标准：新建态只能操作“设置考试信息”；创建后保留原有人员配置和发布操作；草稿不显示考试情况。
- 测试方式：先增加步骤禁用及查询参数回落的自动化断言，观察失败后实现；执行目标前端测试、类型检查和轻量自审。

## Task 2：按所选试卷版本默认带入考试规则

- 状态：已完成
- Owner：Codex
- 输入：已发布试卷版本候选、`PaperVersionVO` 及考试创建表单。
- 输出：选择试卷后默认带入时长、及格比例、题目顺序和多选题计分方式，并保留既有分类和封面回填。
- 前后端影响：仅 PC Web；前端以 OpenAPI 为准，不修改后端、接口、权限或数据结构。
- API 依赖：`GET /api/paper/papers/versions/{paperVersionId}`。
- 数据影响：保存时仍使用既有考试创建字段，不新增数据。
- 验收标准：选择试卷版本后四项值与版本详情一致；详情读取失败不覆盖当前值；编辑已有考试不触发替换。
- 测试方式：先增加试卷详情调用和四字段回填的自动化断言，观察失败后实现；执行目标前端测试、类型检查和轻量自审。
