# 素材库前端上传与预览

## 背景

后端已提供 `SysFileInfoController` 与 `SysFileMultipartController` 接口，前端需要在不修改后端和 OpenAPI 的前提下完成素材库上传、素材创建、转码状态展示和预览入口。

## 目标

- PC 管理端统一完成小文件上传与大文件分片上传。
- 上传成功后基于现有素材接口创建素材，并展示异步处理状态。
- 统一图片、视频、音频、PDF、Office 派生 PDF、文本和不支持格式的预览行为。

## 非目标

- 不修改后端 Java、数据库或 OpenAPI。
- 暂不开发课程学习门户、学员播放授权和学习进度。
- 暂不承诺压缩包、CAD、宏文件等特殊格式在线预览。
