# Proposal：同步教学任务菜单与初始化权限

## 背景

当前线上菜单树已出现“教学任务”页面节点，但该节点没有 `training:teacher:task` 权限且未归属应用中心模块；初始化菜单数据也没有该节点。门户培训中心同样缺少“培训列表”的 `training:learner:task` 按钮节点，导致新建库与线上菜单配置不一致。

## 范围

- 在培训管理下增加菜单 `9565`“教学任务”，绑定既有 `training:teacher:task`。
- 在门户培训中心下增加按钮 `9564`“培训列表”，绑定既有 `training:learner:task`。
- 同步初始化菜单、前端菜单树基准、菜单角色矩阵和既有数据库的数据迁移。

## 非目标

- 不新增、拆分或修改后端权限码、接口、角色模型和教师任务页面。
- 不改变教师任务的场次归属校验或 `availableActions` 动作判定。
