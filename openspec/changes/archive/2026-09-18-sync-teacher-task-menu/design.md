# Design：同步教学任务菜单与初始化权限

“教学任务”页面访问、任务列表/详情读取、场次推进和线下成绩保存都使用既有 `training:teacher:task`；页面不创建 `START`、`COMPLETE`、`CANCEL` 或“录入成绩”等虚构按钮权限。后端仍根据教师本人场次归属和 `availableActions` 控制可见动作。

菜单 `9565` 位于 `9530` 应用中心的 `800` 培训管理目录，组件为 `business-center/training/teacher-tasks/index`，排序为 0。菜单 `9564` 位于门户培训中心 `9527` 下，为排序 0 的功能节点。

`menus.json` 仅在初始化时插入不存在的菜单 ID，不能修复已部署库中已存在但 `perms` 为空的 `9565`。因此迁移须幂等地插入 `9564`，并将 `9565` 更新为正确的父级、组件、权限、图标、排序和模块归属。
