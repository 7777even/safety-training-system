# Proposal：按中山 50 功能项重整 M5 最小闭环

## 状态

- 状态：已归档（2026-09-20 lims 确认「后端可交互即可」）
- 风险级别：L4（删除既有业务 API/代码、调整权限与 OpenAPI、修改机构类型语义及数据库 COMMENT）
- 原则：不删除现有表、列、索引和历史数据；确认后删除超范围业务代码，并通过新 migration 修改 COMMENT。

## 背景

旧 M5 将企业、学员、教师工作台，课程、考试、培训、结果通用状态统计，通用下钻、通用导出、监管汇总、可配置预警规则和完整预警处置工单一次性纳入，并按“纯后端完成”关闭里程碑。该设计存在三类偏差：

1. 中山 50 未要求教师工作台、通用指标平台、可配置预警规则和分派/评论/忽略/重开流程；
2. 中山 50 明确要求的园区统计、学习情况指标、数据中心二级页面、快捷入口和真实导出没有完成；
3. 当前统计主要是业务对象状态计数，导出使用占位文件，不能形成真实用户闭环。

本 Change 以 `docs/product/功能项中山50.csv` 为唯一原始范围上限，重整 M5 为“监管工作台与学时预警 + 企业工作台”的最小闭环。

## 覆盖功能项及原文语义

| 功能项 | 纳入 M5 的原文语义                                                       |
|-----|-------------------------------------------------------------------|
| 1   | 园区监管工作台；查看监管企业/培训机构培训情况、全园区企业数据、培训情况、培训类型、特种作业培训、培训机构信息和企业培训人员统计。 |
| 2   | 展示待查看预警；查看培训计划预警列表；将培训类型与实际培训计划对比，计划不满足培训类型设置学时时产生预警；数据支持导出。      |
| 3   | 快捷跳转证书管理、课程制作和数据中心；数据中心进入企业/培训机构数据大屏及二级数据页面。                      |
| 4   | 按机构分类创建受监管企业/培训机构，支持查看、编辑、授权、管理，并可进入企业/培训机构管理中心。                  |
| 7   | 监管端学习情况统计：员工账号数、上课次数、上课人数、参与课程数、人均上课次数和参与率。                       |
| 8   | 企业管理员工作台由功能模块和数据分析模块组成，支持快捷进入管理功能。                                |

功能项 5、6 的培训类型和培训计划模板是 M5 的上游事实，不在本 Change 重复建设。功能项 18、25、41 的考试、课程和培训专项统计应分别归属对应业务域，不能由
M5 的通用状态计数代替。功能项 47 的学员首页独立实施，不纳入 M5。

## 目标

1. 建成园区监管工作台、数据中心二级页面和功能项明确列出的真实统计。
2. 建成固定的培训计划学时不足自动预警、待查看列表、详情、下钻和真实导出。
3. 复用并补齐受监管机构管理，不建设第二套机构主数据。
4. 建成企业管理员最小工作台，不建设教师工作台或重复学员首页。
5. 删除无功能项依据的通用 OPS、可配置预警和人工处置业务代码；SQL 保留并标注用途与隐藏状态。
6. 纠正 M5 完成状态，只有监管端、企业端、后端、权限、数据库和真实导出全部验收后才能关闭。

## 非目标

- 不建设教师工作台或教师任务中心。
- 不在 M5 建设学员首页、消息中心或多渠道通知。
- 不建设通用 OLAP、任意维度分析、指标字典或自定义报表平台。
- 不用通用状态计数代替功能项 18、25、41 的专项统计。
- 不提供预警规则 CRUD、自定义指标/运算符/阈值、线上占比预警或预警级别配置。
- 不提供预警分派、评论、人工关闭、忽略和重开工单流程。
- 不提供导出任务中心，不允许占位文件 ID。
- 不删除数据库表、列、索引或历史记录。

## 对既有规格的影响

本 Change 经确认并实施后，取代归档 Change `2026-07-24-implement-ops-regulation-warning` 的产品范围、验收口径和完成结论。原
Change 仅作为历史实现记录。

## 人工确认关卡

确认本 Change 表示接受以下决策：

1. M5 核心是监管工作台、学习统计和培训计划学时预警；企业工作台作为独立最小 Task。
2. 预警规则固定来自培训类型初培/复审学时，不向用户提供规则配置。
3. 学时预警在培训计划保存后自动刷新，监管人员不手工执行检测。
4. 预警只提供待查看/已查看；计划修正后由系统自动结束当前预警，不提供人工处置工单。
5. 监管统计导出采用真实 UTF-8 CSV 作为最小格式，不引入新的表格依赖。
6. SQL 保留不等于功能保留；隐藏能力不得保留公开 Controller、菜单、权限或 OpenAPI。
7. “机构授权”的具体业务含义尚未确认。实施机构管理 Task 前必须由人工明确是账号启停、功能授权、监管关系还是其他授权；AI
   不自行定义权限模型。
8. M5 当前状态从“已完成”调整为“部分完成”，直至真实端到端验收通过。
