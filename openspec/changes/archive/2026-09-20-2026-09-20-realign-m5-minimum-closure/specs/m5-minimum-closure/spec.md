## ADDED Requirements

### Requirement: M5 必须只暴露中山 50 功能项要求的产品能力

系统 MUST 只保留可追溯到功能项 1、2、3、4、7、8 且构成最小闭环所必需的对外能力。无功能项依据且不是必要内部机制的能力 MUST
删除公开代码、API、菜单、权限和 OpenAPI；既有数据库结构和历史数据 MUST 保留并明确标注隐藏状态。

#### Scenario: 收口超范围能力

- **GIVEN** 既有 M5 提供教师工作台、通用状态统计、可配置预警和人工处置流程
- **WHEN** 本 Change 实施
- **THEN** 系统删除对应公开产品入口
- **AND** 保留既有数据库结构与历史数据
- **AND** 使用标准 COMMENT 标注原用途和隐藏状态

### Requirement: 监管工作台必须展示功能项规定的园区数据

系统 MUST 向有权监管用户展示企业/培训机构、培训计划、培训类型、特种作业、参训人员和待查看预警概览，并提供证书、课程制作和数据中心快捷入口。

#### Scenario: 监管人员查看园区概览

- **GIVEN** 当前登录用户属于监管租户并具有监管工作台权限
- **WHEN** 打开监管工作台
- **THEN** 系统展示规定的园区概览
- **AND** 快捷入口不绕过目标模块权限

### Requirement: 学习统计必须使用统一且可下钻的最小口径

系统 MUST 按 Design 第 5.2 节统一计算员工账号数、上课次数、上课人数、参与课程数、人均上课次数和参与率，并允许从园区下钻到机构和明细。

#### Scenario: 园区与机构统计一致

- **GIVEN** 园区下存在多个机构及真实课程报名
- **WHEN** 监管人员分别查看园区汇总和机构明细
- **THEN** 园区汇总等于机构明细的同口径聚合

### Requirement: 培训计划学时不足必须自动产生预警

系统 MUST 在计划保存后自动比较安排总学时与培训类型按初培/复审确定的要求学时，不向用户提供规则配置或手工检测。

#### Scenario: 保存学时不足计划

- **GIVEN** 企业培训计划已选择培训类型和培训性质
- **WHEN** 保存后的安排总学时低于对应要求学时
- **THEN** 系统自动生成或刷新一条待查看预警
- **AND** 记录计划学时、要求学时和差额
- **AND** 重复保存不生成重复预警

#### Scenario: 计划补足学时

- **GIVEN** 当前计划存在有效学时预警
- **WHEN** 企业将计划学时修正为满足要求
- **THEN** 系统自动结束当前预警
- **AND** 默认列表不再显示该预警

### Requirement: 监管预警必须只提供查看闭环

系统 MUST 提供待查看数量、预警列表、详情、标记查看、来源计划跳转和导出，MUST NOT 提供分派、评论、人工关闭、忽略或重开。

#### Scenario: 查看待查看预警

- **GIVEN** 监管工作台存在待查看预警
- **WHEN** 监管人员打开预警详情
- **THEN** 系统将预警标记为已查看
- **AND** 展示企业、计划、培训类型、培训性质、计划学时、要求学时和差额

### Requirement: 监管统计与预警必须提供真实导出

系统 MUST 按当前查看权限和筛选生成真实 UTF-8 CSV 文件，MUST NOT 以固定文件 ID、空文件或任务记录代替导出结果。

#### Scenario: 按当前筛选导出

- **GIVEN** 监管人员具有对应查看和导出权限
- **WHEN** 导出机构统计、学习统计或预警列表
- **THEN** 返回可打开且内容与页面口径一致的 CSV 文件

### Requirement: 企业管理员工作台必须提供权限化入口与可解释概览

系统 MUST 只展示当前企业管理员已授权的模块入口，并展示本企业真实概览和分类待办。

#### Scenario: 企业管理员打开工作台

- **GIVEN** 企业管理员只具有部分业务模块权限
- **WHEN** 打开企业工作台
- **THEN** 只展示已授权模块入口
- **AND** 概览和分类待办可以下钻到对应业务列表

### Requirement: 机构类型必须区分企业和培训机构

系统 MUST 使用明确类型区分企业、培训机构和监管平台，MUST NOT 通过机构名称或描述推断业务分类。

#### Scenario: 创建培训机构

- **WHEN** 管理员按培训机构分类创建机构
- **THEN** 系统保存 `TRAINING_INSTITUTION` 类型
- **AND** 监管统计将其与企业分别统计

### Requirement: M5 完成状态必须以真实纵向闭环为准

M5 MUST NOT 按纯后端、Mock、占位导出或缺少跨租户验证的口径关闭。

#### Scenario: 仅后端或占位实现

- **GIVEN** 任一 M5 链路只有后端、使用 Mock、占位文件或缺少真实监管登录态验证
- **WHEN** 评审 M5 状态
- **THEN** M5 不得标记为已完成
