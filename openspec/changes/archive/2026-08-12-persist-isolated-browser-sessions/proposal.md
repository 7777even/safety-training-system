# 提案：持久化且隔离的浏览器登录会话

## 背景

当前使用 `sessionStorage` 可以隔离不同标签页，但关闭浏览器后会话通常丢失。直接改回共享 `localStorage` 又会让多个标签页互相覆盖登录账户。

## 目标

在同一系统地址下，同时满足：

- 不同标签页/窗口可使用不同账户。
- 浏览器关闭后再次打开时，无需重新输入密码即可恢复已保存的账户会话。
- 单个标签页切换或退出不会影响其他标签页。
- Token 不进入 URL、日志或跨窗口消息内容。

## 非目标

- 不改变后端登录 API、权限模型和 Token 生成策略。
- 不保证浏览器强制清理站点数据后仍能恢复会话。
- 不在多个标签页之间同步当前账户或统一退出。
