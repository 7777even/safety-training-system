# Spec Delta：持久化且隔离的浏览器登录会话

## 新增行为

### 场景：浏览器重启后恢复账户

- 假设浏览器中已保存账户 A、B 两个会话槽位
- 当用户重新打开系统地址
- 那么用户可选择恢复 A 或 B，无需重新输入密码

### 场景：不同标签页绑定不同槽位

- 假设标签页 1 绑定 A，标签页 2 绑定 B
- 当任一标签页登录、退出或切换账户
- 那么另一标签页的槽位和请求 Token 不变

### 场景：禁止静默抢占

- 假设槽位 A 已被标签页 1 使用
- 当标签页 2 尝试选择 A
- 那么系统提示该槽位正在使用，不得静默替换标签页 1 的绑定

## 不变行为

- 登录、退出和当前用户资料 API Contract 不变。
- 服务端权限校验仍以请求中的 Bearer Token 为准。
