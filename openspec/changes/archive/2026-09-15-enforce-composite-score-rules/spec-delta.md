# Spec Delta：培训综合成绩的可配置性、完整性与可追溯性

## ADDED Requirements

### Requirement: 综合评价表单必须是唯一且可追溯的来源公式

当表单类型为 `COMPOSITE` 时，系统 MUST 仅接受 `COURSE`、`EXAM`、`OFFLINE` 来源的 `WEIGHT` 规则；每个来源至多一条，所有规则权重 MUST 合计为 1。每条规则 MUST 对应一个唯一、必填、满分 100 的分数项目。`MANUAL`、`REWARD_PENALTY`、`ADJUSTMENT` 与重复来源 MUST 被拒绝。

#### Scenario: 发布合规综合评价表

- **GIVEN** 表单包含考试权重 0.6 和线下权重 0.4 两条规则，且各自关联唯一分数项目
- **WHEN** 管理员发布新版本
- **THEN** 系统发布该版本并冻结规则

#### Scenario: 发布含人工来源的综合评价表

- **GIVEN** `COMPOSITE` 表单包含 `MANUAL` 来源或 `ADJUSTMENT` 规则
- **WHEN** 管理员发布新版本
- **THEN** 系统拒绝发布并说明正式综合成绩不支持无可追溯来源的规则

### Requirement: 多项同类成绩必须先按计划配置汇总

培训计划的 COURSE、EXAM、OFFLINE 计分内容 MUST 在类别内统一使用 `AVERAGE` 或 `WEIGHTED_AVERAGE`。加权平均的每项权重 MUST 大于 0 且同类合计为 1；算术平均 MUST 不携带内容权重。QUESTION_BANK MUST 不参与综合成绩。

#### Scenario: 两项考试采用加权平均

- **GIVEN** 两项计分考试成绩为 80、90，内容权重为 0.4、0.6
- **WHEN** 系统汇总考试类别成绩
- **THEN** 考试类别成绩为 86

#### Scenario: 同类内容混用汇总方式

- **GIVEN** 同一计划的一项计分考试为 `AVERAGE`，另一项为 `WEIGHTED_AVERAGE`
- **WHEN** 管理员绑定综合评价表或发布计划
- **THEN** 系统拒绝操作并说明同类计分内容必须统一汇总方式

### Requirement: 不完整的公式来源不得生成或确认正式综合成绩

计算和确认综合成绩前，系统 MUST 验证评分表每个来源在计划中有计分内容，且每个此类内容都有正式成绩。缺分 MUST 返回明确的类别及内容名称，且不得创建新计算批次或确认既有批次。正式 0 分 MUST 视为有效成绩。

#### Scenario: 课程未出分但考试和线下已出分

- **GIVEN** 表单引用课程、考试、线下三类来源，课程计分内容尚未产生正式分数
- **WHEN** 管理员计算综合成绩
- **THEN** 系统返回缺少课程正式成绩
- **AND** 不创建 `CALCULATED` 批次

#### Scenario: 多项来源均已出分

- **GIVEN** 表单引用考试 0.6、线下 0.4；两项考试聚合为 86，两项线下聚合为 85
- **WHEN** 管理员计算综合成绩
- **THEN** 系统创建综合成绩 85.6 的待确认批次

### Requirement: 计算批次必须保存逐内容成绩构成

每个新计算批次 MUST 保存被计入的每个计划内容的正式分数、类别内汇总配置、类别汇总分和表单规则权重，并为有查询权限的管理员提供只读查询。历史来源 MUST 不因后续来源成绩变化而改变。

#### Scenario: 查看多个考试的历史构成

- **GIVEN** 某计算批次基于两项考试和两项线下内容生成
- **WHEN** 管理员展开该批次来源明细
- **THEN** 系统按内容显示每项正式分、类别内权重、类别汇总和对综合成绩的贡献
