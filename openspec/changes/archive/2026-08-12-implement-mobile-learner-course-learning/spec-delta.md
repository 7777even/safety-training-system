# Spec Delta：移动端学员课程学习

## 新增

### Requirement：移动端学员可以完成课程学习

系统必须允许当前登录学员在移动端查看本人课程、进入课程详情、切换可学习内容项、预览或受控打开课程素材，并通过现有学习会话接口保存学习进度。

#### Scenario：进入课程并恢复学习

- Given 学员拥有有效课程报名和可学习内容项
- When 学员打开课程详情
- Then 系统展示课程级进度、章节目录和当前内容项
- And 系统按内容项已有断点恢复视频/音频位置或文档相关学习状态

#### Scenario：切换内容项

- Given 学员正在学习一个可学习内容项
- When 学员选择另一个可学习内容项
- Then 系统先尽力上报当前内容项会话，再加载目标内容项
- And 目标内容项展示其学习状态和已有断点

#### Scenario：兼容不同素材格式

- Given 内容项关联视频、音频、图片、PDF、富文本、Office、链接或直播素材
- When 学员打开内容项
- Then 系统按移动端能力展示预览、受控打开或受控下载入口
- And 预览失败时不得直接暴露未授权文件地址

#### Scenario：课程考试内容项

- Given 内容项类型为课程考试且学员具备学习资格
- When 学员点击进入考试
- Then 系统调用现有课程考试启动接口并进入移动端考试页面

#### Scenario：异常与离开

- Given 接口、媒体或预览发生异常
- When 学员继续操作或离开页面
- Then 系统展示可理解的错误/降级状态
- And 页面离开时尽力上报当前学习会话且不阻塞返回

### Requirement：PC 与移动端统一学习计时和媒体兼容策略

系统必须在 PC 与移动端按真实播放或页面可见停留累计有效学习时长，并在暂停、切后台、页面隐藏时停止累计；视频、音频、PDF、Office 和受控文件地址必须按端能力提供预览或降级入口。

#### Scenario：媒体播放计时

- Given 学员打开视频或音频内容项
- When 媒体实际播放
- Then 系统只累计播放期间的有效学习秒数
- And 暂停、结束、切后台或页面隐藏时停止累计

#### Scenario：非媒体内容计时

- Given 学员打开文档、图片、富文本、外链或直播内容项
- When 页面处于可见状态
- Then 系统累计页面可见停留时间
- And 页面隐藏或离开时停止累计并尽力上报

#### Scenario：HLS 与文件预览兼容

- Given 受控播放信息返回 HLS、MP3、PDF、Office、图片或原始文件格式
- When 学员在 PC 或移动 H5 打开内容
- Then 系统优先使用对应端已有播放器或兼容依赖预览
- And 不支持时提供受控下载/打开降级

### Requirement：课程考试类内容项暂不接入

本 Change 不实现或启用 `QUESTION_BANK`、`PRACTICE`、`EXAM` 课程内容项接入；相关接入延后至题库、考试和练习对应 OpenSpec Change。

## 不变

- 学员本人数据边界和课程完成判定由后端现有规则负责。
- 学习会话幂等语义、接口字段和错误码以现有 API Contract 为准。
- 本 Change 不新增后端接口、数据库结构、权限模型或转码能力。
- 本次优化允许移动端引入 HLS 播放依赖；不新增 Office/PDF 业务 API。
