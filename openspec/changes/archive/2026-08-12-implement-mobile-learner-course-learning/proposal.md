# 移动端学员课程学习

## 背景

移动端目前只能查看课程任务并记录一次进入事件，无法像 PC 端一样打开课程素材、切换章节内容和保存学习断点。学员在手机 H5、App 或企业微信入口中无法完成连续的课程学习闭环。

## 目标

基于现有学员课程学习 API 和 PC 端课程学习经验，完成移动端学员课程列表、课程学习详情和素材预览能力，并保持学习进度可追溯。

## 用户价值

学员可以在移动设备上查看课程进度、进入章节内容、继续上次学习位置，并在素材预览失败时通过受控入口继续访问或下载内容。

## 功能范围

- 移动端课程列表视觉与交互优化，展示课程状态、进度和必修/选修信息。
- 移动端课程学习详情页，展示课程摘要、章节目录、内容项状态和课程级进度。
- 内容项切换、学习断点恢复和离开/切换/完成时的学习会话上报。
- 视频、音频、图片、PDF、富文本、外部链接和直播内容的移动端预览或受控打开。
- Office 文档及移动端无法内嵌的格式提供受控打开或下载兜底，不直接暴露未授权文件地址。
- 课程考试内容项沿用现有课程考试启动接口，进入移动端考试页面。
- 加载、空状态、接口失败、素材不支持和预览失败状态。

## 非目标范围

- 不新增或修改后端 API、数据库结构、权限模型和课程完成判定规则。
- 不实现真实转码、派生文件、在线转码任务或媒体增强能力。
- 不实现离线缓存、下载到本地后的离线学习和原生 App 专属播放器能力。
- 不复制 PC 端左右分栏和桌面端导航结构。
- 不新增评论、笔记、评分统计、倍速、清晰度切换或防录屏能力。
