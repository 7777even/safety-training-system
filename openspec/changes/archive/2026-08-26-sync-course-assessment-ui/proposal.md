# Proposal：同步课程考核与独立考试前端

> 状态：已于 2026-08-26 获得人工确认，按 `tasks.md` 实施。

## 背景

后端已将课程题库练习、课程测验与独立考试拆分为不同业务来源，现有 PC 与移动端仍保留课程内容关联独立考试和旧作答入口，无法按最新 OpenAPI 完成课程考核闭环。

## 目标

1. 课程章节直接关联题库或已发布试卷版本。
2. 管理员可在具体开课内管理课程测验阅卷和自动生效结果。
3. PC 与移动学员可完成课程题库练习和课程测验，且不与独立考试串联。
4. 独立考试页面严格按最新 `exam.openapi.json` 调用和展示。

## 非目标

- 不修改题库、试卷、课程或考试的后端业务规则、权限模型、数据库结构和 OpenAPI Contract。
- 不新增课程专项练习类型、课程人工成绩发布或独立菜单。
- 不实现仿真、防作弊或人脸识别能力。
