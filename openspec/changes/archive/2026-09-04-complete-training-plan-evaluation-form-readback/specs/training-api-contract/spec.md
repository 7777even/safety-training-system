# training-api-contract Specification

## ADDED Requirements

### Requirement: 培训计划评价表单绑定必须形成保存与读回闭环

系统 MUST 允许草稿培训计划整体绑定已发布的固定评价表单版本，并 MUST 从计划详情读回当前有效绑定，使调用方可以在重新加载后恢复计划评价配置。

#### Scenario: 保存后重新加载绑定

- **GIVEN** 当前用户有权查看和编辑某个草稿培训计划
- **AND** 已发布评价表单版本属于当前机构且可用
- **WHEN** 用户整体保存计划评价表单绑定后重新查询计划详情
- **THEN** 详情返回当前有效的全部绑定摘要
- **AND** 每条摘要包含绑定 ID、计划 ID、表单版本 ID、表单 ID、表单名称、版本号、发布状态、评价用途、是否必填和启用状态
- **AND** 调用方可以使用 `formVersionId` 查询既有不可变版本详情

#### Scenario: 没有绑定时返回空集合

- **GIVEN** 培训计划当前没有有效评价表单绑定
- **WHEN** 用户查询计划详情
- **THEN** `evaluationForms` 返回空数组
- **AND** 不返回 `null` 或历史已删除绑定

#### Scenario: 重复保存整体替换

- **GIVEN** 草稿培训计划已经绑定某一评价用途的固定表单版本
- **WHEN** 用户使用当前计划版本再次提交该用途的新全量绑定
- **THEN** 原绑定按项目逻辑删除规则失效
- **AND** 只保留本次提交的有效绑定
- **AND** 不因历史有效数据残留触发唯一约束或返回系统未知错误

#### Scenario: 拒绝旧版本覆盖

- **GIVEN** 客户端提交的计划版本落后于数据库版本
- **WHEN** 客户端整体替换评价表单绑定
- **THEN** 系统返回 HTTP 409 和业务码 8104
- **AND** 原有绑定保持不变

#### Scenario: 计划查看权限不扩张为评价表单管理权限

- **GIVEN** 用户有权查看某个培训计划但没有评价表单管理权限
- **WHEN** 用户查询该计划详情
- **THEN** 系统可返回该计划已经绑定的表单名称和版本摘要
- **BUT** 用户不能借此查询未绑定表单或完整评价项目与评分规则
- **AND** 完整版本详情继续执行 `evaluation:form:list` 权限校验

#### Scenario: 异常绑定阻止返回残缺详情

- **GIVEN** 当前有效绑定指向的评价表单版本或表单主体异常缺失
- **WHEN** 用户查询培训计划详情
- **THEN** 系统返回 HTTP 500 和业务码 8132
- **AND** 不静默丢弃绑定或返回伪造摘要
- **AND** 服务端日志记录计划 ID 与绑定 ID
