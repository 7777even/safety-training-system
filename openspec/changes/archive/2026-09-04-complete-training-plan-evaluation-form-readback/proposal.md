# Proposal：补齐培训计划评价表单绑定读回闭环

> 状态：已完成（2026-09-04 人工确认并实施）。

## 背景

培训计划当前可以整体绑定固定的评价表单版本，发布校验和后续综合评价也会读取这些绑定关系，但计划详情不返回已绑定数据，且不存在独立的计划绑定查询接口。管理端保存后刷新页面无法恢复已绑定版本，只能重新选择，现有能力因此停留在“可写、不可读回”的非闭环状态。

同时，评价表单绑定的整体替换使用了不符合项目逻辑删除约定的 Mapper 删除方式。旧绑定可能继续保持有效，并在再次保存相同评价用途时触发唯一约束。

## 本次覆盖的功能项

| 序号 | 原文语义                                                                 | 本次边界                                              |
|----|----------------------------------------------------------------------|---------------------------------------------------|
| 34 | 可设置关于培训的全部内容，包含培训基本信息设置、线上培训、线下培训、培训人员及附件资料上传等；根据培训计划可添加培训内容，设置培训详情。 | 计划详情可读回本计划已经保存的评价表单版本绑定。                          |
| 40 | 综合素质评价表模板支持在线设置；设置完成的评分表可在培训管理过程支持引用。                                | 被计划引用的固定评价表单版本可在刷新后识别、展示并继续编辑；完整表单内容仍由既有版本详情接口读取。 |

## 目标

1. 培训计划详情返回当前有效的评价表单版本绑定摘要。
2. 管理端仅依赖公开契约即可在刷新后恢复已绑定版本、评价用途、是否必填和启用状态。
3. 需要查看评价项目与评分规则时，调用方可使用返回的 `formVersionId` 继续访问既有评价表单版本详情接口。
4. 评价表单整体绑定真正替换旧集合，重复保存不会累加或触发旧数据造成的唯一约束冲突。
5. 保持计划版本控制、草稿可编辑边界、机构隔离和既有权限不变。

## 功能范围

- 扩充培训计划详情响应中的评价表单绑定摘要。
- 补齐绑定摘要所需的评价表单名称、版本号和发布状态等稳定识别信息。
- 修正计划评价表单整体绑定和计划删除时的绑定软删除行为。
- 同步 `docs/api/training.openapi.json`、后端实现和自动化测试。

## 非目标范围

- 不新增独立的计划评价表单绑定 GET 路径。
- 不在计划详情中复制评价项目、评分规则等完整版本内容；完整内容继续使用既有版本详情接口。
- 不修改评价表单定义、发布、版本不可变规则或评价计算规则。
- 不新增权限，不改变 `training:plan:list`、`training:plan:edit` 或 `evaluation:form:list` 的语义。
- 不修改数据库结构、唯一索引或正式初始化数据。
- 不实施前端页面、Mock、联调或 UI；前端以 OpenAPI 为准另开。

## 前后端影响

仅后端；前端以 OpenAPI 为准另开。

## Impact

- API：`TrainingPlanVO` 新增 `evaluationForms`，复用并补全 `TrainingPlanEvaluationFormVO`；计划详情成功响应 example 同步。
- 后端：计划详情聚合查询评价表单绑定、版本与表单摘要；整体绑定使用项目约定的主键值逻辑删除。
- 数据：无结构变化、无 migration；仅修正既有数据的正常写入方式。
- 兼容：响应新增字段，为向后兼容的加法变更；调用方不需要迁移请求。

## 人工确认关卡

本 Change 修改 API Contract，属于 L4。Proposal、Design、Tasks 和 Spec Delta 经人工确认后才进入实现。确认同时表示接受：

1. 读回能力并入既有计划详情，不新增功能重复的独立 GET。
2. 计划详情仅返回绑定及版本摘要；完整评价项目和评分规则继续按 `formVersionId` 调用既有版本详情接口。
3. 计划查看权限可以读取该计划已经绑定的表单名称和版本摘要，但不能据此读取未绑定表单或完整版本内容。
4. 异常绑定不静默丢弃，统一返回 HTTP 500/8132“培训计划评价表单绑定数据不完整”。
