# Tasks：课程能力业务开发

> 状态：等待需求与架构确认。确认后一次只实施一个 Task，并在完成后更新状态、测试记录与 FR 覆盖。

## Task 1：完成课程资源与素材库能力

- 状态：待确认
- Owner：产品、架构、后端、前端
- 输入：CRS-001、CRS-002；文件存储与转码方案确认。
- 输出：资源上传、预览、素材复用、处理状态查询及状态限制能力。
- 前后端影响：新增资源 API、管理端资源页面与异步状态展示。
- API 依赖：课程资源 OpenAPI Contract。
- 数据影响：新增资源元数据、转码任务及资源与课程材料的关联；需要 migration。
- 验收标准：转码中资源不可下载、编辑或用于课程；转码成功资源可被课程使用；资源操作和状态均受权限控制。
- 测试方式：资源状态机、权限、上传校验、异步状态与 API Contract 测试。

## Task 2：完成课程创建与章节内容编排能力

- 状态：待确认
- Owner：产品、后端、前端
- 输入：CRS-003、CRS-004、CRS-005；课程分类和目录规则确认；Task 1 的可用资源。
- 输出：课程基本信息、章节目录、材料与知识点编排能力。
- 前后端影响：新增课程与章节 API、PC 管理端制作页面。
- API 依赖：课程、章节、课程材料 OpenAPI Contract。
- 数据影响：新增课程、章节、课程内容关联；需要 migration。
- 验收标准：有权用户可维护课程信息和有序章节树；仅可引用可用资源；尚未建设的考试与仿真内容不显示为可用实体。
- 测试方式：章节树、排序、资源引用、权限与 API Contract 测试。

## Task 3：完成课程授权与开课能力

- 状态：待确认
- Owner：产品、权限负责人、后端、前端
- 输入：CRS-007、CRS-008；组织授权、可见范围、开课与合格规则确认；Task 2 的课程。
- 输出：课程公共/内部归属、组织授权、开课配置和课程任务可见性。
- 前后端影响：新增授权与开课 API、PC 管理端配置页面、学员端课程列表数据源。
- API 依赖：课程授权、开课、学员课程列表 OpenAPI Contract。
- 数据影响：新增授权、开课与受众范围关联；需要 migration。
- 验收标准：仅授权范围内用户可在有效期内看到并进入课程；查看与编辑删除权限严格区分。
- 测试方式：组织数据范围、权限矩阵、有效期和跨端列表 Contract 测试。

## Task 4：完成学员课程学习与学习详情能力

- 状态：待确认
- Owner：产品、后端、PC 前端、移动端前端
- 输入：CRS-006、CRS-009、LRN-003～LRN-007 的课程部分；学习有效性、完成和选课规则确认；Task 3 的开课记录。
- 输出：课程任务、我的课程、选课大厅、章节学习、学习记录和管理端学习详情。
- 前后端影响：新增学习 API；替换 PC 课程占位页；实现移动端课程业务页。
- API 依赖：课程详情、学习记录、选课与学习详情 OpenAPI Contract。
- 数据影响：新增或扩展学员课程关系、章节学习记录和学习结果；需要 migration。
- 验收标准：学员只访问本人有权课程；学习过程和结果可回查；管理员只查看其数据范围内详情。
- 测试方式：学习规则、数据范围、PC/移动端关键流程、API Contract 与回归测试。
