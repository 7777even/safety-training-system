# Spec Delta：课程能力

## 新增需求

### 课程资源与制作

- 系统必须支持 `FR-ENT-CRS-001` ～ `FR-ENT-CRS-005` 定义的资源管理、资源处理状态、课程创建、章节目录和内容编排。
- 资源处于转码中时，系统必须禁止下载、编辑和用于课程制作；成功后方可使用。
- 未建设的考试和仿真能力不得以虚构数据或虚假入口作为课程章节内容交付。

### 课程授权、学习与直播

- 系统必须支持 `FR-ENT-CRS-006` ～ `FR-ENT-CRS-010` 定义的学习记录、组织授权、开课、学习详情和直播课程。
- 学员只能访问其课程授权、开课有效期与组织数据范围共同允许的课程内容。
- 每项学习时长、完成、合格、通知和直播集成规则必须在 API Contract 与测试中有可验证定义后实施。

## 依赖与约束

- 课程 API Contract 是 PC、移动端与后端协作的唯一接口来源。
- 课程领域数据结构变化必须通过 migration，并同步 Entity、API Contract 和本 Change design。
- 课程与考试、仿真、培训、证书和统计之间仅通过经确认的边界协作；不得提前实现后续领域。
