# Proposal：启动课程能力业务开发

## 背景

系统基础平台已经完成，PC 课程中心与移动端课程目录仍是业务占位。需求基线定义了课程资源、课程制作、授权开课、学习记录和直播共
10 条课程 FR，是后续考试和培训计划的基础输入。

## 目标

将课程域需求整理为可确认、可拆分和可验证的正式业务开发 Change，建立从 `FR-ENT-CRS-001` ～ `FR-ENT-CRS-010` 到 API
Contract、数据演进、前后端功能和测试的追踪链路。

## 用户价值

企业/培训机构能够逐步完成课程资源建设、课程制作、组织开课和学习过程管理；学员能够接收、查看和学习已授权课程。课程结果将为考试、培训与档案提供可信输入。

## 范围

- 课程资源与素材管理、资源处理状态。
- 课程创建、分类、章节目录及内容编排。
- 课程授权、开课、学习、学习详情与直播课程。
- 与学员端课程任务、我的课程和选课大厅的必要协作。

## 非目标范围

- 理论考试、题库、测验、仿真练习和仿真考试的实体实现；课程仅预留经确认的内容关联边界。
- 培训计划、证书、档案、统计、监管预警的实现。
- 未确认的直播平台、转码供应商、人脸识别、微信接入、外部人员学习和跨机构授权。
