# Spec Delta：课程管理端连续工作流

## MODIFIED Requirements

### Requirement：课程制作工作台

PC 管理端必须通过可刷新、可返回的全页工作台承载课程基础信息、内容编排、发布版本和当前课程开课配置。首次保存基础信息前，依赖 `courseId` 的阶段必须禁用。

#### Scenario：新增课程后继续编排

- Given 管理员从课程中心新增课程
- When 基础信息保存成功
- Then 页面使用新 `courseId` 更新当前地址并进入内容编排
- And 不返回课程列表或打开新的业务弹窗

### Requirement：页面内课程编排

章节、内容项、材料规则、直播场次和开课表单必须在课程工作台页面内编辑。素材选择可以使用一个独立弹窗，但该弹窗内部不得继续打开业务弹窗。

#### Scenario：选择课程素材

- Given 管理员正在编辑素材内容项
- When 打开素材选择器
- Then 只能选择启用且处理成功的素材
- And 可以按 Contract 支持的名称和类型筛选
- And 确认返回完整素材记录

### Requirement：统一文件上传和预览降级

PC Web 必须提供可复用文件上传组件，支持页面弹窗和抽屉内面板两种承载方式。组件必须对支持的本地文件提供预览；无法由现有 Contract 恢复历史文件 URL 时必须显示明确降级提示。

#### Scenario：素材抽屉上传文件

- Given 管理员正在素材编辑抽屉
- When 进入上传文件
- Then 抽屉内容切换为上传队列
- And 不叠加第二层弹窗或遮罩

## 保持不变

- 不新增 API、权限点、数据库结构或业务状态。
- Mock 与真实请求继续共享同一页面调用接口。
- 学员端和考试类课程内容项不进入本次变更。
