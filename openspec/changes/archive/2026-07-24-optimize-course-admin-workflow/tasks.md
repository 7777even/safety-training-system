# Tasks：课程管理端工作流优化

> 已由用户确认实施。一次连续完成三个业务 Task。

## Task 1：课程中心与四阶段详情工作台

- **状态**：已完成
- **Owner**：AI
- **输入**：已确认方案、现有课程中心、课程基础 Contract、详情编辑原型
- **输出**：列表/详情路由状态、四阶段导航、基础信息全页表单
- **前后端影响**：仅 PC Web；不修改后端
- **API 依赖**：课程分页、详情、创建、更新、分类关联和内容模式切换
- **数据影响**：无数据库结构变化
- **验收标准**：
  - 新增和编辑使用全页工作台，不再使用课程基础信息弹窗。
  - 首次保存取得 `courseId` 后更新查询参数并解锁后续阶段。
  - 刷新、前进和后退能够恢复当前阶段。
  - 更新携带最新 `version`，2040 冲突不静默覆盖。
- **测试方式**：课程工作台公开状态测试、课程页面测试、PC lint/typecheck/build

## Task 2：内容编排、素材选择和统一上传

- **状态**：已完成
- **Owner**：AI
- **输入**：Task 1、章节/内容/材料/直播/下载素材 Contract、素材与上传参考图
- **输出**：三栏内容编排、素材选择器、预览面板、统一上传组件、素材抽屉上传面板
- **前后端影响**：仅 PC Web；不修改后端
- **API 依赖**：章节、内容项、材料规则、直播场次、下载素材、素材分页、系统文件上传
- **数据影响**：仅现有 Mock 会话数据
- **验收标准**：
  - 章节、内容项、材料规则和直播配置均在页面内编辑。
  - 素材选择器支持单选、多选、分页筛选、已选回显和内嵌预览。
  - 上传组件支持队列、进度、失败重试、移除和可支持格式预览。
  - 素材编辑抽屉打开上传时不出现第二层遮罩。
- **测试方式**：素材选择/上传公开行为测试、页面结构测试、PC lint/typecheck/build

## Task 3：发布、开课与完整验收

- **状态**：已完成
- **Owner**：AI
- **输入**：Task 1–2、发布版本和开课 Contract
- **输出**：页面内发布版本、当前课程开课配置、复用的全局开课管理、QA/Retro
- **前后端影响**：仅 PC Web；不修改后端
- **API 依赖**：课程发布/下线/版本、开课 CRUD 与状态流转、报名和学习详情
- **数据影响**：仅现有 Mock 会话数据
- **验收标准**：
  - 版本历史和快照不再使用业务弹窗。
  - 发布后可直接进入当前课程开课阶段。
  - 无发布版本时不能创建开课，并显示明确原因。
  - 独立开课管理继续支持跨课程管理、报名和学习详情。
  - 完成规格符合性与代码质量双轴 Review。
- **测试方式**：课程定向测试、PC lint/typecheck/build、桌面视觉与核心流程检查
