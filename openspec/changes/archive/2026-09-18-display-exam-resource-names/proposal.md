# Proposal：考试资源名称回显

## 背景

考试列表和详情当前只返回并展示试卷版本、题库的内部 ID。管理员无法在不跳转资源管理页的情况下确认考试实际绑定的试卷或题库。

## 范围

- 为考试查询响应新增只读 `paperName`、`paperVersionNo`、`questionBankName`。
- PC 考试列表展示考试类型、试卷版本或题库名称、开放开始/结束时间。
- PC 考试详情直接展示接口返回的资源名称，不再以 ID 作为可见回退文本。

## 非目标

- 不改变考试资源绑定、权限、数据库结构或任何请求字段。
- 不新增接口；名称仅随既有考试列表与详情查询返回。
