# Spec Delta：课程考核与独立考试来源分离

## ADDED Requirements

### Requirement: 题库和试卷资源必须与业务任务分离

系统 MUST 将题库和已发布试卷版本作为可复用内容资源，将课程内容项和独立考试作为不同的业务任务。独立考试任务 MUST NOT
作为课程题库或测验的可复用资源模板。

#### Scenario: 同一试卷用于课程测验和独立考试

- **GIVEN** 一个已发布试卷版本
- **WHEN** 它同时被课程测验和独立考试引用
- **THEN** 两个业务任务分别保存自身上下文和规则
- **AND** 不会因共用试卷而共用考生、阅卷人、作答或成绩

### Requirement: 课程理论题库必须直接引用题库

课程 `QUESTION_BANK` 内容项 MUST 直接引用当前机构可用的题库，MUST NOT 要求管理员先创建或发布 `BANK_PRACTICE` 独立考试任务。

#### Scenario: 章节添加理论题库

- **GIVEN** 当前机构存在可用题库
- **WHEN** 管理员在课程章节添加理论题库
- **THEN** 系统保存内容项与该题库的直接关系
- **AND** 请求不包含 `examId`

### Requirement: 课程测验必须直接引用已发布试卷版本

课程 `QUIZ` 内容项 MUST 直接引用当前机构已发布的试卷版本，MUST NOT 要求管理员先创建或发布独立在线考试任务。

#### Scenario: 章节添加测验

- **GIVEN** 当前机构存在已发布试卷版本
- **WHEN** 管理员在课程章节添加测验
- **THEN** 系统保存内容项与该试卷版本的直接关系
- **AND** 请求不包含 `examId`

### Requirement: 考核执行必须保存明确业务来源

每个 Candidate、Attempt、批阅和成绩事实 MUST 归属于唯一考核执行对象。执行对象 MUST 明确记录来源类型、来源业务 ID、资源类型及资源
ID，MUST NOT 通过空字段、名称或 `examType` 猜测来源。

#### Scenario: 同一资源被多个业务场景复用

- **GIVEN** 同一试卷版本被两个课程内容项和一个独立考试引用
- **WHEN** 同一学员分别作答
- **THEN** 系统创建三个相互隔离的执行上下文
- **AND** 任一场景的答案、成绩和进度均不影响其他场景

### Requirement: 题库练习不得依赖正式试卷版本

题库练习 MUST 允许 `paperVersionId` 为空。开始练习时系统 MUST 按冻结规则从题库选取已发布题目版本，并在 Attempt
中冻结题目、选项、正确答案、分值和执行参数。

#### Scenario: 只绑定题库的课程练习开始作答

- **GIVEN** 课程理论题库已绑定可用题库但没有试卷版本
- **WHEN** 有效报名学员开始练习
- **THEN** 系统创建 `paperSourceType=QUESTION_BANK` 的作答快照
- **AND** 不返回“考试未绑定试卷版本”

#### Scenario: 题库后续变更

- **GIVEN** 学员已开始一次题库练习
- **WHEN** 题库题目或题目版本后续变更
- **THEN** 已有 Attempt 仍按开始时快照保存、交卷、判分和重放

### Requirement: 课程题库练习完成一轮即完成内容项

课程题库练习 MUST 在开始时冻结题库全部可用已发布题目版本。学员将冻结题目全部至少作答一次并提交后，系统 MUST
将该轮练习和对应课程内容项标记为完成，MUST NOT 设置正确率或合格门槛。

#### Scenario: 完成一轮课程题库练习

- **GIVEN** 一次课程题库练习已冻结全部可用题目
- **WHEN** 学员将全部冻结题目至少作答一次并提交
- **THEN** 系统记录该轮正确率和错题
- **AND** 将该课程内容项标记为完成

#### Scenario: 完成后再次练习

- **GIVEN** 学员已经完成该课程题库内容项
- **WHEN** 学员再次开始并提交练习
- **THEN** 系统追加练习次数并更新最近、最好、正确率和错题事实
- **AND** 不撤销既有内容项完成状态

### Requirement: 课程测验必须显式配置主观题阅卷人并自动生效成绩

纯客观题课程测验 MUST NOT 要求配置阅卷人，交卷并完成自动判分后成绩 MUST 自动生效。包含主观题时，系统 MUST
要求在开课对应考核执行中显式配置至少一名阅卷人，并在全部主观题批阅完成后自动生效成绩。课程测验 MUST NOT 进入独立考试人工成绩发布流程。

#### Scenario: 纯客观题课程测验交卷

- **GIVEN** 课程测验只包含客观题
- **WHEN** 学员交卷且系统完成自动判分
- **THEN** 最终成绩立即在该课程执行中生效
- **AND** 不生成独立考试人工发布任务

#### Scenario: 含主观题但没有阅卷人

- **GIVEN** 课程测验包含至少一道主观题
- **AND** 开课对应考核执行未配置阅卷人
- **WHEN** 管理员发布开课
- **THEN** 系统拒绝发布并提示必须配置课程测验阅卷人

#### Scenario: 主观题全部批阅完成

- **GIVEN** 课程测验已显式配置阅卷人且存在待批阅主观题
- **WHEN** 最后一项主观题完成有效批阅
- **THEN** 系统重新计算并自动生效最终成绩
- **AND** 只更新该课程执行对应的结果和进度

### Requirement: 课程考核必须复用现有课程完成规则

开课 MUST 继续使用 `ALL_REQUIRED_ITEMS / ALL_ITEMS` 确定参与课程完成计算的内容项。课程题库完成一轮后内容项完成；课程测验最终成绩生效后内容项完成。系统
MUST 保存测验合格结果，但本期 MUST NOT 以是否合格阻断课程完成。

#### Scenario: 默认只要求必修内容项

- **GIVEN** 开课使用默认 `ALL_REQUIRED_ITEMS`
- **WHEN** 学员完成全部 `isRequired=1` 内容项但未完成选修项
- **THEN** 系统允许课程完成

#### Scenario: 开课要求完成全部内容项

- **GIVEN** 开课配置为 `ALL_ITEMS`
- **WHEN** 任一必修或选修内容项未完成
- **THEN** 系统不得将课程标记为完成

#### Scenario: 课程测验成绩不合格但已最终生效

- **GIVEN** 学员课程测验最终成绩已生效且 `isPassed=0`
- **WHEN** 系统计算内容项和课程完成状态
- **THEN** 该测验内容项仍按已完成处理
- **AND** 结果中保留最终分数和不合格事实

### Requirement: 批阅任务和成绩必须按来源分流

独立考试和课程测验 MAY 共用批阅引擎，但业务查询、权限校验、成绩归属和统计 MUST 按执行来源分流。

#### Scenario: 查询独立考试批阅任务

- **GIVEN** 系统中同时存在独立考试和课程测验待批阅作答
- **WHEN** 阅卷人按 `examId` 查询独立考试批阅任务
- **THEN** 结果只包含该独立考试来源的作答

#### Scenario: 查询课程测验批阅任务

- **GIVEN** 课程测验存在待批阅作答
- **WHEN** 有权教师按开课和内容项查询
- **THEN** 结果只包含该课程执行来源的作答
- **AND** 每条作答返回课程、开课和内容项来源摘要

### Requirement: 课程结果必须只回写同一报名内容项

课程测验或题库练习结果 MUST 以 `assessmentExecutionId + courseEnrollmentId + courseItemId` 为幂等边界更新课程进度，MUST
NOT 因共用题库、试卷或用户而回写其他报名或独立考试。

#### Scenario: 同一学员在两个课程使用同一试卷

- **GIVEN** 同一学员的两个课程报名均引用同一试卷版本
- **WHEN** 其中一个课程测验结果生效
- **THEN** 系统只更新该执行对象对应的报名和内容项进度
- **AND** 另一课程和独立考试结果不变

### Requirement: 课程考核必须只实现最终模型

系统 MUST 只实现本规格定义的课程资源引用和考核执行归属。代码、Schema 和 API MUST NOT 建立课程 `EXAM / PRACTICE + examId`
路径或第二套执行归属。

#### Scenario: 按最终模型创建课程考核

- **GIVEN** 管理员正在创建课程题库练习或课程测验
- **WHEN** 保存、发布并生成考核执行
- **THEN** 系统仅使用直接资源引用和 `assessmentExecutionId` 执行归属
- **AND** 流程中不存在课程 `examId` 替代路径

## MODIFIED Requirements

### Requirement: 课程考试类内容项

课程当前范围的理论作答内容 MUST 仅包含 `QUESTION_BANK` 理论题库和 `QUIZ` 测验。`QUESTION_BANK` MUST 直接引用题库；`QUIZ`
MUST 直接引用已发布试卷版本。“专项练习” MUST NOT 在未经单独已确认 OpenSpec 时作为课程章节类型。

#### Scenario: 创建课程理论作答内容

- **GIVEN** 管理员正在编辑课程章节
- **WHEN** 创建理论作答内容
- **THEN** 系统只允许选择理论题库或测验
- **AND** 不提供课程专项练习新建语义

### Requirement: 课程完成态必须读取同一课程执行结果

课程完成态 MUST 只读取同一 `assessmentExecutionId + courseEnrollmentId + courseItemId`
上下文的有效结果。课程题库完成一轮后内容项完成；课程测验最终成绩自动生效后内容项完成；是否合格不阻断本期课程完成。

#### Scenario: 不同来源产生同一资源的通过结果

- **GIVEN** 学员已在独立考试中通过某试卷
- **WHEN** 课程也引用该试卷版本
- **THEN** 独立考试结果不会自动完成课程测验

## REMOVED Requirements

### Requirement: 课程 EXAM_LIKE 内容项直接关联已发布考试

移除“课程 `EXAM / QUESTION_BANK / PRACTICE` 内容项均必须通过 `examId` 直接关联已发布考试”的语义。移除原因是该设计把独立考试任务误作课程可复用资源，与功能项
16 和 22 的业务角色分工不一致。
