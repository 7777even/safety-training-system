# M4 最小闭环增量规格

本 Change 不增加超出 `openspec/specs/m4-minimum-closure/spec.md` 的产品能力，只明确现有要求在 PC 界面的可验收状态。

## 问卷

- 管理员 MUST 可在界面创建、编辑、复制、删除未投放问卷，维护题目/选项，完成 PC/手机预览；复制后 MUST 显示新草稿。
- 投放页 MUST 展示可扫码二维码及填写链接，并可选择契约已有的用途和结果可见性；提交者在配置允许且已提交后 MUST 能从界面查看其获授权的基础统计。
- 重复提交 MUST 由服务端拒绝；页面不得仅靠按钮禁用宣称防重。

## 成果和专家查课

- 已结束成果页 MUST 展示计划信息、学员成绩/详情、奖惩和基础统计，不重算正式成绩。
- 专家 MUST 能通过培训中已绑定的表单提交意见；管理员 MUST 能在对应培训回看。

## 档案

- 管理员 MUST 能从已结束计划生成/更新一期档案，并通过业务选择入口查看一期、企业和个人视角；不得手输计划或人员全局 ID。
- 正式文件 MUST 按真实格式下载；个人档案已公开的文件端点 MUST 返回实际文件或明确的缺失事实，不得始终因未赋值 `fileInfoId` 失败。
- 结果不完整、未结束或无正式文件时 MUST 拒绝生成或禁下载；不引入签到前置。

## 证书与导航

- 管理员和学员 MUST 能在线预览并下载授权范围内的已签发证书；学员 MUST 能翻阅本人全部证书。
- 菜单、组件、路由和 Controller 权限 MUST 对齐；正式初始化与升级后都能到达已实现的 M4 页面，成果详情仍从具体培训计划进入。
- 模板设计 MUST 所见即所得：画布按底图原始像素等比渲染真实底图，元素按自身坐标与字号叠加并可拖动回写；底图 MUST 可由已保存的模板读回（`GET /api/certificate/templates/{id}/background`）。
- 元素坐标在契约与运行时 MUST 同名（`xPosition`/`yPosition`）；保存后重新打开设计器 MUST 回显坐标，不得静默丢失。
- 证书变量 MUST 按中文口径渲染：`SOURCE_TYPE` 等编码类变量在证书成品与设计器画布上 MUST 显示「课程」「理论考试」「培训计划」，不得印出英文编码；口径由同一份字典提供（前端 `constants/enum-options`，后端 `CertificateSourceTypes`），未知编码原样保留。
- 元素较多时设置区 MUST 在自身区域内滚动，预览画布 MUST 保持可见；新增元素入口 MUST 保持可达；在画布上选中元素 MUST 将其设置项滚入设置区可视范围。
