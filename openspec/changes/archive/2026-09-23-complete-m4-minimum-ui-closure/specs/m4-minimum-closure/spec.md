## ADDED Requirements

### Requirement: M4 界面必须完成已定义能力的最小操作链

系统 MUST 让已定义的问卷、已结束成果、专家查课、三级档案和证书能力通过相应登录角色在界面上完成，不得以仅有 API、路由或占位页面代替操作闭环。本要求不增加新的业务规则、成绩口径或产品能力。

#### Scenario: 管理员和填写人完成问卷链

- **GIVEN** 管理员具有当前问卷权限
- **WHEN** 管理员设计、编辑、复制、删除草稿、双端预览并按当前契约设置用途和结果可见性后投放
- **THEN** 填写人可扫描真实二维码在登录态提交一次
- **AND** 重复提交由服务端拒绝
- **AND** 管理员及获授权的填写人按设置查看基础统计

#### Scenario: 管理员和专家核对正式成果

- **GIVEN** 计划已结束且引用专家查课表
- **WHEN** 管理员查看培训成果、专家提交查课意见
- **THEN** 成果界面展示计划信息、学员成绩与详情、奖惩及基础统计
- **AND** 管理员能在对应培训回看专家意见及提交信息

#### Scenario: 管理员形成三级档案

- **GIVEN** 已结束培训的参训结果完整
- **WHEN** 管理员从业务上下文更新档案，并进入一期、企业、个人视角
- **THEN** 三个视角展示一致的已存在档案事实
- **AND** 一期与个人档案可下载真实格式的受控文件
- **AND** 未结束、结果不完整或文件未生成时不得伪装正式档案完成

#### Scenario: 管理员与学员查看证书

- **GIVEN** 课程、理论考试或培训已配置启用的证书模板且学员达标
- **WHEN** 系统按既有规则自动签发证书
- **THEN** 管理员可在证书管理页预览及下载
- **AND** 学员可在个人中心翻阅、在线查看及下载本人证书
- **AND** 正式菜单、组件路径及后端权限对齐

### Requirement: 证书模板设计必须所见即所得且坐标契约可往返

系统 MUST 让模板设计者按真实底图定位元素，不得要求先手工量取坐标；模板元素的坐标字段在 HTTP 契约与运行时 MUST 使用同一名称，避免界面保存或回显时静默丢失。

#### Scenario: 设计者按真实底图定位元素

- **GIVEN** 模板已上传底图
- **WHEN** 管理员打开设计与发布并查看画布
- **THEN** 画布 MUST 按底图原始像素等比渲染真实底图
- **AND** 每个元素 MUST 按自身坐标与字号叠加显示，且能通过拖动或坐标输入回写
- **AND** 画布尺寸 MUST 由底图原始像素决定，无需人工填写

#### Scenario: 坐标字段在契约与运行时一致

- **GIVEN** 契约声明元素坐标字段为 `xPosition` 与 `yPosition`
- **WHEN** 客户端按契约提交设计并重新读取模板
- **THEN** 服务端 MUST 接收并返回同名坐标字段
- **AND** 保存后重新打开设计器 MUST 回显已保存的坐标，不得因字段名不一致而丢失

#### Scenario: 元素较多时预览画布保持可见

- **GIVEN** 模板已包含多个元素，设置区高度超过弹窗可视高度
- **WHEN** 管理员滚动设置区查看或修改靠下的元素
- **THEN** 设置区 MUST 在自身区域内滚动，预览画布 MUST 保持在视口内可见，不得被一起滚出视口
- **AND** 新增元素入口在设置区滚动时 MUST 保持可达
- **AND** 在画布上选中元素 MUST 将该元素对应的设置项滚入设置区可视范围

### Requirement: 证书变量取值必须以中文口径呈现

证书成品面向学员，证书变量 MUST 以中文口径渲染。来源类型等以编码存储的枚举，在证书成品与设计器画布上 MUST 显示为对应中文，不得直接印出库内英文编码；同一口径 MUST 在设计器画布、模板预览与正式签发三处保持一致，并由同一份字典提供。

#### Scenario: 来源类型变量渲染为中文

- **GIVEN** 签发规则与已签发证书的来源类型以 `COURSE` / `EXAM` / `TRAINING` 编码存储
- **WHEN** 模板预览或证书正式签发渲染 `SOURCE_TYPE` 变量
- **THEN** 证书 MUST 显示「课程」「理论考试」「培训计划」，而非英文编码
- **AND** 设计器画布的示例值 MUST 与正式签发同口径，不得一处中文一处英文
- **AND** 未知编码 MUST 原样保留，便于发现来源脏数据，不得渲染为空或占位符
