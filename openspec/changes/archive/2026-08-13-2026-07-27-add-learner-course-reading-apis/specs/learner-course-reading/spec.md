# learner-course-reading Specification

## ADDED Requirements

### Requirement: 学员只能分页读取本人课程

系统 MUST 提供“我的课程”分页接口，并强制使用当前登录人作为报名查询主体。

#### Scenario: 读取本人课程

- **GIVEN** 当前用户在当前机构存在多个课程报名
- **WHEN** 用户按学习状态分页查询“我的课程”
- **THEN** 系统只返回该用户自己的匹配报名
- **AND** 每项包含课程、开课、学习状态、进度、时间和封面字段

#### Scenario: 不能查询他人课程

- **GIVEN** 当前机构存在其他用户的报名
- **WHEN** 当前用户查询“我的课程”
- **THEN** 系统不返回其他用户的报名
- **AND** 接口不接受用于覆盖当前用户的 `userId`

### Requirement: 学员只能发现当前可自主报名的开课

系统 MUST 提供学员可报名开课分页接口，并在服务端执行发布状态、有效期、报名方式、参与范围和重复报名过滤。

#### Scenario: 发现可报名开课

- **GIVEN** 开课已发布、启用、在有效期内、报名方式为 OPEN 或 LINK 且允许自助报名
- **AND** 当前用户满足参与范围且尚未报名
- **WHEN** 用户按关键字或课程分类分页查询
- **THEN** 系统返回该开课及自助报名需要的字段
- **AND** `enrollmentAvailability` 为 `AVAILABLE`

#### Scenario: 隐藏不可报名开课

- **GIVEN** 开课未发布、已失效、不允许自助报名、用户不属于参与范围或用户已经报名
- **WHEN** 用户查询可报名开课
- **THEN** 系统不返回该开课

### Requirement: 本人学习任务来自冻结课程版本

系统 MUST 从报名关联开课的冻结课程版本快照返回章节和内容项任务，并合并该报名的内容项进度。

#### Scenario: 本人读取学习任务

- **GIVEN** 当前用户是报名本人且开课绑定有效课程版本快照
- **WHEN** 用户读取报名学习任务
- **THEN** 系统按快照顺序返回课程、章节和内容项
- **AND** 每个内容项包含标题、必修标记、进度、可学习状态及必要引用
- **AND** 尚无进度记录的内容项仍以 NOT_STARTED 返回

#### Scenario: 拒绝访问他人报名任务

- **GIVEN** 报名属于当前机构的其他用户
- **WHEN** 当前用户读取该报名的学习任务
- **THEN** 系统拒绝访问
- **AND** 不泄漏课程、章节、内容项或进度信息

#### Scenario: 冻结快照异常

- **GIVEN** 报名关联开课没有有效冻结版本快照
- **WHEN** 报名本人读取学习任务
- **THEN** 系统返回快照不存在的数据异常
- **AND** 不回退读取可变课程草稿
