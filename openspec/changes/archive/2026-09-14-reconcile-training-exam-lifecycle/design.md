# Design：培训考试恢复与双端统一

## 入口状态机

```text
EXAM + PENDING/NOT_STARTED -> 只读须知 -> 明确开始 -> 统一 enter -> 作答
EXAM + IN_PROGRESS          -> 统一 enter -> 恢复原作答
EXAM + 终态                 -> 统一 enter -> 结果回看
QUESTION_BANK               -> 统一 enter -> 练习或结果
```

须知读取只读取培训专属考试快照，绝不创建 Candidate 或 Attempt。统一 `enter` 保持创建或恢复的兼容语义。

## 截止时间

服务端保存的绝对 `deadlineTime` 是裁决依据。页面离开只暂存答案；重入按照该时间重新计算剩余时间。`ANSWERING` 但截止时间缺失或不可解析时，客户端显示异常并禁止本地自动收卷；已到期时调用超时收卷并跳转结果。服务端手动提交再次校验截止时间，并由定时任务兜底扫描超时作答。

## 跨端一致性

PC 与移动端共用相同的培训内容状态判断、只读须知接口、统一进入接口和终态跳转规则。列表只恢复状态呈现，不改变任务数据、结果投影或计划状态口径。
