# Proposal：补齐机构主数据管理能力

## Why

已评审数据模型将 `sts_org_organization` 定义为平台、园区、企业和培训机构的统一业务主体，并要求部门、成员及培训业务数据通过
`organization_id` 归属机构。课程实施阶段因完整机构能力尚未就绪，先创建该表并初始化
`org_code=DEFAULT` 的默认占位机构。

后续 BASE-02 只实施了机构成员、标签、岗位和角色数据范围，将“已有机构表”误当作“已有机构管理能力”，没有提供机构列表、创建、
修改、启停用和引用保护 API。当前下游数据虽可关联默认占位机构，但无法登记真实园区、企业或培训机构，监管关系、跨机构授权、培训计划参与
机构和机构档案缺少可维护的真实主体。

## What Changes

- 在既有机构表上补齐机构分页、详情、创建、修改和启停用后端能力。
- 新增机构层级、联系人、默认占位机构和引用保护规则。
- 扩展机构 OpenAPI 与平台级显式权限点。
- 修正路线图和进度记录中将机构基础支撑提前关闭的问题。

## Capabilities

### New Capabilities

- `organization-master-data`：平台、园区、企业和培训机构的统一主数据登记册。

### Modified Capabilities

- `org-member-data-scope`：成员、部门及角色归属必须引用有效且非占位的真实机构。
- `org-resource-grant`：监管关系与跨机构资源授权不得使用 `DEFAULT` 占位机构。

## 目标

- 建立可维护的机构主数据登记册，覆盖平台、园区、企业和培训机构四类主体。
- 提供机构分页查询、详情、创建、修改和启停用能力，并保证机构编码全局稳定唯一。
- 明确机构层级、联系人、状态及默认占位机构的处理边界。
- 为部门、成员、监管关系、资源授权和各业务模块提供稳定、可追溯的真实机构 ID。
- 修正路线图和进度记录中将机构基础支撑提前标记完成的问题。

## 用户价值

- 平台运营人员可先登记真实机构，再为机构建立部门、人员、岗位和标签。
- 园区、企业和培训机构能以独立主体参与监管、授权、课程、考试和培训业务。
- 下游业务不再依赖 `DEFAULT` 占位机构，机构关联和隔离规则可以通过真实数据验证。
- 前端协作方可依据稳定 OpenAPI 实现机构列表和机构维护入口。

## 功能范围

- 机构主数据分页查询与详情。
- 创建和修改机构编码、名称、类型、上级机构、联系人、状态和描述。
- 机构编码全局唯一；机构层级不得成环，父子机构必须为有效机构。
- 启用、禁用及被引用机构的变更保护。
- 机构管理权限点、初始化菜单权限和 `docs/api/org.openapi.json` 契约扩展。
- 逐步停止新增业务数据继续依赖 `DEFAULT` 占位机构；历史数据迁移不在本 Change 自动执行。

## 非目标范围

- 前端页面、Mock、前后端联调或 UI 验收；前端以 OpenAPI 为准另开。
- 修改普通账号“单一主机构、单一主部门”的既有规则。
- 新增机构类型、监管层级或跨机构任职模型。
- 自动把现有 `DEFAULT` 数据拆分或迁移到真实机构。
- 修改监管关系、资源授权、部门、成员及各业务模块的既有表结构。
- 删除 `DEFAULT` 占位机构或批量改写其历史关联数据。

## 影响范围

- `backend/sts-service-admin`：机构 Controller、Service、Mapper、DTO/VO、权限及测试。
- `backend/sts-service-admin-init`：机构管理权限点。
- `docs/api/org.openapi.json`：扩展机构主数据 API 契约。
- `openspec/`、`docs/requirement/`、`engineering/plans/`：补齐规格和进度真相。
- 预计不新增生产依赖，不修改现有机构表结构；若实现阶段发现必须改表，必须暂停并取得人工确认后新增 migration。

## 已确认决策

1. 机构登记册同时校验功能权限和既有 `data_scope`；除 `superAdmin` 外不按角色名称或机构类型赋予隐含权限。
2. `data_scope=ALL` 的普通管理员可以查询、创建和完整维护全部机构。
3. 本机构管理员在具有 `org:organization:edit` 权限时，只能修改本机构名称、联系人和描述，不能修改编码、类型、上级机构或状态。
4. 本期不提供机构物理/逻辑删除接口，只提供启用、禁用；已有任何部门、成员、监管关系、资源授权或业务数据引用时不得禁用。
5. `DEFAULT` 保留为历史兼容占位机构，禁止任何修改；新建真实业务数据不得继续选择它。
6. 机构类型沿用 `PLATFORM`、`PARK`、`ENTERPRISE`、`TRAINING_INSTITUTION`，本 Change 不增加其他类型。
