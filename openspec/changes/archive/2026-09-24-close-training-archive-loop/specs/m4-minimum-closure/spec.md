## ADDED Requirements

### Requirement: 档案事实必须完整覆盖功能项清单

系统 MUST 在一期、企业、个人三个视角返回同一份培训档案事实，字段一致，且 MUST 至少覆盖：培训计划、企业、培训内容、参训人员、签到情况、学员成绩、综合评价、奖惩记录、影像记录、附件、证书与数据统计。系统 MUST NOT 以“后端已查但契约未声明”的方式丢弃事实，MUST NOT 写空快照。

#### Scenario: 三视角事实一致

- **GIVEN** 一期已结束且结果完整的培训
- **WHEN** 分别按一期、企业、个人查询该培训的档案
- **THEN** 三者返回相同的事实字段集合与相同取值
- **AND** 结果可直接展示培训内容、成绩、奖惩、影像、附件与统计

#### Scenario: 契约不得静默收窄事实

- **GIVEN** 服务端已组装完整档案事实
- **WHEN** 调用方按机器可读契约解析响应
- **THEN** 契约声明的字段与响应体一致
- **AND** 不存在已组装但未声明的档案事实字段

### Requirement: 签到情况必须由线下成绩映射呈现

系统 MUST 以已录入的线下成绩映射档案中的签到情况：教师为参训人录入线下成绩即视为该参训人在线下培训到场。系统 MUST NOT 为此新增签到表、签到记录、签到列或扫码、定位、现场证据采集。计划不含线下培训内容时，签到情况 MUST 标记为不适用。签到情况 MUST NOT 进入 `missingItems`，MUST NOT 成为归档、档案文件生成或下载的前置条件。

#### Scenario: 录入线下成绩视为到场

- **GIVEN** 一个含线下培训内容且已结束的培训计划
- **WHEN** 教师为某参训人录入线下成绩后查询档案
- **THEN** 该参训人的签到情况为已到场
- **AND** `missingItems` 中不含签到相关项

#### Scenario: 无线下内容的培训

- **GIVEN** 一个不含线下培训内容的已结束培训计划
- **WHEN** 查询该培训档案
- **THEN** 所有参训人的签到情况为不适用
- **AND** 不影响该档案的可归档性

#### Scenario: 未录入线下成绩不新增阻塞

- **GIVEN** 一个含线下培训内容的已结束培训计划
- **WHEN** 某参训人尚未录入线下成绩
- **THEN** 该参训人的签到情况为未记录
- **AND** 系统不因签到情况本身在 `missingItems` 中新增条目

### Requirement: 归档快照与档案素材必须写入真实事实

归档时系统 MUST 写入真实的奖惩快照与证书快照，MUST NOT 写入空对象。系统 MUST 把培训资料登记为档案素材并保留来源资料关联，同一文件 MUST NOT 被重复登记。快照哈希 MUST 覆盖参训人事实快照，使档案是否发生变化可判定。

#### Scenario: 重复更新档案

- **GIVEN** 一期已归档的培训
- **WHEN** 在事实变化后再次更新档案
- **THEN** 生成新版本且快照哈希与上一版本不同
- **AND** 同一文件不产生重复档案素材行

#### Scenario: 奖惩与证书快照非空

- **GIVEN** 一期存在奖惩记录与已签发证书的已结束培训
- **WHEN** 更新该培训档案
- **THEN** 对应参训人的奖惩快照与证书快照写入真实事实
- **AND** 不存在写入空对象的快照

### Requirement: 档案文件必须是可交付的 PDF 正本

一期档案与个人档案 MUST 输出 `application/pdf` 正本。系统 MUST NOT 以纯 JSON 或纯文本作为对外档案文件，MUST NOT 使用占位文件 ID 或空快照冒充档案。一期档案 MUST 持久化当前版本的受控 `fileInfoId` 并在下载时回读同一文件；个人档案 MUST 按当前可见的已结束培训事实即时组装。PDF MUST 呈现封面信息、数据统计、培训内容、参训人员成绩（含签到情况）、综合评价、奖惩、影像记录清单、附件清单与证书清单。影像与附件原件 MUST NOT 内嵌进 PDF，MUST 经受控端点另行获取。既有以 JSON 生成的历史档案 MUST NOT 被迁移改写；系统 MUST 在档案查询结果中标注该当前文件不是 PDF 正本，提示需重新更新档案。

#### Scenario: 下载一期档案正本

- **GIVEN** 一期结果完整并已归档的培训
- **WHEN** 管理员下载档案文件
- **THEN** 得到 `application/pdf` 文件且可打开、中文正常显示
- **AND** 文件内含数据统计、成绩表（含签到情况）、奖惩、影像与附件清单、证书清单

#### Scenario: 结果不完整时拒绝并无所残留

- **GIVEN** 培训已结束但存在结果不完整的参训人
- **WHEN** 请求更新档案或下载档案文件
- **THEN** 系统拒绝请求且不生成占位文件或空快照

#### Scenario: 影像与附件只出清单

- **GIVEN** 一期培训存在影像与附件资料
- **WHEN** 下载该期档案正本
- **THEN** 文件中包含影像与附件清单
- **AND** 不内嵌影像与附件的二进制原件

#### Scenario: 历史 JSON 档案提示重新更新

- **GIVEN** 一期培训曾以 JSON 生成过档案文件且尚未重新归档
- **WHEN** 查询该期档案
- **THEN** 结果标注当前文件不是 PDF 正本
- **AND** 提示重新更新档案后即可下载 PDF 正本
- **AND** 已生成的 JSON 文件不被改写或迁移

### Requirement: 个人档案必须提供详情与证书入口

个人档案 MUST 提供个人培训记录、参训情况、奖惩记录与综合评价的详情内容，并 MUST 为具备证书查询权限的调用方提供证书清单与下载入口。证书 MUST 复用既有证书查询与文件端点；系统 MUST NOT 在档案中复制证书文件，MUST NOT 因档案查询而新签发证书。个人档案 MUST 支持导出为 PDF。

证书清单 MUST 受权限门控：调用方缺少 `certificate:cert:list` 时，档案响应 MUST NOT 包含证书清单字段，MUST NOT 以“返回清单但禁用下载”代替。

#### Scenario: 查看与下载证书

- **GIVEN** 某人员在一期已结束培训中获得已签发证书，且调用方具备 `certificate:cert:list`
- **WHEN** 查询该人员个人档案
- **THEN** 档案返回该人员的证书清单
- **AND** 可在线查看并下载证书原件

#### Scenario: 缺少证书权限

- **GIVEN** 调用方仅具备 `archive:training:list` 而不具备 `certificate:cert:list`
- **WHEN** 查询该人员个人档案
- **THEN** 档案响应不包含证书清单字段
- **AND** 个人档案的其余详情内容仍正常返回

#### Scenario: 导出个人档案

- **GIVEN** 某人员存在已结束且结果完整的培训记录
- **WHEN** 导出该人员个人档案
- **THEN** 得到 `application/pdf` 个人档案文件

### Requirement: 企业档案必须可筛选并可下载档案文件

企业档案 MUST 支持按培训名称、培训编号、开始时间、结束时间、培训类型筛选当前租户内已结束培训，MUST 支持从列表进入该期档案详情，并 MUST 支持下载该期档案文件。企业档案 MUST NOT 跨租户返回其他机构档案。

#### Scenario: 筛选并下载

- **GIVEN** 当前租户内存在多期已结束培训
- **WHEN** 管理员按培训类型与结束时间范围筛选，并下载其中一期的档案文件
- **THEN** 列表只返回符合条件且属于当前租户的已结束培训
- **AND** 下载得到该期的 PDF 档案正本

#### Scenario: 不跨租户

- **GIVEN** 其他机构存在已结束培训
- **WHEN** 当前租户管理员查询企业档案
- **THEN** 结果中不含其他机构的培训

### Requirement: 档案数据统计口径必须与综合结果一致

档案 MUST 提供数据统计，且至少包含：培训内容项数与必修项数、参训人数、已完成人数、通过人数、未通过人数、结果不完整人数、通过率、平均综合分、线上与线下学时合计、影像与附件数量、奖惩数量与已到场人数。统计判定 MUST 与既有综合结果口径（`PASSED` / `FAILED` / `INCOMPLETE`）一致；分母为 0 的比率 MUST 返回空值，MUST NOT 以 0 冒充。

#### Scenario: 通过率与完成情况

- **GIVEN** 一期已结束培训，参训人结果包含 `PASSED`、`FAILED` 与 `INCOMPLETE`
- **WHEN** 查询该期档案统计
- **THEN** 通过人数、未通过人数与结果不完整人数与综合结果一致
- **AND** 通过率按通过人数除以已判定人数计算

#### Scenario: 无已判定参训人

- **GIVEN** 一期已结束培训中所有参训人均未形成判定结果
- **WHEN** 查询该期档案统计
- **THEN** 通过率与平均综合分为空值
- **AND** 不使用 0 冒充缺失值
