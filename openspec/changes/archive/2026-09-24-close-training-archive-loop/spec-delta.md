# 培训档案事实与档案文件增量规格

## 档案事实清单

- 一期、企业、个人三个视角 MUST 返回**同一份**档案事实，字段 MUST 一致。
- 档案事实 MUST 至少覆盖：培训计划、企业、培训内容、参训人员、签到情况、学员成绩、综合评价、奖惩记录、影像记录、附件、证书、数据统计。
- 系统 MUST NOT 以"后端已查但契约未声明"的方式丢弃事实；MUST NOT 写空快照。

### Scenario：三视角事实一致

- **GIVEN** 一期已结束且结果完整的培训
- **WHEN** 分别按一期、企业、个人查询该培训的档案
- **THEN** 三者返回相同的事实字段集合与相同取值
- **AND** 页面可直接展示培训内容、成绩、奖惩、影像、附件与统计

## 签到情况

- 签到情况 MUST 由**已录入的线下成绩**映射呈现；教师录入线下成绩即视为该学员在线下培训到场。
- 系统 MUST NOT 为此新增签到表、签到记录、签到列或扫码/定位/现场证据采集。
- 计划不含线下培训内容时，签到情况 MUST 标记为不适用。
- 签到情况 MUST NOT 进入 `missingItems`，MUST NOT 成为归档或档案下载的前置条件。

### Scenario：录入线下成绩视为到场

- **GIVEN** 一个含线下培训内容且已结束的培训计划
- **WHEN** 教师为某参训人录入线下成绩后查询档案
- **THEN** 该参训人的签到情况为已到场
- **AND** `missingItems` 中不含签到相关项

### Scenario：无线下内容的培训

- **GIVEN** 一个不含线下培训内容的已结束培训计划
- **WHEN** 查询该培训档案
- **THEN** 所有参训人的签到情况为不适用
- **AND** 不影响档案的可归档性

## 归档快照与资料接线

- 归档 MUST 写入真实的奖惩与证书快照，MUST NOT 写空对象。
- 归档 MUST 把培训资料登记为档案素材并保留来源资料关联，同一文件 MUST NOT 被重复登记。
- 快照哈希 MUST 覆盖参训人事实，使事实变化可判定。

### Scenario：重复更新档案

- **GIVEN** 一期已归档的培训
- **WHEN** 在事实变化后再次更新档案
- **THEN** 生成新版本且快照哈希与上一版本不同
- **AND** 同一文件不产生重复档案素材行

## 档案文件

- 一期档案与个人档案 MUST 输出 `application/pdf` 正本；系统 MUST NOT 以纯 JSON 或纯文本作为对外档案文件。
- 一期档案 MUST 持久化受控 `fileInfoId` 并在下载时回读同一文件；个人档案 MUST 按当前可见事实即时组装且 MUST NOT 使用占位文件 ID。
- PDF MUST 呈现封面信息、数据统计、培训内容、参训人员成绩（含签到情况）、综合评价、奖惩、影像记录清单、附件清单，以及证书数量。
- 影像、附件与证书的**明细** MUST NOT 内嵌进 PDF；MUST 经受控端点另行获取。
- 证书明细（证书编号、持证人、来源 ID）MUST NOT 出现在档案文件中：档案文件一经持久化，下载只校验档案权限，
  内嵌明细等于旁路证书清单的 `certificate:cert:list` 门控，且对外交付物会外带内部主键。
- 既有 JSON 历史档案 MUST NOT 被迁移改写；查询结果 MUST 标注该文件不是 PDF 正本并提示重新更新档案。
- 光栅 PDF 的文本不可检索已人工确认接受；本次 MUST NOT 为此引入 CJK 字体资源。

### Scenario：下载一期档案

- **GIVEN** 一期结果完整并已归档的培训
- **WHEN** 管理员下载档案文件
- **THEN** 得到 `application/pdf` 文件且可打开、中文正常显示
- **AND** 文件内含统计、成绩表、奖惩、影像与附件清单，以及证书数量
- **AND** 文件内不含证书编号、持证人与来源 ID

### Scenario：结果不完整

- **GIVEN** 培训已结束但存在结果不完整的参训人
- **WHEN** 请求更新档案或下载档案文件
- **THEN** 系统拒绝且不生成占位文件

## 个人档案

- 个人档案 MUST 提供详情内容：个人培训记录、参训情况、奖惩记录、综合评价。
- 个人档案 MUST 提供证书清单与下载入口；证书 MUST 复用既有证书查询与文件端点，MUST NOT 在档案中复制证书文件或新签发证书。
- 证书清单 MUST 受权限门控：调用方缺少 `certificate:cert:list` 时，响应 MUST NOT 包含证书清单字段。
- 个人档案文件 MUST 支持导出为 PDF。

### Scenario：查看与下载证书

- **GIVEN** 某人员在一期已结束培训中获得已签发证书，且调用方具备证书查询权限
- **WHEN** 管理员查询该人员个人档案
- **THEN** 档案返回该人员的证书清单
- **AND** 可在线查看并下载证书原件

### Scenario：缺少证书查询权限

- **GIVEN** 调用方仅具备档案查询权限
- **WHEN** 查询该人员个人档案
- **THEN** 响应不包含证书清单字段
- **AND** 个人档案其余详情仍正常返回

## 企业档案

- 企业档案 MUST 支持按培训名称、培训编号、开始时间、结束时间、培训类型筛选当前租户内已结束培训。
- 企业档案 MUST 支持从列表进入该期档案详情，并 MUST 支持下载该期档案文件。
- 企业档案 MUST NOT 跨租户查询其他机构档案。

### Scenario：筛选并下载

- **GIVEN** 当前租户内存在多期已结束培训
- **WHEN** 管理员按培训类型与结束时间范围筛选，并下载其中一期的档案文件
- **THEN** 列表只返回符合条件且属于当前租户的已结束培训
- **AND** 下载得到该期的 PDF 档案正本

### Scenario：不跨租户

- **GIVEN** 其他机构存在已结束培训
- **WHEN** 当前租户管理员查询企业档案
- **THEN** 结果中不含其他机构培训

## 数据统计

- 档案 MUST 提供数据统计，且至少包含：培训内容项数与必修项数、参训人数、已完成人数、通过人数、未通过人数、结果不完整人数、通过率、平均综合分、线上与线下学时合计、影像与附件数量、奖惩数量、已到场人数。
- 统计口径 MUST 与既有综合结果判定一致；分母为 0 的比率 MUST 返回空值而非 0。
