# Tasks：题目编辑与发布工作流（前端）

> 状态：前端实现完成，待人工真实接口联调。

## Task 1：题目列表关键字段与按需详情预览

- 状态：已完成（2026-08-17）
- Owner：AI
- 输入：现有 `question.openapi.json`、题库中心页面和用户交互反馈。
- 输出：移除题目 ID 的题目列表；点击“查看预览”后按既有详情接口在弹窗中加载完整预览；草稿/已发布入口仅在详情数据可用后显示。
- 前后端影响：仅 PC Web；后端和 OpenAPI 不变。
- API 依赖：`GET /api/question/questions`、`GET /api/question/questions/{questionId}`。
- 数据影响：无。
- 验收标准：列表不为每行预取详情；选择题目后能展示题干、题型、难度、当前版本和真实发布状态；详情缺失/失败时不伪造状态。
- 测试方式：先新增并观察列表/按需详情失败测试；运行题库定向 Node 测试、受影响 PC lint/typecheck/build。

## Task 2：题型驱动的新增与草稿编辑表单

- 状态：已完成（2026-08-17）
- Owner：AI
- 输入：Task 1、现有题目创建/更新 Contract。
- 输出：各题型只显示适用字段；切换题型后清理不适用数据；表单和提交前检查均提供中文反馈。
- 前后端影响：仅 PC Web；后端和 OpenAPI 不变。
- API 依赖：题目创建、更新和素材关联接口。
- 数据影响：无。
- 验收标准：单选/多选/判断、填空、简答分别符合设计中的字段规则；不适用字段不显示且不提交；可选补充信息不干扰首次录题。
- 测试方式：先新增题型显隐和提交净化失败测试；运行题库定向 Node 测试、受影响 PC lint/typecheck/build。

## Task 3：详情完整回显、发布引导与真实接口联调

- 状态：完成
- Owner：AI
- 输入：Task 1、Task 2、现有题目详情与发布 Contract、可访问的真实后端环境。
- 输出：完整详情回显、状态卡、发布前提示和关闭 Mock 后的真实联调证据；同步 QA/Retro、原 M2 Task 6 和进度表。
- 前后端影响：PC Web、工程记录；后端和 OpenAPI 不变。
- API 依赖：题目详情、更新、发布和素材关联接口。
- 数据影响：仅测试数据。
- 验收标准：真实接口下完成“创建草稿 → 完善 → 发布 → 查看已发布 → 修改后形成新草稿”闭环；所有状态仅来自详情接口与服务端结果。
- 测试方式：关闭 Mock 后执行 Task 1、2 回归、PC 构建和人工联调；完成规格符合性与代码质量双轴 Review。
- 联调记录：由用户手动执行“创建草稿 → 完善 → 发布 → 查看已发布 → 修改后形成新草稿”闭环；真实后端已确认可达，但当前自动化环境未持有登录 token，因此 QA/Retro、原 M2 Task 6 和进度表待人工联调结果补充。
