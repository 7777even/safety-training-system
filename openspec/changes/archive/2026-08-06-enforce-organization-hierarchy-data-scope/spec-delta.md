# Spec Delta：机构层级与机构树数据权限

## MODIFIED Requirements

### Requirement：机构必须形成合法业务层级

系统 MUST 使用统一机构主数据保存平台、园区、企业和培训机构，并且新建真实机构 MUST 符合以下父子关系：平台无上级，园区直属平台，企业直属园区，培训机构直属园区或企业。
`DEFAULT` 历史占位机构 MUST NOT 作为新机构上级。

#### Scenario：园区下创建企业

- **GIVEN** 当前用户具有机构创建权限且目标园区位于其可见机构范围
- **WHEN** 以该园区为上级创建 `ENTERPRISE`
- **THEN** 系统创建企业机构
- **AND** 新企业成为该园区机构的直接子节点

#### Scenario：企业下创建培训机构

- **GIVEN** 当前用户具有机构创建权限且目标企业位于其可见机构范围
- **WHEN** 以该企业为上级创建 `TRAINING_INSTITUTION`
- **THEN** 系统创建培训机构

#### Scenario：拒绝非法父子类型

- **WHEN** 尝试在平台下直接创建企业，或在企业下创建园区
- **THEN** 系统返回 HTTP 400
- **AND** 不写入非法机构记录

#### Scenario：拒绝范围外上级

- **WHEN** 操作者提交不在其数据范围内的上级机构 ID
- **THEN** 系统返回 HTTP 403
- **AND** 响应不泄露范围外机构详情

### Requirement：普通用户必须具有唯一所属机构

系统 MUST 为每个普通用户维护唯一当前所属机构，并以该机构作为数据范围解析起点。用户主部门和普通角色 MUST 与所属机构一致。系统
MUST NOT 在存在多机构、无机构或跨机构冲突时自动选择一个机构。

#### Scenario：拒绝一人多机构

- **GIVEN** 用户已有未删除机构成员档案
- **WHEN** 再为该用户创建另一个机构的成员档案
- **THEN** 系统拒绝创建
- **AND** 原所属机构保持不变

### Requirement：角色数据范围只按机构树解析

系统 MUST 只支持 `PLATFORM`、`PARK`、`ORGANIZATION` 三类角色数据范围。`PLATFORM` 覆盖当前所属平台及全部后代，`PARK`
覆盖当前所属园区及全部后代，`ORGANIZATION` 仅覆盖用户直接所属机构。

系统 MUST NOT 再支持 `ALL`、`DEPT`、`DEPT_AND_CHILDREN`、`CUSTOM` 或 `SELF` 角色数据范围，也 MUST NOT 保留 CUSTOM
部门授权字段和关联表。账号编码精确等于 `superAdmin` 的既有全局旁路保持不变。

#### Scenario：园区范围覆盖机构子树

- **GIVEN** 用户直接属于园区下的企业或培训机构
- **AND** 授予目标功能权限的角色数据范围为 `PARK`
- **WHEN** 系统解析该功能的数据范围
- **THEN** 返回所属园区自身以及园区下全部企业和培训机构 ID

#### Scenario：本机构不包含后代

- **GIVEN** 用户直接属于企业且企业下存在培训机构
- **AND** 角色数据范围为 `ORGANIZATION`
- **WHEN** 系统解析数据范围
- **THEN** 仅返回该企业机构 ID
- **AND** 不返回下属培训机构 ID

#### Scenario：无权限角色不产生数据范围

- **GIVEN** 用户的角色都未授予目标功能权限
- **WHEN** 系统解析目标功能的数据范围
- **THEN** 系统不返回任何可见机构
- **AND** 不得回退为本机构或形成全量查询

### Requirement：机构归属业务必须统一执行机构树范围

所有机构归属业务的列表、详情、写入、删除、统计、导出、批量操作和异步任务 MUST 使用服务端解析出的可见机构集合。客户端参数 MUST
NOT 扩大范围。本人执行链、教师任务归属、监管关系和显式资源授权 MUST 继续作为附加约束。

#### Scenario：园区查看下属企业数据

- **GIVEN** 园区用户对目标功能具有 `PARK` 数据范围
- **WHEN** 查询该园区下企业产生的业务数据
- **THEN** 系统返回权限集合内的数据
- **AND** 其他园区或其他平台的数据不出现在结果和统计中

#### Scenario：通过详情 ID 越权

- **GIVEN** 目标记录所属机构不在当前可见机构集合
- **WHEN** 用户直接提交该记录 ID 查询、修改或删除
- **THEN** 系统拒绝访问
- **AND** 不泄露目标记录的业务内容

## REMOVED Requirements

- 删除角色部门数据范围、部门及下级范围、自定义部门范围和本人范围。
- 删除普通角色的全系统 `ALL` 范围；由当前平台子树 `PLATFORM` 替代。
- 删除 `customDepts` API 字段及 `us_sys_role_dept` 数据模型。
