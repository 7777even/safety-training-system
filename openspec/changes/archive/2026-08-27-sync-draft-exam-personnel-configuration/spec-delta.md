# Spec Delta：草稿考试人员配置前端同步

## 变更类型

- 前端适配既有考试 API Contract 的语义更新。

## Requirement

### Requirement：草稿考试人员配置支持空阅卷人

考试工作台必须把草稿考试的空阅卷人响应作为正常状态，并允许以空数组整体清空阅卷人配置。

#### Scenario：草稿读取空阅卷人

- **WHEN** 管理员进入尚未配置阅卷人的草稿考试人员配置页
- **THEN** 页面展示正常空态并继续允许配置考生和阅卷人

#### Scenario：清空阅卷人

- **WHEN** 管理员保存考生范围且阅卷人列表为空
- **THEN** 前端提交 `reviewerUserIds: []`，并接受成功响应

#### Scenario：已发布缺执行对象

- **WHEN** 已发布考试的阅卷人接口返回业务码 7062
- **THEN** 前端保留服务端异常语义，不将其解释为草稿发布前置条件
