# Proposal：同步草稿考试人员配置前端语义

## 背景

后端已完成并确认 `2026-08-27-support-draft-exam-participant-configuration`：独立考试草稿可以先配置考生与阅卷人，发布后继续保留人员关系。现有考试工作台和 Mock 仍沿用“批阅人不能为空”的旧语义，导致前端阻止合法的清空操作，且无法正确消费草稿空阅卷人返回。

## 目标

- 草稿考试进入人员配置时，把空的批阅人列表视为正常空态。
- 阅卷人允许保存空数组，表达清空阅卷人。
- Mock 与已确认的 OpenAPI 语义一致。
- 保持发布校验、学员端可见性和课程考核阅卷人流程不变。

## 范围

- 独立考试工作台的人员配置页面与其前端 Mock。
- 对应的前端回归测试。

## 非目标范围

- 不修改后端、OpenAPI、接口路径、字段、权限或数据库。
- 不修改课程考核阅卷人接口或页面。
- 不改变发布所需的考生/阅卷人配置规则，亦不使草稿在学员端可见。
