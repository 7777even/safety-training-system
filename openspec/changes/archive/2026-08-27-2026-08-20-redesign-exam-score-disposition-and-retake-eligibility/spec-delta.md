# Spec Delta：成绩处置与补考资格

## ADDED Requirements

### Requirement：成绩发布前必须提供作答与得分核对

管理端成绩处置页必须在正式发布前提供当前考生本次作答的完整核对信息，包括作答状态、总分、及格结果、逐题答案、自动得分、人工得分、最终得分和批阅状态。

#### Scenario：教师核对已完成批阅的作答

- **GIVEN** 考生已交卷且所有需人工批阅的题目均已批阅
- **WHEN** 教师进入该作答的成绩处置页
- **THEN** 页面展示逐题答案和对应得分，并允许教师在确认后发布正式成绩

#### Scenario：存在待批阅主观题

- **GIVEN** 考生作答仍存在待人工批阅的主观题
- **WHEN** 教师查看成绩处置页
- **THEN** 页面明确标识待批阅题目并禁止发布正式成绩

### Requirement：补考操作只在服务端资格全部满足时出现

作答详情必须返回由服务端计算的补考资格。管理端仅在该资格通过且用户拥有开补考权限时显示“开补考”。

#### Scenario：不及格考生符合全部补考规则

- **GIVEN** 考试已启用补考，考生已正式发布不及格，处于补考窗口内、未达最大补考次数，且考试冻结试卷/规则可用于再次生成作答
- **WHEN** 教师查看成绩处置页
- **THEN** 补考资格为通过，页面显示“开补考”按钮

#### Scenario：补考规则任一项不满足

- **GIVEN** 补考开关、范围、时间窗口、次数上限、考试状态或冻结试卷/规则中任一条件不满足
- **WHEN** 教师查看成绩处置页
- **THEN** 页面展示服务端返回的未满足原因，且不显示“开补考”按钮

#### Scenario：资格读取后条件发生变化

- **GIVEN** 教师已看到可开补考状态
- **WHEN** 教师点击开补考前时间窗口、次数或考试状态发生变化
- **THEN** 服务端重新校验并拒绝不符合条件的创建，且不产生新的补考作答

### Requirement：补考复用当前考试冻结的试卷和规则

补考必须使用当前考试已经冻结、可用于生成作答快照的试卷和规则；本次变更不提供选择或配置另一份补考试卷的能力。

#### Scenario：当前考试试卷规则可用

- **GIVEN** 当前考试的冻结试卷和规则可用于开始作答
- **WHEN** 教师为符合条件的考生开补考
- **THEN** 新作答沿用当前考试的冻结试卷和规则
