# 前端多租户契约同步

## 背景

后端已完成多租户隔离重建，登录、租户管理、系统用户、监管视角和素材播放契约均已发生变化。前端仍保留旧机构层级、机构成员、监管关系、角色数据范围和旧登录请求，导致真实接口无法稳定联调。

## 目标

- 使 PC Web、移动端和 shared 类型与已确认的后端 OpenAPI 契约一致。
- 删除后端已移除能力对应的前端页面、API、Mock 和菜单引用。
- 增加监管聚合及只读租户视角支持。
- 输出真实可用的系统使用说明和菜单清单。

## 范围

- 企业编码登录与租户会话字段。
- 租户、用户、角色和租户上下文相关前端接口与页面。
- 监管聚合、`X-Target-Tenant-Id` 请求头和错误处理。
- 素材播放格式、上传错误提示和现有分片上传契约。
- 旧机构成员 CRUD、监管关系 CRUD 和旧组织层级 UI 清理。

## 非目标

- 不修改后端业务规则、数据库结构或权限模型。
- 不删除仍在产品范围但暂时使用 Mock 的课程、考试和培训页面。
- 不新增后端接口或前端自定义业务字段。
