# 规格增量

## ADDED 个人练习与错题
学员能查看分配练习、全部/未做/错题/收藏题目、答题卡，独立清除练习；正式考试和课程测试的可见历史错题可解析、删除、已掌握、再练，新错答重收录。
## ADDED 理论模拟与我的考试
练习与模拟使用独立会话；模拟交卷后反馈、不进入正式成绩投影；我的考试含正式和随堂测试及可见历史答卷。
## ADDED 课程收藏与讲师关注
54/58共用本人课程收藏；59关注同机构有效教师并查看最小详情；关系取消/重加幂等，失效资源可取消。
# 验收修正

## MODIFIED 我的收藏与课程关注
关注课程仅管理课程；我的收藏提供课程与题目分类，显示本人已收藏题目安全摘要，支持取消及进入本人可访问的原练习记录；失效来源仍允许取消，不泄露模拟或正式答卷答案。

## MODIFIED 练习与模拟记录
每条记录展示来源、错题题干摘要、模式与状态、开始/提交时间、已答/总题数；已提交展示正确、错误、未判定、正确率与累计用时。同名错题再练可通过题干和时间区分，模拟提交前不展示答案或判定结果。
